Schwartz 外科學

CH42 神經外科學 (Neurosurgery)

Source: Schwartz’s Principles of Surgery, 11th Edition

章節導讀

神經外科學涵蓋顱內壓升高、創傷、腫瘤、血管疾病及功能性疾病的診斷與治療。本章重點包括：顱內壓監測與腦疝類型、Glasgow 昏迷量表（GCS）的應用、脊椎創傷的穩定性評估，以及顱內血管瘤的手術與血管內治療決策。

顱內壓升高（Raised Intracranial Pressure, ICP）

正常值與病理

  • 正常ICP： 4-14 mmHg
  • 持續 >20 mmHg 可損傷腦組織
  • Monro-Kellie 原則： 顱腔為剛性結構，內容物總體積決定ICP

顱內壓監測

方式 說明
腦室外引流（EVD/Ventriculostomy） 可引流CSF降低ICP；可取CSF化驗
顱內監測導管（Intraparenchymal bolt） 置入腦實質；較不具侵入性

腦疝類型

類型 說明
小腦幕切跡疝（Uncal herniation） 顳葉內側向內移位→壓迫中腦；可阻斷大腦後动脉→枕葉梗塞
大腦鐮下疝（Subfalcine herniation） 扣帶回從大腦鐮下通過；可阻斷大腦前动脉
中央小腦幕疝（Central transtentorial herniation） 間腦/中腦向下通過小腦幕切跡
小腦扁桃體疝（Tonsillar herniation） 小腦扁桃體向下通過枕骨大孔

表現

  • 頭痛、噁心、嘔吐、進行性意識下降
  • Cushing三聯徵： 高血壓、心搏過緩、不規則呼吸（顱內壓危機標誌）

治療

  1. 確保氣道和足夠通氣
  2. Mannitol： 1g/kg 靜脈推註（20分鐘後生效）；血清滲透壓目標 >300 mOsm/L
  3. 過度換氣： 將 PaCO2 降至 25-30 mmHg
  4. 腦室引流或開顱減壓： 內科治療失敗時

Glasgow 昏迷量表（GCS）

項目 分數
睜眼 自發4 / 對言語3 / 對疼痛2 / 無1
言語 有定向感5 / 困惑4 / 不當言語3 / 無法理解2 / 無1
運動 遵從指令6 / 對疼痛定位5 / 對疼痛回縮4 / 屈曲3 / 伸直2 / 無1
  • GCS總分： 3-15
  • GCS ≤ 8 為重度頭部創傷：需插管保護氣道

創傷

頭部創傷（Head Trauma）

處理原則：

  • 防止**二次傷害**（缺氧、低血壓）
  • 維持收縮壓 >90 mmHg
  • 維持氧合（PaO2 >60 mmHg）
  • 重度頭部創傷： ICP監測

脊椎創傷（Spine Trauma）

穩定性評估（two-column theory）：

柱子 組成
前柱 前縱韌帶、椎體、椎間盤、後縱韌帶前半
後柱 後縱韌帶後半、小關節面、椎弓根、棘突

影像學：

  • CT：用於骨折評估（金標準）
  • MRI：用於韌帶損傷、椎間盤脫出

顱內腫瘤

原發性腦腫瘤

類型 特點
神經膠質瘤（Gliomas） 最常見原發性惡性腦瘤
腦膜瘤（Meningioma） 最常見良性腦瘤；女性較多
神經鞘瘤（Schwannoma） 聽神經瘤最常見

轉移性腫瘤

  • 最常見顱內惡性腫瘤（比原發性更常見）
  • 常見原發： 肺癌、乳腺癌、黑色素瘤、腎細胞癌、結直腸癌

功能性神經外科

深部腦刺激（DBS）

適應症 靶點
帕金森氏病 視丘下核（STN）、GPi
原發性顫抖 視丘腹側中間核（VIM）
肌張力不全 GPi

立體定位放射外科（Stereotactic Radiosurgery）

  • Gamma Knife： 201個鈷-60源聚焦照射

適應症： 腦膜瘤、神經鞘瘤、轉移性腫瘤、動靜脈畸形、三叉神經痛

顱內血管疾病

顱內血管瘤

類型 特點
囊狀血管瘤 蜘蛛膜下腔出血；高死亡率；治療：血管內線圈栓塞或手術夾閉
海綿狀血管瘤（Cavernoma） 良性；MRI梯度迴聲序列確診

缺血性中風

  • 4.5小時內靜脈 tPA
  • 6-8小時內行動脈機械取栓

周邊神經

夾捏神經病變（Entrapment Neuropathies）

病變 受壓神經
腕隧道症候群 正中神經（手腕）
肘隧道症候群 尺神經（肘部）

Summary

  1. GCS ≤ 8 為重度頭部創傷，需要插管保護氣道
  2. 顱內壓升高：正常 4-14 mmHg；持續 >20 mmHg 需積極處理
  3. DBS（深部腦刺激） 已成為治療帕金森氏症和原發性顫抖的標準照護
  4. 創傷性腦和脊椎損傷的主要治療目標： 防止缺氧和低血壓的二次傷害
  5. 囊狀血管瘤的蜘蛛膜下腔出血：是高死亡率神經外科疾病；血管內治療越來越重要
  6. 缺血性中風：4.5小時內靜脈 tPA，6-8小時內行動脈機械取栓
  7. 功能性神經外科：DBS 已成為治療藥物難治性帕金森氏症和原發性顫抖的標準照護
