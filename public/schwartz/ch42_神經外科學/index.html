Schwartz 外科學

CH42 神經外科學 (Neurosurgery)

Source: Schwartz’s Principles of Surgery, 11th Edition

顱內壓升高（Raised Intracranial Pressure, ICP）

正常值與病理

  • 正常ICP： 4-14 mmHg
  • 持續 >20 mmHg 可損傷腦組織
  • Monro-Kellie 原則： 顱腔為剛性結構，內容物總體積決定ICP

內容物體積增加的原因

內容物 原因
腦組織 創傷性腦水腫、腦梗塞水腫
血液 血腫形成、換氣不足導致腦血管擴張
CSF hydrocephalus

顱內壓監測

方式 說明
腦室外引流（EVD/Ventriculostomy） 放入側腦室額角；可引流CSF降低ICP；可取CSF化驗
顱內監測導管（Intraparenchymal bolt） 置入腦實質；較不具侵入性；可測腦組織氧合、溫度；需兩側各一個

腦疝類型（圖42-4）

類型 說明
小腦幕切跡疝（Uncal herniation） 顳葉內側（uncus）向內移位→壓迫中腦；可阻斷大腦後动脉→枕葉梗塞
大腦鐮下疝（Subfalcine herniation） 扣帶回從大腦鐮下通過；可阻斷大腦前动脉
中央小腦幕疝（Central transtentorial herniation） 間腦/中腦向下通過小腦幕切跡
小腦扁桃體疝（Tonsillar herniation） 小腦扁桃體向下通過枕骨大孔

表現

  • 頭痛、噁心、嘔吐、進行性意識下降
  • Cushing三聯徵： 高血壓、心搏過緩、不規則呼吸（顱內壓危機標誌）

治療

  1. 確保氣道和足夠通氣
  2. Mannitol： 1g/kg 靜脈推注（20分鐘後生效）；血清滲透壓目標 >300 mOsm/L
  3. 過度換氣： 將 PaCO2 降至 25-30 mmHg（減少腦血流）
  4. 腦室引流或開顱減壓： 內科治療失敗時

Glasgow 昏迷量表（GCS）（表42-2）

項目 分數
睜眼 自發4 / 對言語3 / 對疼痛2 / 無1
言語 有定向感5 / 困惑4 / 不當言語3 / 無法理解的聲音2 / 無1
運動 遵從指令6 / 對疼痛定位5 / 對疼痛回縮4 / 屈曲（去皮質）3 / 伸直（去大腦）2 / 無1
  • GCS總分： 3-15
  • 插管患者加"T"（如8T）
  • GCS ≤ 8 為重度頭部創傷：需插管保護氣道

診斷研究

影像學

檢查 應用
CT（非顯影） 急性頭部創傷、 foc 神經缺損、檢測急性出血；快速、普及
MRI 軟組織結構最佳；T1/T2/FLAIR/DWI各有不同用途
CT血管造影（CTA） 評估動静脈、血管瘤、剝離
CT灌注（CT perfusion） 評估腦血流（CBF、CBV、MTT）；用於缺血性中風
傳統血管造影 仍然是評估腦/脊椎血管病變的金標準

腦電圖（EEG）

  • 檢測癲癇放電、術中皮質映射
  • 事件相關電位（Evoked potentials）

EMG/神經傳導研究

  • 周邊神經功能評估
  • 通常急性受傷後3-4週進行（等待神經退化完成）

創傷

頭部創傷（Head Trauma）

嚴重程度分級：

等級 GCS
輕度 13-15
中度 9-12
重度 ≤ 8

處理原則：

  • 防止二次傷害（缺氧、低血壓）
  • 維持收縮壓 >90 mmHg
  • 維持氧合（PaO2 >60 mmHg）
  • 重度頭部創傷： ICP監測

脊椎創傷（Spine Trauma）

Key Points：

  • 評估穩定性
  • 評估神經功能障礙

穩定性評估（two-column theory）：

柱子 組成
前柱 前縱韌帶、椎體、椎間盤、後縱韌帶前半
後柱 後縱韌帶後半、小關節面、椎弓根、棘突

影像學：

  • CT：用於骨折評估（金標準）
  • MRI：用於韌帶損傷、椎間盤脫出、神經結構損傷

周邊神經創傷

類型 說明
Axonotmesis 軸突受損但神經鞘完整；可自行恢復
Neurotmesis 完全切斷；需手術修復

脊椎：基本概念

穩定性（Stability）

  • 微創手術干預的常見原因： 創傷、感染、腫瘤、退化性疾病

脊椎融合手術（Spine Fusion Surgery）

  • 目的： 恢復穩定性、減輕疼痛、糾正畸形
  • 骨移植： 自體骨（gold standard）或異體骨
  • 融合率： 頸椎約90%、胸腰椎稍低

脊椎器械（Spinal Instrumentation）

  • 目的： 術中穩定、促進融合
  • 包括： 椎弓根螺絲、棒、鋼板、椎間融合器
  • 適應症： 創傷、退化性脊椎滑脫、脊椎側彎、腫瘤

顱內腫瘤

原發性腦腫瘤

類型 特點
神經膠質瘤（Gliomas） 最常見原發性惡性腦瘤；包括星狀細胞瘤、寡樹突膠質瘤、膠質母細胞瘤
腦膜瘤（Meningioma） 最常見良性腦瘤；女性較多；手術或放射治療
神經鞘瘤（Schwannoma） 聽神經瘤最常見；良性；手術或放射治療

轉移性腫瘤

  • 最常見顱內惡性腫瘤（比原發性更常見）
  • 常見原發： 肺癌、乳腺癌、黑色素瘤、腎細胞癌、結直腸癌
  • 治療： 手術切除、立體定位放射外科、全腦放射治療

癲癇手術

適應症

  • 藥物無法控制的癲癇（難治性癲癇）
  • 已知可切除的癲癇病灶

術式

術式 適用
顳葉癲癇 顳葉切除術
半球性發育不良 半球切除術
失張力發作或全身性癲癇 胼胝體切開術
— 迷走神經刺激（VNS）

功能性神經外科

深部腦刺激（DBS）

適應症 靶點
帕金森氏病 視丘下核（STN）、GPi
原發性顫抖 視丘腹側中間核（VIM）
肌張力不全 GPi
强迫症 內囊/腹側紋狀體
頑固性憂鬱症 膝下扣帶迴（sGC）

三叉神經痛

治療： 藥物（Carbamazepine）、微血管減壓術、射頻熱凝固術、Gasserian球囊壓迫

立體定位放射外科（Stereotactic Radiosurgery）

  • Gamma Knife： 201個鈷-60源聚焦照射

適應症： 腦膜瘤、神經鞘瘤、轉移性腫瘤、動靜脈畸形、三叉神經痛

脊椎腫瘤

類型 說明
髓內腫瘤 星狀細胞瘤、室管膜瘤；症狀：疼痛、神經功能障礙、CSI
髓外硬膜內腫瘤 腦膜瘤、神經鞘瘤；症狀：根性疼痛、神經功能障礙
硬膜外腫瘤 轉移性腫瘤最常見；常見乳腺癌、肺癌、前列腺癌轉移

感染

顱內感染

類型 說明
腦膿瘺（Brain abscess） 發燒、頭痛、局灶性神經缺損；需引流＋抗生素
腦膜腦炎 病原：病毒、細菌；症狀：發燒、頸部僵硬、意識障礙
硬膜下膿瘺（Subdural empyema） 緊急手術引流

脊椎感染

  • 椎間盤炎/骨髓炎： 背痛、發燒；MRI確診；抗生素治療

先天性/發育異常

脊柱裂（Spina Bifida）

類型 說明
隱性脊柱裂（Occulta） 只有骨骼缺損；通常無症狀
脊髓膜膨出（Meningocele） 腦膜通過缺損；無神經組織
脊髓脊髓膜膨出（Myelomeningocele） 脊髓和腦膜都通過缺損；導致神經功能障礙、下肢癱瘓、大小便失禁

先天性顱縫早閉（Craniosynostosis）

  • 一條或多條顱縫過早閉合
  • 治療： 手術切除閉合顱縫（顱骨切開術）

水腦症（Hydrocephalus）

  • CSF迴圈或吸收受阻
  • 治療： 腦室-腹膜（VP）分流或內視鏡第三腦室造口術（ETV）

Chiari I 畸形

  • 小腦扁桃體向下移位超過枕骨大孔5mm

症狀：

  • 頭痛、頸部疼痛
  • 顱神經功能障礙
  • 脊髓空洞症

治療： 後顱窩減壓術

顱內血管疾病

動靜脈畸形（AVM）

  • 先天性血管發育異常
  • 破裂風險： 每年2-4%
  • 治療： 手術切除、立體定位放射外科、血管內栓塞

顱內血管瘤

類型 特點
囊狀血管瘤（Ruptured aneurysm） 蜘蛛膜下腔出血；高死亡率；治療：血管內線圈栓塞或手術夾閉
海綿狀血管瘤（Cavernoma） 良性；MRI梯度迴聲序列確診
毛细血管扩张（Telangiectasia） 良性微病灶

缺血性中風

  • 4.5小時內靜脈tPA
  • 6-8小時內行動脈機械取栓
  • CT灌注成像區分可挽救的"penumbra"

周邊神經

夾捏神經病變（Entrapment Neuropathies）

病變 受壓神經
腕隧道症候群 正中神經（手腕）
肘隧道症候群 尺神經（肘部）
踝隧道徵候群 脛神經（踝部）

周邊神經腫瘤

  • 神經鞘瘤（Schwannoma）、神經纖維瘤（Neurofibroma）
  • 良性；手術切除

重點摘要（Key Points）

  1. 神經外科處理中樞、周邊和自主神經系統疾病；預防、診斷、治療、復健皆含括
  2. 臨床檢查最重要，但MRI、CT、顱內壓監測等輔助影像和監測極有幫助
  3. 創傷性腦和脊椎損傷的主要治療目標： 防止缺氧和低血壓的二次傷害
  4. 囊狀血管瘤的蜘蛛膜下腔出血：是最致殘和需密集治療的神經外科疾病之一；血管內治療是越來越安全的栓塞技術
  5. 腦腫瘤可來自原發或轉移組織；治療通常是手術切除＋/－放射和化療
  6. 脊椎器械用於各類脊椎不穩定的手術固定，包括創傷性、感染性、腫瘤性和退化性
  7. 神經系統感染是嚴重且常見的問題；手術適應症包括神經結構有症狀性壓迫的大多數情況
  8. 功能性神經外科：透過植入裝置的手術快速發展中；已成為治療藥物難治性帕金森氏症和原發性顫抖的標準照護
  9. 立體定位放射外科是治療顱內疾病（原發或輔助）的強大選擇；可用於腫瘤、血管畸形、顱神經痛
  10. Glasgow 昏迷量表是創傷性腦損傷分類的基礎；GCS ≤8 為重度，需要插管保護氣道
