# CH37 腹股溝疝氣 (Inguinal Hernias)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

腹股溝疝氣是普通外科最常見的手術之一，本章涵蓋從流行病學、病理生理、分類診斷到手術修補的完整知識體系。重點在於了解腹股溝管解剖結構、區分間接與直接疝氣的手術意義，以及掌握網片修補的適應症與技術。

## 手術應用解剖學

### 腹股溝管構造

**四層壁**：

| 層 | 結構 |
|----|------|
| **前壁** | <span style="color:#22d3ee">腹外斜肌腱膜</span> |
| **後壁** | <span style="color:#22d3ee">腹橫肌</span>、<span style="color:#22d3ee">腹橫筋膜</span> |
| **上壁** | <span style="color:#22d3ee">腹內斜肌</span> + <span style="color:#22d3ee">腹橫肌</span> |
| **下壁（底部）** | <span style="color:#22d3ee">腹股溝韌帶</span>（Poupart 韌帶） |

- **長度**：約 <span style="color:#34d399">4-6 cm</span> 錐形管道
- **起始**：後腹壁，通過深（內）腹股溝環（transversalis fascia 的開口）
- **終點**：淺（外）腹股溝環
- **內容物**：<span style="color:#22d3ee">精索</span>（3 條动脉、3 條靜脈、2 條神經、蔓狀靜脈叢、輸精管）；被 3 層精索筋膜覆蓋

### 重要韌帶結構

| 結構 | 說明 |
|------|------|
| **<span style="color:#22d3ee">腹股溝韌帶</span>（Inguinal / Poupart ligament）** | 髂前上棘至恥骨結節；形成腹股溝管底部 |
| **<span style="color:#22d3ee">Cooper 韌帶</span>（Pectineal ligament）** | 腔隙韌帶（lacunar ligament）融合於恥骨結節骨膜的部分 |
| **<span style="color:#22d3ee">腔隙韌帶</span>（Lacunar / Gimbernat ligament）** | 腹股溝韌帶進入恥骨時的三角形扇狀展開 |
| **<span style="color:#22d3ee">髂恥韌帶</span>（Iliopubic tract）** | 從髂前上棘到 Cooper 韌帶的腱膜帶；比腹股溝韌帶更深；構成股環前界 |

### 腹股溝神經

| 神經 | 來源 | 支配區域 |
|------|------|---------|
| **<span style="color:#60a5fa">髂腹股溝神經</span>（Ilioinguinal nerve）** | L1 | 陰莖根部/陰囊上部（男）；陰阜/大陰唇（女）；大腿內側上部感覺 |
| **<span style="color:#60a5fa">髂腹下神經</span>（Iliohypogastric nerve）** | T12-L1 | 臀部外側皮膚；腹股溝區感覺 |
| **<span style="color:#60a5fa">生殖股神經</span>（Genitofemoral nerve）** | L1-L2 | 生殖支：精索、提睪肌、陰囊/陰唇；股支：大腿上部前外側感覺 |
| **<span style="color:#60a5fa">股外側皮神經</span>（Lateral femoral cutaneous nerve）** | L2-L3 | 大腿外側感覺 |

### 後腹腔鏡視角的重要解剖

**五個腹膜皺褶（腹腔內標記）**：

- <span style="color:#22d3ee">臍正中韌帶</span>（urachus）
- <span style="color:#22d3ee">內側臍韌帶</span>（臍靜脈閉合殘留）
- <span style="color:#22d3ee">外側臍韌帶</span>（腹壁下血管）
- <span style="color:#f87171">外側窩</span>（間接疝氣位置）
- <span style="color:#f87171">內側窩</span>（直接疝氣位置）

**兩個潛在間隙**：

| 間隙 | 說明 |
|------|------|
| **Bogros space（腹膜前間隙）** | 腹膜與腹橫筋膜後板層之間；含脂肪和疏鬆結締組織 |
| **Retzius space** | Bogros space 最內側部分，位於膀胱上方 |

**Myopectineal orifice of Fruchaud**：由腹股溝韌帶分割的相對弱點區域；股環和內側腹股溝環皆穿過此區域。

**危險三角/區域（腹腔鏡修補時）**：

| 結構 | 邊界 | 內容物/注意事項 |
|------|------|----------------|
| **<span style="color:#f87171">Doom 三角</span>（Triangle of doom）** | 內：輸精管；外：生殖血管；後：腹膜邊緣 | 含髂外血管、旋髂深靜脈、股神經、生殖支 |
| **<span style="color:#f87171">Pain 三角</span>（Triangle of pain）** | 內：髂恥韌帶；外：生殖血管 | 含股外側皮神經、股支（生殖股神經）、股神經 |
| **<span style="color:#f87171">Death 圈</span>（Circle of death）** | — | 髂總、髂內、閉孔、腹壁下、髂外血管形成的血管延續 |

## 病理生理學

### 先天性 vs. 後天性

| 類型 | 說明 |
|------|------|
| **先天性** | 腹膜狀況（processus vaginalis）未閉合 → 隱性腹股溝疝氣；常見於兒童 |
| **後天性** | 腹壁肌肉弱點；遺傳因素；多種環境風險因素 |

### 風險因素

| 類別 | 因素 |
|------|------|
| **增加腹壓** | 慢性咳嗽（COPD）、用力、便秘、前列腺肥大、懷孕、腹水、站立 |
| **腹壁弱化** | 先天性結締組織疾病、膠原蛋白合成缺陷、抽菸 |
| **其他** | 肥胖（保護作用）、家族史、早產（<1500g）、過去右下方切口中手術史、动脉瘤、重體力勞動 |

### 膠原蛋白與疝氣

- 組織學研究：腹股溝疝氣患者 <span style="color:#60a5fa">I 型/III 型膠原蛋白比率</span>顯著降低
- <span style="color:#60a5fa">III 型膠原蛋白</span>對傷口張力強度貢獻較小
- Ehlers-Danlos 症候群等多種結締組織疾病與疝氣相關

## 分類系統

### Nyhus 分類

| Type | 描述 |
|------|------|
| **Type I** | 間接疝氣；內環正常；典型於嬰兒、兒童 |
| **Type II** | 間接疝氣；內環擴大但不侵犯腹股溝管底；未延伸至陰囊 |
| **Type IIIA** | 直接疝氣（大小不計） |
| **Type IIIB** | 間接疝氣已擴大至侵犯後腹股溝壁；滑動或陰囊疝氣通常歸類於此；也包含褲形疝氣（pantaloon） |
| **Type IIIC** | 股疝氣 |
| **Type IV** | 復發性疝氣；可加修飾 A（間接）、B（直接）、C（股）、D（混合） |

## 診斷

### 病史要點

- **最常見**：站立、咳嗽或用力時出現的腹股溝腫塊；躺下時可復位
- **疼痛**：神經受壓迫 → 彌漫性壓力感、局部尖銳疼痛或轉移痛（可放射至陰囊、睪丸或大腿內側）
- **嵌頓風險**：隨著缺陷變大、疝氣囊內容物增加，變得更難復位

### 理學檢查

- **檢查姿勢**：站立位（增加腹壓）
- **觸診**：食指通過陰囊至外腹股溝環；請患者用力（Valsalva）增加腹壓

**鑑別間接 vs. 直接**：

| 測試 | 說明 |
|------|------|
| **腹股溝阻斷測試** | 手指堵住內環，囑咳嗽；控制性衝動提示間接；持續突出提示直接 |
| 咳嗽衝動感覺 | 手指尖感覺 → 間接；手指背側感覺 → 直接 |

<span style="color:#fbbf24;font-weight:600">臨床要點：</span>準確率僅略高於 50%，最終確診常需手術探查。

### 鑑別診斷

| 類別 | 項目 |
|------|------|
| **惡性腫瘤** | 淋巴瘤、後腹腔肉瘤、轉移瘤、睪丸腫瘤 |
| **血管/淋巴** | 股动脉瘤/假性动脉瘤、淋巴結 |
| **陰囊疾病** | 靜脈曲張、附睪炎、睪丸扭轉、鞘膜積液、隱睪症 |
| **其他** | 皮脂腺囊腫、化膿性汗腺炎、Nuck 囊腫（大陰唇）、隱靜脈曲張、腰大肌膿腫、血腫、腹水 |

### 影像學

| 檢查 | 敏感度/特異度 | 說明 |
|------|-------------|------|
| **超聲波（US）** | <span style="color:#34d399">86% / 77%</span> | 最不具侵入性；利用腹壓增加誘發內容物移動；可能假陰性（缺乏移動）或假陽性（精索移動） |
| **CT** | <span style="color:#fbbf24">80% / 65%</span> | 可排除其他診斷 |
| **MRI** | <span style="color:#34d399">95% / 96%</span> | US 不確切時使用；昂貴；不常規使用 |

## 治療

### 保守治療（Watchful Waiting）

- **無症狀或症狀輕微的腹股溝疝氣**：建議保守觀察
- **<span style="color:#60a5fa">72%</span>** 的無症狀腹股溝疝氣患者在 <span style="color:#60a5fa">7.5 年</span>內會出現症狀並需要手術修復
- **併發症發生率（即刻 vs. 延遲修復）**：相當
- **褌帶（Truss）**：可緩解最多 <span style="color:#60a5fa">65%</span> 患者的症狀；但不改變併發症風險；可能增加嵌頓率

### 手術適應症

- **優先修復**：股疝氣、有症狀的腹股溝疝氣
- **嵌頓和絞窄**：緊急手術適應症

### 嵌頓和絞窄

| 情況 | 定義 | 處理 |
|------|------|------|
| **<span style="color:#f87171">嵌頓</span>（Incarceration）** | 內容物無法復位 | 嘗試 Taxi；非緊急 |
| **<span style="color:#f87171">絞窄</span>（Strangulation）** | 血液供應受損 | **緊急手術**；跡象包括壓痛、發燒、白血球增多、血行動力學不穩定 |

**Taxi 操作（用於嵌頓但無絞窄跡象者）**：

1. 給予止痛和輕度鎮靜
2. Trendelenburg 姿勢
3. 雙手拉長疝氣囊；由外向內逐步輕柔復位

<span style="color:#f87171;font-weight:600">警告：絞窄時嚴禁 Taxi</span>，將壞死組織退回腹腔可致災難性後果。

**絞窄手術前準備**：液體復甦、鼻胃管減壓、預防性靜脈抗生素。

### 抗生素預防

- 清潔手術通常不需術前預防性抗生素
- Cochrane 評論（17 個 RCT）：預防性抗生素整體降低感染率（<span style="color:#34d399">3.1% vs. 4.5%</span>）
- 含網片修補時效果更明顯（<span style="color:#34d399">2.4% vs. 4.2%</span>）

## 開放手術修補

### 前側腹股溝區域暴露

- 切口：於腹股溝上方，髂前上棘內下兩指寬度處
- 依序切開：皮膚 → 皮下組織 → Scarpa 筋膜 → 腹外斜肌腱膜

### 組織修復（Tissue Repairs）

#### 1. Bassini 修復

- 歷史性進步；現已少用（復發率較現代技術高）
- 游離精索、高位結紮疝氣囊、重建腹股溝管底
- 三層修復：將腹內斜肌、腹橫肌、腹橫筋膜縫至腹股溝韌帶

#### 2. Shouldice 修復

- 改良 Bassini 原則；四層連續縫合；張力分佈於多層
- 復發率低（但因技術要求高而使用減少）
- 常規切斷生殖股神經的生殖支 → 同側陰囊/陰唇感覺喪失
- **原則**：反覆連續縫合；從內環至恥骨結節再折返

#### 3. McVay 修復（Cooper 韌帶修復）

- **適應症**：股疝氣；無法使用網片的條件（如污染傷口）
- 將腹橫筋膜/腹直肌鞘縫至 <span style="color:#22d3ee">Cooper 韌帶</span>
- **放鬆切口（Relaxing incision）**：垂直切開腹直肌鞘約 <span style="color:#60a5fa">2-4 cm</span> → 減少張力；但可能增加術後疼痛和腹壁疝氣風險

#### 4. Desarda 修復（2001 年新技術）

- **不使用網片；使用一片外斜肌腱膜條**
- 將外斜肌腱膜內側瓣縫至腹股溝韌帶；游離的外斜肌腱膜條形成後壁

### 網片修復（Prosthetic Mesh Repairs）

#### Lichtenstein 修補（無張力平片修補）

- **最廣泛使用的開放網片修補技術**
- 將網片（<span style="color:#fb923c">聚丙烯</span>）置於精索後方，覆蓋整個腹股溝管底
- 網片固定於腹股溝韌帶、恥骨結節和聯合腱（不是高張力縫合）
- **復發率 <span style="color:#34d399"><1%</span>**
- 補片邊緣需超過缺損邊緣至少 <span style="color:#60a5fa">2-3 cm</span>

#### Plug and Patch / Prolene Hernia System (PHS)

- 網塞填塞疝氣環 + 平片覆蓋

#### 網片類型

| 類型 | 材料 | 特點 |
|------|------|------|
| **合成不可吸收** | 聚丙烯、PET | 耐用；標準選擇 |
| **合成可吸收** | Vicryl 等 | 最終失去支撐；復發率高 |
| **複合網片（Composite）** | 兩面不同材料 | 置於腹腔時臟層有防黏連塗層 |
| **生物網片** | 豬心包膜等 | 允許宿主細胞長入；感染區域可用 |

## 腹腔鏡與機器人修補

### 優勢

- 術後疼痛較少、恢復更快
- 雙側疝氣可同時修補
- 復發率與開放修補相當
- **學習曲線更長**

### 技術類型

| 技術 | 說明 |
|------|------|
| **IPOM（腹腔內網片置入）** | 網片置於腹腔內；需防黏連塗層 |
| **TAPP（經腹腹膜前修補）** | 進入腹腔、切開腹膜、剝離至腹膜前間隙置網片、最後關閉腹膜 |
| **TEP（全腹膜外修補）** | **不通過腹腔**；直接剝離至腹膜前間隙；泌尿外科/婦科手術史者可能黏連過多 |

### 網片固定

- 固定於 <span style="color:#22d3ee">Cooper 韌帶</span>和腹股溝韌帶（避免在 "Pain 三角" 內的結構上固定）
- 可吸收固定夾或縫線固定

### 腹腔鏡修補絕對禁忌症

- <span style="color:#f87171">嵌頓疝氣伴腸阻塞</span>
- <span style="color:#f87171">絞窄性疝氣</span>
- <span style="color:#f87171">大型陰囊疝氣</span>（難以腹腔鏡操作）

### 腹腔鏡 vs. 開放修補

| 結果 | 腹腔鏡 | 開放 |
|------|--------|------|
| 術後疼痛 | **較少** | 較多 |
| 恢復時間 | 較快 | 較慢 |
| 總費用 | 較高 | 較低 |
| 學習曲線 | 較陡 | 較短 |
| 雙側修補 | 一次完成 | 需兩次切口 |
| 復發率 | 相當 | 相當 |

## 復發與併發症

### 復發率比較

| 修補方式 | 復發率 |
|---------|--------|
| 組織修復（Bassini/Shouldice/McVay） | 較高（取決於技術和疝氣類型） |
| Lichtenstein 網片修補 | **<span style="color:#34d399"><1%</span>** |
| 腹腔鏡網片修補 | 與開放相當 |
| Desarda | 較低（與網片修補相當？） |

### 主要併發症

| 併發症 | 說明 |
|--------|------|
| **術後疼痛** | 最主要關注點；可為神經損傷相關 |
| **神經損傷** | 髂腹股溝、髂腹下、生殖股神經損傷 → 慢性疼痛 |
| **睪丸併發症** | 睪丸腫脹、附睪炎、睪丸萎縮（精索血管損傷） |
| **血清腫/血腫** | 常見；多為自限性 |
| **感染** | 網片感染需移除；清潔傷口感染率 <span style="color:#60a5fa">2-5%</span> |
| **遲發性網片腐蝕** | 罕見；可進入膀胱或腸道 |

### 慢性疼痛

- **定義**：持續 ><span style="color:#60a5fa">3 個月</span>的術後疼痛
- **預防**：識別並保護神經；避免網片張力過高；使用可吸收固定物
- **治療**：神經阻斷、注射、手術神經切斷（三支神經皆可切斷）

## 特殊情況

### 兒童隱性腹股溝疝氣

- **早產兒**隱性腹股溝疝氣發生率極高（processus vaginalis 未閉合）
- 通常僅需單純疝氣囊高位結紮（不需重建）

### 股疝氣

- **嵌頓和絞窄風險顯著高於腹股溝疝氣**
- <span style="color:#60a5fa">3 個月</span>嵌頓累積發生率：<span style="color:#f87171">2.8%</span>；<span style="color:#60a5fa">2 年</span>：<span style="color:#f87171">4.5%</span>
- 股疝氣：<span style="color:#f87171">22%</span>（3 個月）和 <span style="color:#f87171">45%</span>（2 年）
- **建議確診後即使無症狀也應修復**

### 肥胖患者

- 外部腹股溝解剖難以評估
- 股疝氣可能被漏診
- 網片修補技術難度增加

### 復發性疝氣

- 再次修補前需影像學評估
- 建議由有經驗的外科醫師執行
- 網片修補復發後可考慮腹腔鏡修補（從不同平面進入）

## Summary

- <span style="color:#60a5fa">腹股溝解剖的透徹了解</span>是成功手術治療的關鍵（無論開放或腹腔鏡）
- 微創或無症狀腹股溝疝氣患者建議保守觀察（72% 在 7.5 年內會出現症狀）
- <span style="color:#f87171">股疝氣嵌頓/絞窄風險顯著高於腹股溝疝氣</span>（2 年嵌頓率 45% vs. 4.5%）；確診後即使無症狀也應修復
- <span style="color:#60a5fa">網片強化顯著改善復發率</span>（Lichtenstein <1%）；無張力修補為首選
- <span style="color:#60a5fa">慢性術後疼痛</span>（神經損傷相關）是主要關注；術中應識別並保護神經
- <span style="color:#f87171">嵌頓性疝氣若無絞窄跡象可先嘗試 Taxi</span>；絞窄疑似時**嚴禁**手法復位
- 老年/高風險患者可考慮局部麻醉下開放修補（可在門診執行）
