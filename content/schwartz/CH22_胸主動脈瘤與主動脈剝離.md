# CHAPTER 22 THORACIC AORTIC ANEURYSMS AND AORTIC DISSECTION 胸主動脈瘤與主動脈剝離

source: Schwartz's Principles of Surgery, 11th Edition

---

## Thoracic Aortic Aneurysm (TAA) 胸主動脈瘤

### Etiology & Classification 病因與分類

| Cause 病因 | Features 特徵 |
|-----------|--------------|
| **Nonspecific medial degeneration** 非特異性中膜退化 | Most common cause; elastic fiber fragmentation, smooth muscle loss 最常見原因；彈力纖維斷裂、平滑肌流失 |
| **Aortic dissection** 主動服剝離 | Creates false lumen, weakens wall 形成假腔、弱化管壁 |
| **Marfan syndrome** 馬凡氏症候群 | FBN1 mutation, fibrillin abnormality, TGF-β excess |
| **Loeys-Dietz syndrome** | TGF-β receptor mutations; aggressive, low threshold for repair |
| **Ehlers-Danlos (vascular type)** 埃勒斯-當洛氏(血管型) | Type III collagen defect; spontaneous arterial rupture 第三型膠原蛋白缺陷；自發性动脉破裂 |
| **Familial TAA** 家族性TAA | >20% have genetic predisposition; ACTA2 (14% of families) |
| **Bicuspid aortic valve** 雙葉主動服瓣 | 2% of population; 10x higher dissection risk; medial degeneration |
| **Infection (mycotic)** 感染(徽菌性) | S. aureus, Salmonella; saccular aneurysms |
| **Syphilitic aortitis** 梅毒性主動服炎 | Treponema pallidum; obliterative endarteritis of vasa vasorum |
| **Aortitis** 主動服炎 | Takayasu, giant cell arteritis, rheumatoid |
| **Trauma (pseudoaneurysm)** 外傷(假性動瘤) | Contained leak from trauma/surgery 外傷/術後局限性滲漏 |

### Growth & Rupture Risk 生長與破裂風險

| Location 位置 | Growth Rate 生長速率 | Critical Diameter 臨界直徑 | Rupture Risk at Critical 臨界時破裂風險 |
|--------------|-------------------|------------------------|-------------------------------------|
| **Ascending aorta** 升主動服 | 0.07 cm/yr | 6.0 cm | 31% |
| **Descending aorta** 降主動服 | 0.19 cm/yr | 7.0 cm | 43% |

### Aneurysm >6cm Annual Rates >6公分主動服瘤年度比率

- **Rupture 破裂:** 3.6%
- **Dissection 剝離:** 3.7%
- **Death 死亡:** 10.8%

### Clinical Manifestations 臨床表現

| Presentation 表現 | Features 特徵 |
|-----------------|--------------|
| **Asymptomatic** 無症狀 | Incidental finding on imaging 影像檢查時意外發現 |
| **Chest discomfort** 胸部不適 | Anterior chest, mimics angina (ascending) 前胸，像心絞痛(升主動服) |
| **Back pain** 背痛 | Between scapulae (descending) 肩胛骨間(降主動服) |
| **Compression symptoms** 壓迫症狀 | SVC syndrome, hoarseness (RLN), dysphagia, hemoptysis |
| **Aortic regurgitation** 主動服逆流 | Annular dilatation, heart failure 環狀擴張、心衰竭 |
| **Embolization** 栓塞 | Atheromatous debris to visceral/renal/extremities 粥狀硬化碎屑至內臟/腎/肢體 |
| **Rupture** 破裂 | Cardiac tamponade (ascending), hemorrhagic shock (descending) |

### Imaging 影像學

| Modality 工具 | Use 用途 |
|--------------|---------|
| **CXR** X光 | Initial screening; may appear normal 初步篩檢；可能正常 |
| **Echo (TTE/TEE)** 超音 | Ascending aorta, aortic root, valve; intraoperative 升主動服、主動服根部、瓣膜；術中 |
| **CT angiography** CTA | Gold standard; 3D reconstruction; entire aorta 黃金標準；3D重建；整條主動服 |
| **MRI/MRA** | Excellent detail; no contrast (renal failure patients) 極佳解析；無對比劑(腎衰竭患者) |
| **Angiography** 血管攝影 | Definitive anatomy; branch vessel involvement 確定解剖；分支血管侵犯 |

### Standard Aortic Measurement Locations 標準主動服測量位置

1. Sinuses of Valsalva 瓦爾沙瓦實
2. Sinotubular junction 竇管交界
3. Mid-ascending aorta 中段升主動服
4. Proximal arch (innominate origin) 近端主動弓(無名動脉起始)
5. Mid-arch (between carotid/subclavian) 中段主動弓(頸/鎖骨下之間)
6. Proximal descending (isthmus) 近端降主動服(峽部)
7. Mid-descending 中段降主動服
8. Aorta at diaphragm 橫膈膜處主動服
9. Abdominal aorta (celiac origin) 腹主動服(腹腔軸起始)

### Bicuspid Aortic Valve Considerations 雙葉主動服瓣考量

- 50-70% develop aortic dilatation 50-70%會發展主動服擴張
- Consider ascending aorta replacement at **>4.5 cm** during AVR 建議主動服瓣置換時一併置換>4.5公分的升主動服
- Different pathobiology than tricuspid valve aneurysms 與三葉瓣動服瘤有不同的病理生物學

## Aortic Dissection 主動服剝離

### Stanford Classification 斯坦福分類

| Type 類型 | Description 描述 |
|----------|----------------|
| **Type A** | Involves ascending aorta (with or without arch/descending) 侵犯升主動服(含或不含主動弓/降主動服) |
| **Type B** | Involves only descending aorta (distal to L subclavian) 只侵犯降主動服(左鎖骨下动脉遠端) |

### DeBakey Classification 德貝基分類

| Type 類型 | Description 描述 |
|----------|----------------|
| **Type I** | Involves entire aorta 侵犯整條主動服 |
| **Type II** | 局限於升主動服 |
| **Type IIIa** | 局限於胸降主動服 |
| **Type IIIb** | 延伸至腹主動服 |

### Pathophysiology 病理生理學

1. **Intimal tear** 內膜裂口 → blood enters media 血液進入中膜
2. **Medial separation** 中膜分離 → creates true + false lumen 形成真腔+假腔
3. **Propagation** 延伸 → branch vessel compromise 分支血管受影響
4. **Weakening** 弱化 → rupture risk 破裂風險

### Risk Factors 危險因子

- **Hypertension** (most common; 70% of patients) 高血壓(最常見；70%患者)
- Connective tissue disorders (Marfan, Loeys-Dietz, EDS) 結締組織疾病
- Bicuspid aortic valve 雙葉主動服瓣
- Cocaine use 使用古柯鹼
- Trauma 外傷
- Iatrogenic (catheterization, cardiac surgery) 醫源性

### Clinical Presentation 臨床表現

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Sudden severe chest pain** 突發性劇烈胸痛 | "Tearing" or "ripping" quality "撕裂"或"撕裂"性質 |
| **Pain radiation** 疼痛放射 | To back, neck, jaw, abdomen 至背部、頸部、下頜、腹部 |
| **Hypertension** 高血壓 | More common in Type B B型較常見 |
| **Hypotension** 低血壓 | Suggests rupture, tamponade, severe AR (Type A) 提示破裂、填塞、嚴重AR(A型) |
| **Pulse deficit** 脈搏缺失 | Carotid, brachial, femoral (30%) 頸、肱、股動脉(30%) |
| **New murmur** 新雜音 | Aortic regurgitation (Type A) 主動服逆流(A型) |
| **CVA/stroke** 中風 | Cerebral hypoperfusion 腦部低灌流 |
| **Paraplegia** 下身麻痺 | Spinal cord ischemia 脊髓缺血 |
| **Mesenteric ischemia** 腸繫膜缺血 | Abdominal pain, organ dysfunction 腹痛、器官功能障礙 |

### Diagnostic Imaging 診斷影像

| Test 檢查 | Recommendation 建議 |
|----------|------------------|
| **CT angiography** CTA | First-line; sensitivity >95%, specificity >95% 首選；敏感度>95%、特異性>95% |
| **TEE** | Bedside; cardiac function, valve, pericardium 床邊；心功能、瓣膜、心包 |
| **MRI** | Excellent detail; longer acquisition time 極佳解析；採集時間較長 |
| **Aortography** 主動服攝影 | Historical gold standard; rarely needed now 歷史黃金標準；現已少用 |

### Type A Dissection Management A型剝離處理

| Situation 情況 | Treatment 治療 |
|--------------|------------|
| **Acute Type A** 急性A型 | **Emergency surgical repair** (ascending aorta replacement) 緊急手術修復(升主動服置換) |
| **Complicated Type A** 複雜性A型 | (Malperfusion, rupture) → Emergency surgery (灌注不良、破裂)→緊急手術 |
| **Uncomplicated** 無併發症 | Ascending aorta replacement ± arch repair 升主動服置換±主動弓修復 |
| **Malperfusion syndrome** 灌注不良症候群 | May need hybrid approach 可能需要混合方式 |

### Type B Dissection Management B型剝離處理

| Situation 情況 | Treatment 治療 |
|--------------|------------|
| **Uncomplicated** 無併發症 | Medical management (BP control, monitoring) 藥物治療(血壓控制、監測) |
| **Complicated** 複雜性 | (rupture, malperfusion, expansion) → TEVAR or open repair |
| **Chronic (>14 days)** 慢性(>14天) | Medical management; surgery for complications |

### Medical Management Goals 藥物治療目標

- **HR:** <60 bpm 心率<60
- **SBP:** 100-120 mmHg 收縮壓100-120
- **IV beta-blockers** (esmolol, labetalol) first-line 靜脈β受體阻斷劑優先
- **Add vasodilators** (nitroprusside) if needed 必要時加用血管擴張劑

### Surgical/Endovascular Options 手術/血管內治療選項

| Procedure 術式 | Use 用途 |
|--------------|---------|
| **Ascending aorta replacement** 升主動服置換 | Type A |
| **Hemiarch repair** 半弓修復 | Limited arch involvement 有限主動弓侵犯 |
| **Total arch replacement + frozen elephant trunk** 全弓置換+冰凍象鼻 | Extended arch disease 廣泛主動弓疾病 |
| **TEVAR** | Type B complicated; preferred over open 複雜性B型；優於開放手術 |
| **Open descending aorta replacement** 開放式降主動服置換 | Failed TEVAR, contraindications TEVAR失敗、禁忌症 |

## Heritable Aortic Syndromes 遺傳性主動服症候群

### Marfan Syndrome 馬凡氏症候群

| Feature 特徵 | Detail 詳情 |
|------------|-----------|
| **Gene** 基因 | FBN1 (chromosome 15) |
| **Protein** 蛋白質 | Fibrillin-1 |
| **Mechanism** 機制 | Abnormal fibrillin → ↑TGF-β activity → matrix degeneration |
| **Cardiac** 心臟 | Aortic root dilatation (75-85%), annuloaortic ectasia, MVP |
| **Extracardiac** 心臟外 | Tall stature, high palate, joint hypermobility, lens dislocation |
| **Surgical threshold** 手術閾值 | Ascending aorta >5.0-5.5 cm (varies by institution) |
| **Life expectancy** 預期壽命 | 32 years without treatment; now near normal with surgery |

### Loeys-Dietz Syndrome

| Feature 特徵 | Detail 詳情 |
|------------|-----------|
| **Gene** 基因 | TGFBR1, TGFBR2 |
| **Triad** 三聯徵 | Arterial tortuosity/aneurysms + hypertelorism + bifid uvula/cleft palate |
| **Behavior** 行為 | Aggressive; rupture/dissection at smaller diameters |
| **Surgical threshold** 手術閾值 | Aorta >4.0-4.5 cm (lower than other syndromes) |

### Ehlers-Danlos (Vascular Type) 埃勒斯-當洛氏(血管型)

| Feature 特徵 | Detail 詳情 |
|------------|-----------|
| **Gene** 基因 | COL3A1 (type III collagen) |
| **Problem** 問題 | Spontaneous arterial rupture (mesenteric most common) |
| **Aortic** 主動服 | TAA and dissection less common, but very challenging surgery |
| **Surgical caution** 手術注意 | Tissue integrity severely reduced; holds sutures poorly |

### Familial TAA 家族性胸主動服瘤

- **>20% of TAA patients** have genetic predisposition >20%胸主動服瘤患者有遺傳傾向
- **ACTA2 mutation** (14% of families)
- **Autosomal dominant** with variable penetrance 體染色體顯性，表現度各異
- Other genes: MYH11, MYLK, ELN, TGFBR1/2, SMAD3, FBN2, etc.

## Surgical Techniques 手術技術

### Ascending Aortic Replacement 升主動服置換

- **Standard approach:** Median sternotomy, CPB 標準方式：正中胸骨切開、體外循環
- **Cannulation:** Axillary artery (best for arch surgery), femoral, direct aortic 插管：腋動脉(主動弓手術最佳)、股動脉、直接主動服
- **Myocardial protection:** Antegrade/retrograde cardioplegia 心肌保護：順行/逆行心麻痹
- **Valve-sparing root replacement (David procedure):** When valve salvage possible 保留瓣膜根部置換：當可保留瓣膜時

### Aortic Arch Replacement 主動弓置換

| Technique 技術 | Description 描述 |
|--------------|----------------|
| **Hemiarch** 半弓 | Replace ascending + proximal arch 置換升主動服+近端主動弓 |
| **Total arch** 全弓 | Replace entire arch with individual branch reattachment 置換整個主動弓並個別重新連接分支 |
| **Frozen elephant trunk** 冰凍象鼻 | Arch replacement + stented descending graft (hybrid) 主動弓置換+支架型降主動服移植片(混合) |
| **Debranching** 分支轉移 | Arch branch vessels bypassed to allow TEVAR 主動弓分支繞道以進行TEVAR |

### Descending Thoracic Aortic Replacement 降胸主動服置換

- **Left thoracotomy** approach 左胸切開方式
- **CPB:** Often left heart bypass or femoral-femoral 體外循環：常為左心繞道或股-股
- **Spinal protection:** CSF drainage, mild hypothermia, spinal monitoring 脊髓保護：腦脊髓液引流、輕度低溫、脊髓監測
- **Renal/visceral protection:** Cold perfusion 腎/臟器保護：冷灌注

## Endovascular Repair (TEVAR) 血管內修復

### Indications 適應症

- **Complicated Type B dissection** 複雜性B型剝離
- **Traumatic aortic injury** (pseudoaneurysm) 外傷性主動服損傷
- **Penetrating aortic ulcer** 穿透性主動服潰瘤
- **High-risk TAA** (selected cases) 高風險胸主動服瘤(特定病例)

### Advantages 優點

- Less invasive than open surgery 比開放手術創傷小
- Lower perioperative mortality 術期死亡率較低
- Shorter ICU/hospital stay ICU/住院時間較短
- Less spinal cord injury risk 脊髓損傷風險較低

### Complications 併發症

| Complication 併發症 | Risk 風險 | Prevention/Treatment 預防/治療 |
|-------------------|----------|------------------------------|
| **Endoleak** 內漏 | 5-15% | Type I: proximal extension; Type II: embolization |
| **Retrograde Type A dissection** 逆行性A型剝離 | 2-5% | Careful wire/catheter manipulation |
| **Spinal cord ischemia** 脊髓缺血 | 3-5% | CSF drainage, staged procedures |
| **Stroke** 中風 | 2-5% | Careful arch manipulation |
| **Renal failure** 腎衰竭 | 5-10% | Hydration, minimize contrast |

## Thoracoabdominal Aortic Aneurysm (TAAA) 胸腹主動服瘤

### Crawford Classification 克勞福分類

| Type 類型 | Extent 範圍 |
|----------|-----------|
| **Type I** | Descending胸 → suprarenal abdominal 降主動服→腎上腹主動服 |
| **Type II** | Descending胸 → infrarenal abdominal 降主動服→腎下腹主動服 |
| **Type III** | Lower descending → infrarenal 下段降主動服→腎下 |
| **Type IV** | Infrarenal (juxtarenal) only 僅腎下(近腎) |
| **Type V** | Supra celiac/pre celiac 腹腔軸上方/前 |

### Surgical Strategy 手術策略

- **Left thoracoabdominal incision** 左胸腹切開
- **CPB:** Left heart bypass, femoral-femoral 體外循環：左心繞道、股-股
- **Visceral protection:** Cold Ringer's lactate or blood cardioplegia into branch vessels 臟器保護：冷林格氏乳酸鹽或血液心麻痹液注入分支血管
- **Spinal protection:** CSF drainage, hypothermia, reimplant intercostals 脊髓保護：腦脊髓液引流、低溫、重新植入肋間血管

### Complications 併發症

| Complication 併發症 | Risk 風險 |
|-------------------|----------|
| **Spinal cord ischemia/paraplegia** 脊髓缺血/下身麻痺 | 3-8% (Type I/II higher) |
| **Acute kidney injury** 急性腎損傷 | 10-20% |
| **Respiratory failure** 呼吸衰竭 | 10-15% |
| **Mortality** 死亡率 | 5-15% (higher in Type II) |

## Postoperative Care 術後照護

### Monitoring 監測

- **Hemodynamic:** Invasive BP, CVP, sometimes PA catheter 血流動力學：有創血壓、中心靜脈壓、有時肺動脉導管
- **Neurologic:** Mental status, motor/sensory exam, spinal drain 神經學：意識狀態、運動/感覺檢查、脊髓引流管
- **Renal:** Urine output, creatinine 腎臟：尿量、肌酸酐
- **Cardiac:** ECG, troponin, echo for EF/valve function 心臟：心電圖、肌鈣蛋白、超音心圖測EF/瓣膜功能
- **Respiratory:** ABG, chest X-ray 呼吸：血液氣體、胸部X光

### Complications to Watch 需注意的併發症

| Complication 併發症 | Signs 徵象 | Treatment 治療 |
|-------------------|----------|-------------|
| **Bleeding** 出血 | Chest tube output, shock 胸管輸出、休克 | Re-exploration 再開刀 |
| **Tamponade** 填塞 | Beck's triad, echo 貝克氏三聯、超音 | Pericardiocentesis, re-exploration 心包穿刺、再開刀 |
| **Stroke** 中風 | Focal deficits 局部缺損 | CT, neurology consult |
| **Spinal cord injury** 脊髓損傷 | Lower extremity weakness 下肢無力 | CSF drainage, BP augmentation |
| **AR (new/worsened)** 新發/惡化AR | Murmur, HF 雜音、心衰竭 | Echo, possible reoperation |
| **Graft infection** 移植片感染 | Fever, sepsis 發燒、敗血症 | Antibiotics, possible graft excision |

### Long-term Follow-up 長期追蹤

- **Imaging surveillance:** CT/MRI yearly 影像監測：每年CT/MRI
- **BP control:** <130/80 mmHg 血壓控制：<130/80
- **Beta-blockers:** Standard 標準使用β受體阻斷劑
- **Avoid strenuous activity:** Heavy lifting in heritable syndromes 避免劇烈活動：遺傳性症候群避免提重物
