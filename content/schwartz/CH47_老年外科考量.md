# CH47 老年外科考量 (Surgical Considerations in Older Adults)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

老年外科病人具有獨特的病理生理特徵，包括衰弱、認知功能下降、多共病症及多重用藥。本章介紹Fried衰弱表型、術前認知功能評估（Mini-Cog）、譫妄預防及術後功能恢復的關鍵原則，強調老年族群需要多專科團隊合作以優化圍手術期照護。

---

## <span style="color:#60a5fa">衰弱症（Frailty）</span>

### Fried衰弱表型定義（5項指標，符合≥3項為衰弱）

| 指標 | 標準 |
|------|------|
| **體重減輕** | 過去一年非刻意減輕<span style="color:#f87171">≥5%</span>體重 |
| **疲憊感** | CES-D量表評分「大部分時間」 |
| **體能活動** | 男性<span style="color:#60a5fa"><383 kcal/週</span>；女性<span style="color:#60a5fa"><270 kcal/週</span> |
| **行走時間（15英尺）** | 依身高/性別（<span style="color:#f87171">6-7秒以上</span>） |
| **握力** | 依BMI/性別（見下表） |

### 衰弱風險分層

| 分層 | 符合項目 | 風險 |
|------|---------|------|
| **衰弱前期（Prefrail）** | 1-2項 | 中間風險 |
| **衰弱（Frailty）** | ≥3項 | <span style="color:#f87171">高風險</span> |

### 評估工具

| 工具 | 說明 |
|------|------|
| **Timed Up and Go（TUGT）** | 計時起身、走10英尺、轉身、返回坐下的時間；<span style="color:#f87171">≥15秒</span>=跌倒高風險 |
| **ADL/IADL** | 基本/工具性日常生活活動能力 |
| **Mini-Cog** | 三字回憶+時鐘繪製測試（認知障礙篩檢）|

## <span style="color:#60a5fa">術前評估</span>

### ACS NSQIP/AGS 最佳實踐要點

| 項目 | 內容 |
|------|------|
| **目標和治療偏好** | 確認並記錄患者目標、預立醫囑 |
| **醫療代理人** | 確認並記錄健康照護代理人 |
| **麻醉前禁食** | 可考慮清流質縮短至2小時 |
| **藥物管理** | 停用非必要藥物；確認必要藥物已服用 |
| **靜脈血栓預防** | 遵循最佳實踐 |
| **抗生素預防** | 遵循最佳實踐 |

### 功能評估

| 評估內容 | 工具/方法 |
|---------|----------|
| **基本ADL** | 穿衣、洗澡、如廁、轉移、禁制、進食 |
| **工具性ADL** | 購物、洗衣、交通、理財、服藥、備餐、家務 |
| **體能表現** | TUGT（<span style="color:#f87171">≥15秒</span>=高風險）|
| **跌倒史** | 過去1年跌倒次數 |
| **認知功能** | Mini-Cog |
| **視覺/聽覺/吞嚥** | 缺陷評估 |

### 認知功能評估（Mini-Cog）

| 步驟 | 內容 |
|------|------|
| 1 | 說出三個詞（banana, sunrise, chair）要求患者記住 |
| 2 | 要求患者畫時鐘並標出指定時間 |
| 3 | 請患者回憶三個詞 |

**解讀：** ≤3分=認知障礙

### 決策能力評估（四項標準）

1. 能表達治療選擇
2. 理解相關資訊
3. 承認其醫療狀況和選項
4. 能進行理性的討論

## <span style="color:#f87171">譫妄（Delirium）</span>

### 定義

- 注意力及覺察的障礙，急性發作且有波動性
- DSM-5定義

### 發生率

| 手術類型 | 發生率 |
|---------|--------|
| 白內障/泌尿科手術 | <span style="color:#34d399">4-5%</span> |
| 腹主動脈瘤修復/髖關節骨折 | <span style="color:#f87171">50-60%</span> |

### 術後譫妄後果

- 術後第一年<span style="color:#f87171">死亡風險增加2-3倍</span>

### 術後譫妄風險因素

| 類別 | 因素 |
|------|------|
| **患者因素** | <span style="color:#f87171">年齡≥70歲</span>、認知障礙、功能受限、憂鬱、聽力/視力障礙 |
| **術前實驗室** | 血鈉/鉀/血糖異常 |
| **手術因素** | 胸腔大手術、腹主動脈瘤修復、髖關節骨折 |
| **術中因素** | 失血量大（術後血球容積比<span style="color:#f87171"><30%</span>）|
| **術後因素** | 疼痛控制不足、輸液/電解質/代謝異常、噪音/環境改變 |

### 引起譫妄的常見藥物

- **抗膽鹼能藥物：** 三環抗憂鬱劑、抗組織胺、H2阻斷劑、抗痙攣劑
- **皮質類固醇**
- **<span style="color:#f87171">Meperidine</span>**
- **鎮靜催眠藥：** BZD、Zolpidem

### 預防（術後照護 bundle）

- **感官增強：** 眼鏡、助聽器
- **早期活動**
- **認知定向和治療活動**
- **睡眠優化**
- **疼痛管理（避免不足）**

### 治療流程

1. 排除可逆原因：感染、藥物、電解質、尿滯留、糞嵌塞
2. 非藥物治療優先
3. **藥物治療（只用於躁動譫妄且有安全疑慮者）：** <span style="color:#fb923c">Haloperidol</span> 0.5-1mg
4. 只在疑似戒斷時使用BZD

## <span style="color:#60a5fa">跌倒</span>

### 統計

- **<span style="color:#f87171">1/3的65歲以上成年人</span>過去一年有跌倒經歷**
- 過去一年跌倒者：<span style="color:#60a5fa">60%</span>在接下來一年內再跌倒

### 跌倒後果

- 功能狀態下降
- 入住護理之家機會增加
- **「Long lie」（跌倒後無法起身）」** → 持續功能下降

### 術前跌倒預後

| 術前跌倒次數 | 術後30天跌倒風險（校正OR）|
|-------------|-------------------|
| 1次 | <span style="color:#60a5fa">2.3</span> |
| 2次 | <span style="color:#60a5fa">3.6</span> |
| ≥3次 | <span style="color:#f87171">5.5</span> |

---

## <span style="color:#60a5fa">老年急性腹痛特點</span>

| 特點 | 說明 |
|------|------|
| **非典型表現** | 發燒、白血球升高、腹膜徵候可能不明顯 |
| **病情較嚴重** | 闌尾炎、膽囊炎死亡率較年輕人高 |
| **警訊** | 老年急性腹痛即使無發燒/白細胞升高也不能排除嚴重感染 |

---

## <span style="color:#60a5fa">術後功能恢復</span>

- **衰弱老年人術後常經歷顯著且持續的功能下降**
- **心臟功能**占老年患者術後死亡原因的一半以上
- **液體平衡**需要特別注意

---

## Summary

- **<span style="color:#60a5fa">衰弱評估：</span>** Fried衰弱表型（5項指標，≥3項=衰弱）；衰弱前期1-2項
- **<span style="color:#60a5fa">Mini-Cog：</span>** 三字回憶+時鐘繪製；≤3分=認知障礙
- **<span style="color:#f87171">譫妄：</span>** 腹主動脈瘤修復/髖關節骨折術後發生率<span style="color:#f87171">50-60%</span>；死亡風險增加2-3倍
- **<span style="color:#60a5fa">譫妄預防bundle：</span>** 感官增強、早期活動、認知刺激、睡眠優化、疼痛管理
- **<span style="color:#f87171">跌倒：</span>** 65歲以上1/3過去一年有跌倒；術前跌倒≥3次術後30天跌倒風險達5.5倍
- **<span style="color:#60a5fa">老年急性腹痛：</span>** 非典型表現，即使無發燒/白細胞升高也不能排除嚴重感染
- **<span style="color:#60a5fa">心臟功能：</span>** 占老年患者術後死亡原因的<span style="color:#60a5fa">>50%</span>
