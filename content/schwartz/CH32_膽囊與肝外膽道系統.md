# CH32 膽囊與肝外膽道系統

---

## 解剖與生理學

### 膽囊結構

- **形狀**：梨形囊狀，長約 7-10 公分，寬約 3-4 公分
- **容量**：30-50 毫升
- **位置**：肝臟臟面膽囊窩，透過漿膜層與肝臟連接
- **分區**：底部（fundus）、體部（body）、漏斗部（infundibulum）、頸部（cystic duct）

### 膽管系統

| 名稱 | 功能/描述 |
|------|-----------|
| **左/右肝管** | 收集肝臟膽汁 |
| **總肝管（CHD）** | 左、右肝管匯合 |
| **總膽管（CBD）** | 與膽囊管匯合後形成，長約 6-8 公分 |
| **膽囊管** | 連接膽囊與總膽管，內有 Heister 瓣膜 |
| **壺腹（Vater ampulla）** | 總膽管與胰管匯合後進入十二指腸 |

### 膽汁分泌與調節

- **膽汁成分**：膽鹽（70%）、磷脂（15%）、膽固醇（5%）、膽紅素、蛋白質、電解質
- **CCK（膽囊收縮素）**：脂肪、胺基酸進入十二指腸時釋放 → 膽囊收縮、Oddi 括約肌放鬆
- **膽鹽腸肝循環**：95% 在末端迴腸被重吸收，經門脈回肝臟再分泌

### 膽囊功能

- **儲存**：空腹時儲存膽汁
- **濃縮**：吸收水分和電解質，膽汁可濃縮 10 倍
- **排空**：進食後收縮排空膽汁

## 膽囊與膽道疾病

### 膽結石病（Cholelithiasis）

#### 流行病學

- 美國：每年約 100 萬新病例
- **終身盛行率**：男性 8%、女性 17%

#### 危險因素

| 因素 | 說明 |
|------|------|
| **4F's** | Female（女性）、Forty（40 歲以上）、Fat（肥胖）、Fertile（多產） |
| **種族** | 美洲原住民 > 白人 > 非裔美人 > 亞洲人 |
| **遺傳** | 一親等有膽結石者，風險增加 2 倍 |
| **體重快速下降** | 減重手術、極低熱量飲食 |
| **肝硬化** | 膽紅素升高 |
| **克隆氏症** | 末端迴腸疾病或切除 |

#### 膽結石分類

| 類型 | 成因 | 佔比 |
|------|------|------|
| **膽固醇結石** | 膽汁中膽固醇過飽和 | 80-90% |
| **色素結石** | 膽紅素鈣沉積 | 10-20% |

#### 發病機制

- **膽固醇結石**：膽汁膽固醇過飽和 → 膽固醇單水結晶形成 → 黏液膠固 → 結石形成
- **色素結石**：慢性溶血（游離膽紅素 ↑）→ 鈣膽紅素沉積

#### 臨床表徵

- **無症狀**：70-80% 終身無症狀
- **膽囊絞痛**：右上腹/上腹痛，30 分-6 小時，含油脂食物後誘發
- **膽囊炎**：疼痛、發燒、Murphy's sign（+）
- **黃疸**：結石掉入總膽管

#### 診斷

| 檢查 | 敏感性 |
|------|--------|
| **腹部超聲** | >95% |
| **CT** | 膽固醇結石不敏感 |
| **MRCP** | 膽管結石評估首選 |
| **ERCP** | 治療性檢查 |

### 膽囊炎（Cholecystitis）

#### 急性膽囊炎

**病因分類**：

| 類型 | 原因 |
|------|------|
| **結石性**（90-95%） | 膽囊管阻塞（結石） |
| **非結石性**（5-10%） | 嚴重創傷、燒傷、敗血症、長期 TPN |

**東京準則（診斷標準）**：

- **A**：區域性發炎徵兆（Murphy's sign、右上腹壓痛）
- **B**：發燒 >38.3°C、白血球 >10,000/μL
- **C**：影像學陽性發現（膽囊壁 >3-4 mm、周圍液體）

**階梯式治療**：

1. NPO、靜脈輸液、抗生素
2. 症狀 <72 小時 → **早期腹腔鏡膽囊切除術**（72 小時內手術預後更好）
3. 高風險患者 → 經皮穿肝膽囊造口術（PC）

**併發症**：

- 膽囊壞死、穿孔
- 膽囊周圍膿腫
- 膽汁性腹膜炎
- 氣性膽囊炎（gangrenous cholecystitis）

#### 慢性膽囊炎

- 反覆急性發作導致膽囊纖維化
- 膽囊壁增厚、萎縮
- **治療**：膽囊切除術

---

### 總膽管結石（Choledocholithiasis）

#### 來源

- 原發性：膽管內形成
- 續發性：膽囊結石掉入（90%）

#### 臨床表徵

- 黃疸（30-50%）
- 膽絞痛
- 膽管炎（Charcot's triad：黃疸 + 發燒 + 右上腹痛）
- 胰臟炎

#### 診斷

- **血液檢查**：膽紅素 ↑、ALP ↑、GGT ↑、AST/ALT ↑
- **影像**：MRCP 首選、ERCP 確診 + 治療
- **術中膽道攝影（IOC）**：膽道評估

#### 治療

| 方法 | 適應症 |
|------|--------|
| **ERCP + 括約肌切開術** | 已知總膽管結石 |
| **腹腔鏡膽道探查（Laparoscopic CBDE）** | 單一術式處理膽囊 + 總膽管 |
| **開腹膽道探查** | 開放手術時 |

**CBDE 技術**：

- **經膽囊管途徑**：首選，小結石可沖洗排出
- **膽囊管氣球擴張 + 網籃取石**
- **膽道鏡取石**：直接可視
- **膽道切開術（Choledochotomy）**：必要時

---

### 膽囊功能障礙與 Oddi 括約肌功能障礙

#### 膽囊功能障礙（Biliary Dyskinesia）

- **定義**：膽囊排空功能異常，無結石
- **診斷**：HIDA 掃描膽囊排空分數 <35%
- **治療**：膽囊切除術（90% 症狀改善）

#### Oddi 括約肌功能障礙（Sphincter of Oddi Dysfunction）

- **類型**：I（疼痛 + 黃疸）、II（疼痛 + 其一）、III（僅疼痛）
- **診斷**：ERCP 顯示總膽管擴張、造影劑排泄延遲
- **治療**：內視鏡括約肌切開術

---

### 非結石性膽囊炎（Acalculous Cholecystitis）

#### 危險因素

- ICU 患者、敗血症
- 長期靜脈營養（TPN）
- 嚴重燒傷、創傷
- 多重器官衰竭

#### 病理

- 膽囊充盈、膽汁滯留、缺血

#### 診斷

- 超聲：膽囊壁增厚 >4 mm、周圍液體
- CT：協助排除其他病因
- HIDA：膽囊不顯影

#### 治療

- 廣效抗生素
- **高風險 → PC 造口**
- **穩定患者 → 腹腔鏡膽囊切除術**

### 膽道囊腫（Choledochal Cysts）

#### 分型（Bismuth-Corlette）

| Type | 描述 |
|------|------|
| **I** | 肝外膽道梭狀擴張（最常見，50%） |
| **II** | 肝外膽道憩室 |
| **III** | 十二指腸壁內囊腫（總膽囊） |
| **IVa** | 肝內 + 肝外多發囊腫 |
| **IVb** | 肝外多發囊腫 |
| **V** | Caroli 病（肝內囊腫） |

#### 病因

- 膽胰管共同通道 >1.5 cm → 胰液逆流 → 膽道發炎 → 囊腫

#### 致癌風險

- 膽囊癌風險 ↑20-30 倍
- **治療**：切除囊腫 + 膽道重建（Roux-en-Y hepaticojejunostomy）

---

### 原發性硬化性膽管炎（PSC）

#### 特點

- 肝內外膽管發炎性狹窄
- 進行性 → 二級膽汁性肝硬化

#### 合併症

- **潰傷性結腸炎**（60-70%）
- 甲狀腺炎、腹膜後纖維化

#### 診斷

- **ERCP**：多處狹窄 + 擴張（beading 現象）
- 肝功能：ALP ↑、GGT ↑

#### 治療

| 方法 | 說明 |
|------|------|
| 內科 | 皮質類固醇、Ursodeoxycholic acid（症狀治療） |
| 內視鏡 | 氣球擴張 + 支架（狹窄） |
| 手術 | 肝外膽管切除 + hepaticojejunostomy |
| 肝移植 | 末期肝病（5 年存活 85%） |

#### 併發症

- 膽管癌（10-15% 終身風險）

---

### 膽管狹窄（Bile Duct Strictures）

#### 病因

| 原因 | 說明 |
|------|------|
| **醫源性**（90%） | 膽囊切除術時受傷 |
| 慢性胰臟炎 | 纖維化 |
| 膽管結石 | 慢性發炎 |
| Mirizzi 症候群 | 膽囊結石壓迫總肝管 |

#### 分類（Dineen）

| 等級 | 程度 |
|------|------|
| I | 總膽管/總肝管狹窄，無黃疸 |
| II | 總膽管/總肝管狹窄，輕度黃疸 |
| III | 狹窄達 bifurcation |
| IV | 單側肝管狹窄 |

#### 治療

| 程度 | 治療 |
|------|------|
| 輕度 | 內視鏡氣球擴張/支架 |
| 複雜/持久 | 手術切除 + Roux-en-Y choledochojejunostomy |

## 膽道系統創傷

### 膽囊創傷

- **原因**：穿透傷、腹部手術
- **治療**：膽囊切除術

### 肝外膽管創傷

- **原因**：90% 為醫源性（膽囊切除術）
- **發生率**：0.2%（腹腔鏡膽囊切除術）

#### 膽道損傷機制

- 過度向頭側牵引 → 膽囊管與總膽管對齊 → 誤切
- 電燒熱傷害
- 錯誤結紮/切斷

#### 預防：「安全關鍵視角」（Critical View of Safety）

1. 清除 Calot 三角脂肪組織
2. 分離膽囊下 1/3 與 Cystic plate
3. 確認僅有膽囊管和膽囊动脉進入膽囊

#### 膽道損傷分類（Strasberg）

| Type | 描述 |
|------|------|
| A | 膽囊管或小膽管漏 |
| B | 右肝管結紮 |
| C | 右肝管切斷 + 漏 |
| D | 總膽管/總肝管側壁受傷 |
| E1 | 總膽管離斷（遠端狹窄） |
| E2 | 總膽管離斷（近端狹窄） |

#### 膽道損傷表現

| 時間 | 表現 |
|------|------|
| **術中** | 膽汁漏、膽道攝影異常 |
| **術後** | 膽汁漏（膽囊管殘株）、膽管狹窄、黃疸 |

#### 診斷

- CT：膽汁瘤（biloma）、腹水
- ERCP：定位漏/狹窄位置
- MRCP：完整膽道地圖

#### 治療

| 情況 | 處理 |
|------|------|
| 術中發現 | 立即修復（T 管引流或膽道對膽道/膽道空腸吻合） |
| 術後漏 | PC 引流 + 內視鏡支架 |
| 狹窄 | 氣球擴張 → 支架 → 必要時手術 |
| 複雜/復發 | 手術切除 + hepaticojejunostomy |

## 膽囊腫瘤

### 膽囊癌（Gallbladder Cancer）

#### 流行病學

- 美國：每年約 4,000 例
- 好發：60-70 歲，女性 2-6 倍
- 種族差異：美洲原住民、墨西哥裔、智利人較高

#### 危險因素

| 因素 | 風險 |
|------|------|
| 膽結石 | 85% 患者有結石；<3% 結石患者會得癌 |
| 膽囊息肉 >10 mm | 25% 惡性風險 |
| 陶瓷膽囊（Porcelain） | ~10% 膽囊癌風險（傳統認為絕對適應症，現認為可觀察） |
| 膽囊腺瘤 | 癌前病變 |
| PSC、膽道囊腫 | 膽道癌風險 ↑ |

#### 病理

- **腺癌**（80-90%）：乳頭狀、結節型、浸潤型
- 鱗狀細胞癌、未分化癌（罕見）

#### 轉移途徑

- **直接侵犯**：肝臟（IVb、V 段）
- **淋巴**：cystic node → pericholedochal → portal → celiac
- **靜脈**：肝臟

#### TNM 分期

| 分期 | 描述 |
|------|------|
| T1a | 黏膜層 |
| T1b | 肌肉層 |
| T2 | 漿膜下層 |
| T3 | 穿透漿膜或侵犯肝臟 <2 cm |
| T4 | 肝臟 >2 cm 或其他器官 |

#### 治療

| 分期 | 手術 |
|------|------|
| **T1a** | 單純膽囊切除術（5 年存活 85-100%） |
| **T1b-T2** | 擴大膽囊切除術（肝 IVb/V 段切除 + 淋巴結清掃） |
| **T3-T4** | 擴大右肝切除 + 淋巴結清掃 |
| **無法切除** | 化學治療、放射治療、支架（減黃） |

#### 預後

- 整體 5 年存活 <5%，中位存活 6 個月
- T1a 單純膽囊切除：85-100%
- T2 擴大切除：>70%

### 膽管癌（Cholangiocarcinoma）

#### 流行病學

- 美國：每年 2,500 例/10 萬人
- 好發：50-70 歲，男 > 女

#### 分型

| 位置 | 比例 |
|------|------|
| **肝門部（Klatskin 瘤）** | 50%（總肝管分叉） |
| **遠端** | 40% |
| **肝內** | 10% |

#### 分型（Bismuth-Corlette for Klatskin 瘤）

| Type | 範圍 |
|------|------|
| I | 總肝管 |
| II | 侵犯 bifurcation |
| IIIa/IIIb | 延伸至右/左二級肝管 |
| IV | 雙側二級肝管 |

#### 危險因素

- 膽道囊腫、潰傷性結腸炎、肝結石
- PSC（5-10% 終身風險）
- B/C 型肝炎、肝硬化
- 肝吸蟲感染

#### 臨床表徵

- **無痛性黃疸**（最常見）
- 搔癢、體重減輕、右上腹痛
- 膽管炎（10%）

#### 腫瘤標記

- **CA 19-9**：敏感性 79%、特異性 98%（>129 U/mL）

#### 治療

| 腫瘤位置 | 手術方式 |
|----------|----------|
| **遠端** | 胰十二指腸切除（Whipple） |
| **肝門部 I/II** | 局部切除 + 淋巴結清掃 + 膽道重建 |
| **肝門部 III** | 半肝切除（侵犯側） |
| **肝門部 IV/無法切除** | 肝移植（嚴格條件）、支架、化療 |

#### 化學治療

- 無法切除：Gemcitabine + Cisplatin（反應率 10-20%）
- 膽道引流：ERCP 金屬支架

#### 預後

| 類型 | 中位存活 | 5 年存活 |
|------|----------|---------|
| 肝門部 | 5-8 個月 | 10-30% |
| 遠端 | 32-38 個月 | 30-50% |

## 膽囊切除術要點

### 適應症

- 有症狀膽結石
- 膽囊炎（急/慢性）
- 膽囊息肉 >10 mm
- 膽囊癌（疑似）
- 膽囊功能障礙
- 外傷

### 腹腔鏡膽囊切除術步驟

1. 建立氣腹（CO₂）
2. 4 孔法（劍突下、臍上、右肋下 ×2）
3. 確認 Calot 三角 → 分離膽囊管、膽囊动脉 → 夾閉切斷
4. 從肝臟剝離膽囊（電燒/超聲刀）
5. 膽囊取出（袋）
6. 止血、沖洗、縫合

### 膽囊三角重要解剖

- **Calot 三角**：膽囊管、肝總管、膽囊动脉形成的三角
- **安全原則**：「單一管道」原則（最後只切斷 2 個結構）

### 膽道受傷預防

- **30° 角內視鏡**（優於 0°）
- **術中膽道攝影（IOC）**：可減少 50% 膽道損傷
- **關鍵安全視角（Critical View of Safety）**
- **熒光膽道攝影（ICG 螢光）**：新技術

### 轉換開腹的時機

- 嚴重炎症黏連
- 解剖變異
- 出血
- 疑似膽道損傷

## 膽道引流與支架

### 經皮穿肝膽道引流（PTBD）

- **適應症**：近端膽道阻塞、ERCP 失敗/禁忌
- **用途**：減黃、膿膽管炎

### ERCP 支架

| 類型 | 適應症 |
|------|--------|
| **塑膠支架** | 短期（3-6 個月）/ 姑息 |
| **金屬支架** | 惡性狹窄（可撐開式 SEMS） |

## 重點速記表

| 疾病 | 關鍵特點 |
|------|----------|
| **急性膽囊炎** | Murphy's sign（+）、發燒、白血球 ↑、超聲壁增厚 |
| **總膽管結石** | 黃疸 + ALP ↑ + ERCP 確診 + 治療 |
| **膽道囊腫** | 分型 I-V，癌變風險，治療：切除 + 重建 |
| **PSC** | 膽道狹窄 + 潰傷性結腸炎 → 肝移植 |
| **膽囊癌** | T1a 單純切除，T2 以上擴大切除 |
| **膽管癌** | 無痛性黃疸 + CA19-9 ↑，位置決定術式 |
| **膽道損傷** | 預防：Critical View of Safety，治療：視損傷程度 |
