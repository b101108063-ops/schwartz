# CH33 胰臟

---

## 解剖與生理學

### 胰臟結構

- **位置**：腹膜後器官，長 12-15 公分，寬 2-4 公分
- **分區**：頭部（十二指腸 C 彎內）、頸部鉤狀突（uncinate process）、體部、尾部
- **管道系統**：Wirsung 管（主胰管）+ Santorini 管（副胰管）

### 內分泌功能

| 細胞類型 | 激素 | 功能 |
|----------|------|------|
| **β 細胞** | 胰島素 | 血糖 ↓ |
| **α 細胞** | 昇糖素 | 血糖 ↑ |
| **δ 細胞** | 體抑素（somatostatin） | 抑制胰島素、昇糖素分泌 |
| **PP 細胞** | 胰多胜肽（PP） | 抑制胰臟外分泌 |
| **ε 細胞** | 飢餓激素（ghrelin） | 食欲調節 |

### 外分泌功能

- **每日分泌量**：1,500-3,000 mL
- **消化酶**：胰蛋白酶（trypsin）、澱粉酶（amylase）、脂肪酶（lipase）
- **碳酸氫鹽**：中和胃酸

### 胰液分泌調節

| 刺激物 | 作用 |
|--------|------|
| **CCK** | 膽囊收縮 + 胰液分泌 ↑ |
| **分泌素（secretin）** | 碳酸氫鹽分泌 ↑ |
| **膽鹽** | 胰液分泌 ↑ |
| **迷走神經** | 基礎分泌 ↑ |

## 急性胰臟炎（Acute Pancreatitis）

### 病因分類

| 病因 | 比例 |
|------|------|
| **膽結石** | 40% |
| **酒精** | 30% |
| **特發性** | 15-25% |
| 其他 | 藥物、創傷、高血脂、高血鈣、感染、自體免疫 |

### 發病機制

- **共同通道理論**：膽結石 → Vater 壺腹阻塞 → 膽汁逆流 → 胰管活化
- **胰蛋白酶原活化**：胰蛋白酶原在腺泡細胞內被異常活化
- **酒精**：直接毒性 + 出口阻塞
- **游離脂肪酸**：中性脂肪分解後毒性

### 嚴重程度分類（Atlanta Classification 2012）

| 分類 | 標準 |
|------|------|
| **輕度** | 無器官衰竭、無局部併發症 |
| **中度** | 短暫性器官衰竭（<48 h）、局部併發症 |
| **重度** | 持續性器官衰竭（>48 h） |

### 嚴重度評估

| 評分系統 | 項目 |
|----------|------|
| **Ranson 標準** | 入院時（年齡、WBC、血糖、LDH、AST）+ 48 h（血球比容 ↓、BUN ↑、Ca ↓、PaO₂ ↓、鹼缺乏、液體需求） |
| **APACHE II** | >8 分為重症 |
| **BISAP** | BUN >25、系統性發炎反應、年齡 >60、器官衰竭、胸膜滲液 |
| **CT 嚴重程度指數（CTSI）** | 胰臟壞死 + 胰周積液 |

### 局部併發症

| 併發症 | 說明 |
|--------|------|
| **急性胰周積液（APFC）** | 滲出液，無包膜，<4 週 |
| **胰壞死** | 無生活組織（sterile 或 infected） |
| **壞死後囊腫（WOPN）** | 壞死組織被包膜包圍，>4 週 |
| **胰腺假囊腫** | 胰液外漏被纖維/肉芽組織包圍，>4 週 |

### 治療原則

| 嚴重程度 | 治療 |
|----------|------|
| **輕度** | NPO、靜脈輸液、疼痛控制、監測 |
| **中/重度** | ICU、加護監測、液體復甦、營養支持（鼻胃管或鼻空腸管餵食）、抗生素（壞死懷疑感染時） |

### 壞死感染處理

- **無症狀 sterile 壞死**：保守治療
- **疑似感染**：細針抽吸（FNA）培養
- **確診感染**：抗生素 + 延遲手術（延後 4 週以上讓壞死組織成熟）
- **微創手術**：經皮穿肝引流 → 微創壞死切除（step-up approach）

### 膽結石相關急性胰臟炎

- **膽囊切除時機**：
  - 輕度膽囊炎：入院時或出院後 2 週內（72 小時內最佳）
  - 膽道炎或黃疸：ERCP + 膽囊切除

## 慢性胰臟炎（Chronic Pancreatitis）

### 病因

| 病因 | 說明 |
|------|------|
| **酒精** | 70-80%（劑量相關） |
| **吸菸** | 獨立危險因子 |
| **遺傳** | PRSS1、SPINK1、CFTR 突變 |
| **自體免疫** | IgG4 相關胰臟炎 |
| **熱帶性胰臟炎** | 營養不良相關（亞洲） |
| **胰管阻塞** | 創傷、囊腫、腫瘤 |
| **特發性** | 30% |

### 病理變化

- 進行性腺泡萎縮
- 纖維化（stellate cells 活化）
- 胰管狹窄 + 結石（碳酸鈣結石）
- 胰島細胞破壞

### 臨床表現

| 症狀 | 說明 |
|------|------|
| **腹痛** | 主要症狀（85%），飯後/夜間加重 |
| **脂肪瀉** | 脂肪酶分泌不足（晚期） |
| **體重減輕** | 飲食恐懼 + 吸收不良 |
| **糖尿病** | β 細胞破壞（40-60%） |
| **黃疸** | 頭部慢性發炎 → 膽管狹窄 |

### 診斷

| 檢查 | 目的 |
|------|------|
| **腹部 X 光** | 胰管結石（30-50%） |
| **超聲** | 囊腫、結石 |
| **CT/MRI** | 胰管擴張、萎縮、結石 |
| **ERCP** | 胰管狹窄、"chain of lakes" |
| **EUS** | 細微變化、早期診斷 |

### 治療

| 方法 | 適應症 |
|------|--------|
| **內科** | 禁酒、戒菸、胰酶補充、疼痛控制、血糖管理 |
| **內視鏡** | 胰管狹窄擴張、支架、結石移除（ERCP + 網籃） |
| **手術** | 保守治療失敗、難控制疼痛、併發症 |

### 胰管減壓手術

| 手術 | 原理 |
|------|------|
| **Puestow（側側胰空腸吻合）** | 縱向切開胰管 → Roux-en-Y 空腸 |
| **Frey 手術** | Puestow + 胰頭局部切除（適用於頭部有腫塊） |
| **Beger 手術** | 胰頭切除 + 保留十二指腸 |

### 胰切除手術

| 手術 | 範圍 | 適用 |
|------|------|------|
| **Whipple** | 胰頭 + 十二指腸 | 頭部病變 |
| **遠端胰切除** | 體尾部 | 尾部病變 |
| **全胰切除** | 整個胰臟 | 瀰漫性疾病（末期） |

## 胰臟囊腫與囊腫性腫瘤

### 囊腫分類

| 類型 | 惡性風險 | 特點 |
|------|----------|------|
| **假囊腫** | 無 | 胰管受損、急性胰臟炎後 |
| **漿液性囊腺瘤（SCN）** | <1% | 微囊腫、中央疤痕 |
| **黏液性囊腺瘤（MCN）** | 高（6-36%） | 卵巢型間質、好發女性體尾部 |
| **IPMN** | 中-高（主胰管型 62%） | 乳頭狀增生、黏液分泌 |
| **實性假乳頭狀瘤（SPT）** | 低但可轉移 | 年輕女性、實心 + 囊性 |

### IPMN 分型

| 分型 | 位置 | 惡性風險 |
|------|------|----------|
| **主胰管型（MD-IPMN）** | 整條胰管 | 62% |
| **分支胰管型（BD-IPMN）** | 分支導管 | 18%（年惡性率 2-3%） |
| **混合型** | 兩者皆有 | 中等 |

### 囊腫處理原則

| 囊腫大小 | 建議 |
|----------|------|
| **<1 cm** | MRI 監測，2-3 年後延長間隔 |
| **1-2 cm** | MRI 每年，若穩定可延長 |
| **2-3 cm** | EUS ± FNA，縮短期監測 |
| **>3 cm** | 手術評估（BD-IPMN） |

### 高風險特徵（的手術適應症）

- 黃疸（胰頭囊腫）
- 囊內有固體結節
- 主胰管 >10 mm
- 細胞學陽性
- 快速增大

## 胰臟神經內分泌腫瘤（pNET）

### 功能性 pNET

| 腫瘤 | 激素 | 症狀 | 治療 |
|------|------|------|------|
| **胰島素瘤** | 胰島素 | 低血糖（Whipple 三聯症） | 手術切除 |
| **胃泌素瘤** | gastrin | Zollinger-Ellison 症（胃酸 ↑、潰痬、腹瀉） | 質子泵抑制劑 + 手術/化療 |
| **VIPoma** | VIP | WDHA（腹瀉、低血鉀、無胃酸） | 手術、化療 |
| **體抑素瘤** | somatostatin | 膽結石、糖尿病、脂肪瀉 | 手術 |

### 非功能性 pNET

- 最常見（90%）
- 發現時常已轉移
- 症狀：疼痛、黃疸、體重減輕

### 治療原則

| 分期 | 治療 |
|------|------|
| **原發可切除** | 手術切除（胰十二指腸切除/遠端胰切除） |
| **局部晚期** | 手術 ± 術後化療 |
| **轉移** | 減積手術（症狀控制）、荷爾蒙治療（octreotide）、標靶藥物（everolimus、sunitinib）、化療 |

## 胰臟癌（PDAC）

### 流行病學

- 美國：每年確診 53,670 例、死亡 43,090 例
- **5 年存活率**：7.2%（最差）
- 第三大癌症死因
- 好發：60-70 歲，男稍多

### 危險因子

| 因子 | 風險 |
|------|------|
| **吸菸** | 2-3 倍 |
| **家族史** | 2 倍（一親等） |
| **遺傳性胰臟炎** | 20 倍 |
| **慢性胰臟炎** | 5-15 倍 |
| **糖尿病** | 2 倍（新發糖尿病可能是早期症狀） |
| **肥胖** | 增加 |
| **種族** | 非裔美人較高 |

### 基因突變

| 基因 | 頻率 |
|------|------|
| **KRAS** | 90% |
| **p16/CDKN2A** | 80-95% |
| **TP53** | 50-75% |
| **SMAD4/DPC4** | 55% |
| **BRCA2** | 少數家族性 |

### 病理分類

| 類型 | 說明 |
|------|------|
| **腺癌（90%）** | 最常見 |
| **黏液腺癌** | 預後稍好 |
| **腺鱗癌** | 預後差 |
| **未分化癌** | 高度惡性 |

### TNM 分期（AJCC 2017）

| 分期 | T | N | M |
|------|----|----|----|
| **IA** | T1（≤2 cm） | N0 | M0 |
| **IB** | T2（2-4 cm） | N0 | M0 |
| **IIA** | T3（>4 cm） | N0 | M0 |
| **IIB** | 任何 T | N1（1-3 淋巴結） | M0 |
| **III** | T4（侵犯主要血管）或 N2（≥4 淋巴結） | 任何 N | M0 |
| **IV** | 任何 T | 任何 N | M1 |

### 臨床表現

| 症狀 | 頻率 |
|------|------|
| **體重減輕** | 最常見 |
| **黃疸** | 頭部癌 50-80% |
| **上腹痛** | 常見，可放射至背部 |
| **疼痛** | 晚期（神經侵犯） |
| **新發糖尿病** | 可能是早期表現 |

### 診斷

| 檢查 | 用途 |
|------|------|
| **腹部超聲** | 初步篩檢 |
| **CT（四期造影）** | 分期首選（敏感性 >90%） |
| **MRI/MRCP** | 膽胰管評估 |
| **ERCP** | 膽管阻塞診斷 + 支架 |
| **EUS + FNA** | 小腫瘤確診、淋巴結分期 |
| **CA19-9** | 輔助診斷、術後追蹤（非篩檢） |

### 可切除性評估

| 分期 | 標準 |
|------|------|
| **可切除** | 無血管侵犯、邊界清楚 |
| **邊緣可切除（borderline）** | SMA/celiac abutment ≤180°、短段靜脈阻塞、可切除的肝轉移（單一） |
| **無法切除** | SMA >180°、celiac 侵犯、遠處轉移 |

### 手術治療

#### 胰十二指腸切除術（Whipple Procedure）

**適應症**：胰頭癌、壺腹癌、膽管癌

**手術步驟**：

1. 評估可切除性（腹腔探查）
2. 膽囊切除 + 膽管分離
3. 胃竇或幽門保存
4. 胰頸分離
5. 胰鉤狀突切除（從 SMV/PV 游離）
6. 胃/十二指腸切除
7. **重建**：胰空腸吻合（pancreaticojejunostomy）→ 膽管空腸吻合 → 胃空腸吻合

#### 遠端胰切除術

- **適應症**：體尾部癌
- **常合併脾切除**（淋巴結清掃）

#### 靜脈切除重建

- 侵犯 SMV/PV 但可切除時 → 靜脈切除 + 重建
- 成效在高容量中心可接受

### 化學治療

| 情境 | 方案 |
|------|------|
| **輔助治療** | Gemcitabine 或 5-FU + 放療 |
| **轉移性** | FOLFIRINOX（較有效但毒性高）或 Gemcitabine + nab-paclitaxel |
| **局部晚期** | 化療 + 立體定位放療（SBRT） |

### 標靶/免疫治療

| 藥物 | 機制 |
|------|------|
| **Erlotinib** | EGFR 抑制劑（些微效益） |
| **Everolimus** | mTOR 抑制劑（pNET） |
| **Sunitinib** | VEGF 抑制劑（pNET） |

### 緩和治療

| 方法 | 適應症 |
|------|--------|
| **ERCP 支架** | 膽管阻塞（塑膠支架短期、金屬支架長期） |
| **胃空腸吻合** | 十二指腸阻塞 |
| **疼痛控制** | 口服嗎啡、celiac plexus 阻斷 |

## 胰臟手術併發症

### 胰十二指腸切除術後

| 併發症 | 發生率 | 處理 |
|--------|--------|------|
| **胰汁漏** | 10% | 引流、保守治療（95% 自癒）、必要時手術 |
| **膽汁漏** | 5% | 引流、支架 |
| **胃排空延遲** | 常見 | 保守治療、紅黴素 |
| **出血** | 2-5% | 輸血、血管栓塞、必要時手術 |

- **胰汁漏**：5-10%
- **脾膿腫**（保留脾臟時）

## 胰臟移植

### 全胰移植

- **適應症**：第一型糖尿病 + 嚴重低血糖、無法控制
- **胰島素依賴**：可免除（但有手術風險）

### 胰島細胞移植

- **適應症**：第一型糖尿病 + 低血糖感知受損
- **成效**：部分案例可免除胰島素多年
