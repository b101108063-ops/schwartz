# CH29 結腸、直腸與肛門
## Colon, Rectum, and Anus

---

## 手術前置準備 (Operative Preliminaries)

### 機械性腸道準備

- **目的**：減少術後感染
- **常用製劑**：PEG 溶液、檸檬酸鎂

PEG 溶液需大量飲用，可能腹脹噁心。檸檬酸鎂耐受性較好，但可能電解質異常。近期引入口服製劑（40+ 顆）但未證實優於傳統製劑。

- **抗生素預防**：口服抗生素 + 機械準備可減少手術部位感染

### 抗生素預防

- 手術前立即給予廣效靜脈抗生素（需對腸道菌有效）
- 覆蓋厭氧與兼氧菌
- 複雜骨盆手術可能需泌尿科、婦科腫瘤科、神經外科、整型外科會診

## 發炎性腸道疾病 (Inflammatory Bowel Disease)

### 流行病學

| 疾病 | 發生率（每 10 萬人） | 高峰年齡 | 遺傳關聯 |
|------|-------------------|---------|---------|
| 潰傷性結腸炎 | 8-15 | 20-30 歲、60-70 歲 | 較弱 |
| 克隆氏症 | 1-5 | 15-30 歲、60-70 歲 | 較強 |

- 15% 無法區分兩者 → **未定型結腸炎**
- 家族傾向：10-30% 患者有家族史
- 同卵雙胞胎 50% 一致率，異卵 10%

### 病因學

- **多因素疾病**：環境 + 遺傳 + 免疫

**環境因素**：飲食、微生物暴露、酒精、煙草。

**遺傳因素**：polygenic，多基因參與。

| 基因 | 染色體位置 | 功能 |
|------|-----------|------|
| **NOD2** | 第 16 對 | 最強關聯，協調細胞激素產生 |
| **ATG16L1** | 第 2 對 | 對 muramyl dipeptide 免疫反應 |
| **IRGM** | 第 5 對 | 干擾素-γ 清除細胞內病原體 |

- **免疫失調**：腸道微生物引發病理性免疫反應

### 病理與鑑別診斷

#### 潰傷性結腸炎 (Ulcerative Colitis)

- **範圍**：黏膜層浸潤，結腸和直腸
- **特徵**：
  - 黏膜下層浸潤
  - Crypt abscesses 常見
  - 黏膜脆弱、多發炎性假息肉
  - 長期：結腸縮短，疤痕取代黏膜
  - **連續性**侵犯，**不侵犯小腸**（backwash ileitis 例外）

分布依範圍遞增：直腸炎 → 直腸乙狀結腸炎 → 左側結腸炎 → 全結腸炎。診斷依靠結腸鏡 + 黏膜切片。

#### 克隆氏症 (Crohn's Disease)

- **範圍**：**全層**侵犯，口腔到肛門
- **特徵**：
  - 黏膜潰瘍
  - 發炎細胞浸潤
  - **非乾酪性肉芽腫（noncaseating granulomas）**
  - 內視鏡：深層匍行潰爛、鵝卵石外觀
  - **跳躍式病變（Skip lesions）**、直腸保留

- **併發症**：纖維化、狹窄、瘻管
- **診斷**：結腸鏡 + 切片

| 特色 | 潰傷性結腸炎 | 克隆氏症 |
|------|------------|---------|
| 侵犯深度 | 黏膜/黏膜下層 | **全層** |
| 分布 | 連續性 | **跳躍式病變** |
| 直腸侵犯 | 常見 | 常見**保留** |
| 肉芽腫 | 無 | **有** |
| 瘻管/狹窄 | 少 | **常見** |
| 糞便特性 | 血性腹瀉 | 水性腹瀉 |

### IBD 治療

#### 5-ASA 製劑

- **Mesalamine**：輕中度潰傷性結腸炎維持治療
- **Sulfasalazine**：潰傷性結腸炎 / 脊椎關節病變

#### 皮質類固醇

- **Budesonide**：侷限於迴腸/右側結腸病變
- **Systemic steroids**：中重度急性發作

#### 免疫調節劑

| 藥物 | 適應症 | 監測 |
|------|--------|------|
| **Azathioprine/6-MP** | 類固醇依賴/減量 | WBC、肝毒性 |
| **Methotrexate** | 類固醇無效之克隆氏症 | CBC、肝功能 |
| **Cyclosporine** | 嚴重潰傷性結腸炎靜脈注射 | 血中濃度、腎毒性 |

#### 生物製劑

| 藥物 | 靶點 | 適應症 |
|------|------|--------|
| **Infliximab** | Anti-TNFα | 中重度克隆氏症/潰傷性結腸炎、瘻管型克隆氏症 |
| **Adalimumab** | Anti-TNFα | 克隆氏症、潰傷性結腸炎 |
| **Ustekinumab** | Anti-IL-12/23 | 克隆氏症 |

#### 手術治療

- **潰傷性結腸炎**：直腸結腸切除 + IPAA（恢復連續性）或 end ileostomy
- **克隆氏症**：分段切除，避免廣泛切除（復發率高）

## 憩室疾病 (Diverticular Disease)

### 流行病學

- 西方國家 40-60 歲 30-40% 有憩室症
- 僅 10-25% 有症狀，10-25% 發展為憩室炎
- 右側憩室：年輕人、亞洲人較常見

### 病理生理學

- **假性憩室（False diverticula）**：黏膜/黏膜下層穿過肌肉層
- 腸壁肌肉增厚 → 腔內壓力增加
- **血管結構**：周圍血管被拉扯 → 出血

### 併發症

#### 急性憩室炎 (Acute Diverticulitis)

| Hinchey 分級 | 描述 | 治療 |
|------------|------|------|
| I | 結腸旁膿瘺 | 抗生素、引流 |
| II | 骨盆腔/後腹腔膿瘺 | CT 引導引流 |
| III | 化膿性腹膜炎 | 手術 |
| IV | 糞便性腹膜炎 | 手術 |

- **CT 表現**：結腸壁增厚、結腸旁脂肪條紋
- **CT 引導引流**：大膿瘺（>2 cm）
- **手術**：Hartmann's procedure 或 primary anastomosis + diversion

#### 出血 (Hemorrhage)

- 5% 憩室患者
- 老年人常見
- 80% 自發停止
- **治療**：結腸鏡注射/電燒、血管造影、手術

#### 瘻管 (Fistulas)

- **Colovesical** 最常見（65%）
- 其次：colovaginal、coloenteric、colocutaneous
- **治療**：切除受影響腸段 + primary anastomosis

### 手術時機

- 傳統：第二次發作後建議 elective colectomy
- 近期資料：復發並不增加併發症風險
- **免疫抑制患者**：單次發作後即建議手術
- **年輕患者**：仍有爭議

## 結腸直腸腺癌與息肉 (Adenocarcinoma and Polyps)

### 流行病學

- 美國每年新確診 >130,000 例
- 第三大癌症死因
- 50 歲後發生率上升
- 90% 確診時 >50 歲

### 風險因素

#### 環境/飲食因素

| 風險增加 | 保護因子 |
|---------|---------|
| 高脂肪飲食 | 高纖維飲食 |
| 肥胖 | 蔬菜 |
| 酒精攝取 | 鈣、硒、維生素 A/C/E |
| 吸菸 | Oleic acid（橄欖油） |

#### 遺傳疾病

| 疾病 | 基因 | 特徵 |
|------|------|------|
| **FAP** | APC（第 5 對） | >100 息肉、100% 癌症風險 |
| **AFAP** | APC、MYH | 10-100 息肉、右側結腸 |
| **Lynch（HNPCC）** | MMR genes | 右側結腸、早發 |
| **MYH-associated** | MYH | 自體隱性遺傳、AFAP 表現型 |

### 發病機制：腺瘤-癌序列 (Adenoma-Carcinoma Sequence)

```
Normal → APC mutation → Early adenoma → K-ras → Intermediate adenoma → DCC/p53 loss → Late adenoma → Carcinoma → Metastasis
```

| 基因變化 | 角色 |
|---------|------|
| **APC** | 腫瘤抑制基因（起始） |
| **K-ras** | 原致癌基因（生長訊號） |
| **DCC** | 腫瘤抑制基因（黏附） |
| **p53** | 腫瘤抑制基因（凋亡） |

### 三大基因途徑

| 途徑 | 特徵 | 比例 |
|------|------|------|
| **LOH（染色體不穩定）** | 非整倍體、染色體刪失 | 80% |
| **MSI（微衛星不穩定）** | 錯配修復缺陷 | 10-15% |
| **CIMP（CpG 島甲基化）** | 鋸齒狀息肉途徑 | 10-15% |

### 息肉分類

| 類型 | 惡性風險 | 治療 |
|------|---------|------|
| **增生性息肉** | 極低（>2 cm 則升高） | 觀察 |
| **腺瘤性息肉** | 5-40%（依類型大小） | 切除 |
| **鋸齒狀息肉** | 中等 | 切除 |
| **錯構瘤性** | 低（除 FAP 相關） | 視症狀 |

### 息肉大小與惡性風險

| 大小 | 侵入性癌風險 |
|------|-------------|
| <1 cm | <1% |
| 1-2 cm | 10% |
| >2 cm | 35-50% |

### 篩檢策略

| 篩檢方法 | 優點 | 缺點 |
|---------|------|------|
| **FOBT/FIT** | 非侵入、便宜 | 敏感性低 |
| **Flex sig** | 敏感性高 | 僅左側結腸 |
| **Colonoscopy** | 完整、最敏感 | 侵入性、需準備 |
| **CT colonography** | 非侵入 | 小息肉敏感性低 |

| 族群 | 起始年齡 | 間隔 |
|------|---------|------|
| 一般風險 | 50 歲 | 10 年 colonoscopy 或每年 FOBT |
| FAP | 10-12 歲 | 年度 flex sig |
| Lynch | 20-25 歲 | 1-2 年 colonoscopy |
| 家族性大腸癌 | 40 歲或最早的發病年齡-10 年 | 5 年 |

### TNM 分期（AJCC 第 8 版）

| Stage | T | N | M | 5 年存活 |
|-------|---|---|---|---------|
| I | T1-2 | N0 | M0 | >90% |
| IIA | T3 | N0 | M0 | 80-85% |
| IIB | T4a | N0 | M0 | 70-75% |
| IIC | T4b | N0 | M0 | 55-60% |
| IIIA | T1-2 | N1 | M0 | 70-80% |
| IIIB | T3-4a | N1 | M0 | 50-65% |
| IIIC | any T | N2 | M0 | 30-45% |
| IVA | any | any | M1a | <20% |
| IVB | any | any | M1b | <10% |

### 治療原則

#### 結腸癌

- **切除範圍**：切除腫瘤 + 淋巴引流區域
- **淋巴結數目**：至少 12 個（quality indicator）

| 分期 | 治療 |
|------|------|
| **Stage 0-I** | 僅手術 |
| **Stage II** | 高風險因子 → 考慮化療 |
| **Stage III** | 輔助化療（5-FU-based ± oxaliplatin） |
| **Stage IV** | 化療為主、切除轉移（肝/肺） |

#### 直腸癌

| 特點 | 挑戰 |
|------|------|
| 骨盆解剖限制 | 難以達到陰性放射狀邊緣 |
| 臨近重要結構 | 需要多專科團隊 |
| TME 原則 | 全直腸繫膜切除 |

##### 直腸癌特殊考量

| 分期 | 治療 |
|------|------|
| T1N0 | 局部切除（理想條件：<3 cm、分化好） |
| T2N0 | 根治切除或新輔助化放療 |
| T3-4 或 N+ | **新輔助化放療 + TME** |

- **化放療**：5-FU + 30-50.4 Gy，術後 6-8 週執行
- **TME**：銳利解剖，減少局部復發
- **APR**：低位直腸腫瘤需切除肛門括約肌時執行

### 化學治療

| 藥物組合 | 用途 |
|---------|------|
| **5-FU/Leucovorin** | Stage III 輔助化療 |
| **FOLFOX** | 轉移性或 Stage III 輔助化療 |
| **FOLFIRI** | 轉移性疾病 |
| **Anti-EGFR（Cetuximab）** | KRAS wild-type |
| **Anti-VEGF（Bevacizumab）** | 轉移性疾病 |

## 其他結腸直腸腫瘤

### 類癌（Carcinoid）

| 位置 | 預後 | 治療 |
|------|------|------|
| 直腸 | 佳（80% 存活） | 局部切除（<1 cm） |
| 結腸 | 較差 | 根治切除 |

### 胃腸道間質瘤 (GIST)

- 5-10% 發生於結腸直腸
- **CD117（KIT）positive**
- **治療**：Imatinib（tyrosine kinase inhibitor）

### 淋巴瘤

- 原發性胃腸道淋巴瘤少見
- **治療**：手術切除 ± 化療

### 黑色素瘤 (Melanoma)

- 預後極差（5 年 <10%）
- **治療**：廣泛局部切除（APR 不優於局部切除）

## 良性結腸直腸疾病

### 直腸脫垂 (Rectal Prolapse)

| 類型 | 描述 |
|------|------|
| Mucosal | 部分厚度、與內痔相關 |
| Full-thickness | 完全脫垂、procidentia |
| Internal | 內部腸套疊 |

**治療選擇**：

- **腹部手術**：rectopexy ± sigmoid resection
- **會陰手術**：Altemeier、Delorme
- **Ventral rectopexy**：微創、腹腔鏡

### 腸扭轉 (Volvulus)

| 類型 | 扭轉部位 | 治療 |
|------|---------|------|
| Sigmoid | 乙狀結腸 | 內視鏡減壓 → 選擇性切除 |
| Cecal | 盲腸 | 手術（右半結腸切除） |
| Transverse | 橫結腸 | 手術 |

### 偽性阻塞 (Ogilvie's Syndrome)

- 無機械性阻塞之結腸擴張
- **治療**：
  - 停止麻醉藥物/抗膽鹼藥物
  - Neostigmine（2 mg IV）：80% 有效
  - 結腸鏡減壓

### 缺血性結腸炎 (Ischemic Colitis)

| 特點 | 說明 |
|------|------|
| 最常見部位 | 脾彎 |
| 病因 | 低血流、小血管疾病 |
| 診斷 | CT、結腸鏡 |
| 治療 | 80% 保守治療成功 |

**後遺症**：

- 狹窄（10-15%）
- 慢性節段性缺血（15-20%）

### 困難梭菌結腸炎 (C. difficile Colitis)

| 嚴重程度 | 治療 |
|---------|------|
| 輕度 | Metronidazole PO |
| 重度 | Vancomycin PO |
| 猛爆性 | Vancomycin + IV Flagyl + 手術 |

## 肛門疾病

### 痔瘡 (Hemorrhoids)

| 分級 | 描述 | 治療 |
|------|------|------|
| I | 突起不脫垂 | 保守治療 |
| II | 脫垂但自動回縮 | 橡皮筋結紮 |
| III | 脫垂需手動復位 | 橡皮筋結紮/注射療法 |
| IV | 無法復位/嵌頓 | 痔瘡切除術 |

**治療選項**：

| 方法 | 適應症 | 併發症 |
|------|--------|-------|
| **Rubber band ligation** | I-III 度 | 疼痛、出血、感染 |
| **Sclerotherapy** | I-II 度 | 感染、纖維化 |
| **Infrared photocoagulation** | 小病灶 | 復發 |
| **Hemorrhoidectomy** | III-IV 度、混合型 | 疼痛、尿滯留、出血 |
| **PPH（Stapled）** | II-III 度 | 慢性疼痛、狹窄 |

### 肛裂 (Anal Fissure)

| 類型 | 治療 |
|------|------|
| 急性 | 保守治療（纖維軟便劑、坐浴） |
| 慢性 | **內側括約肌切斷術（Lateral internal sphincterotomy）** |

### 膿瘺與瘻管 (Abscess and Fistula)

| 膿瘺類型 | 治療 |
|---------|------|
| Perianal | 門診引流 |
| Ischiorectal | 手術室引流 |
| Intersphincteric | 檢查麻醉下引流 |
| Supralevator | 依來源決定（經直腸或經臀部） |

**瘻管分類**：

| 類型 | 位置 | 手術 |
|------|------|------|
| Intersphincteric | 內外括約肌間 | Fistulotomy |
| Transsphincteric | 穿越外括約肌 | Seton ± sphincterotomy |
| Suprasphincteric | 繞過外括約肌 | Seton |
| Extrasphincteric | 從直腸繞過 | 經腹手術 |

### 肛門瘙癢 (Pruritus Ani)

- **原因**：感染（HPV、皰疹、念珠菌）、皮膚炎、衛生問題
- **治療**：去除刺激物、hydrocortisone、肌膚屏障

## 創傷

### 結腸創傷

| 因素 | 考量 |
|------|------|
| 穿通傷 | 優先縫合 vs. 造口 |
| 鈍傷 | 少見但可能發生 |
| 高風險 | >6 小時、多重器官損傷、污染 |

### 直腸創傷

| 原則 | 說明 |
|------|------|
| 優先修復 | 穩定患者 |
| 轉流 | 槍傷、爆炸傷、高感染風險 |
| 沖洗 | 遠端直腸沖洗 |

## 免疫抑制患者

### HIV 患者

- 伺機性感染（CMV、HSV、Cryptosporidium）
- Kaposi sarcoma、淋巴瘤風險增加
- 肛門上皮內病變（HSIL）發生率高

### 移植患者

- CMV 感染常見
- 困難梭菌結腸炎
- 憩室炎發生率增加

### 中性球減少性結腸炎（Typhlitis）

| 特點 | 說明 |
|------|------|
| 死亡率 | >50% |
| 病因 | 中性球減少 |
| **治療** | 抗生素、NG 吸引、緊急手術 |
