# CH38 甲狀腺、副甲狀腺與腎上腺
## Thyroid, Parathyroid, and Adrenal

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

甲狀腺、副甲狀腺與腎上腺疾病是內分泌外科的核心範疇。本章系統整理甲狀腺結節的評估流程（Bethesda 分類）、甲狀腺機能亢進的手術治療、原發性副甲狀腺機能亢進的手術適應症，以及腎上腺腫瘤的手術原則。重點在於甲狀腺乳頭狀癌的手術範圍決策，以及嗜鉻細胞瘤的術前 α-blockade 準備。

## 甲狀腺 (Thyroid)

### 甲狀腺胚胎學

- 甲狀腺起源於**第三週胚胎前腸**（foramen cecum）
- <span style="color:#60a5fa">甲狀腺濾泡細胞</span>起源於 endoderm（median thyroid anlage）
- **C cells (parafollicular cells)** 起源于 <span style="color:#c084fc">ultimobranchial bodies</span>（第四 branchial pouch），分泌 <span style="color:#fb923c">calcitonin</span>
- 甲狀腺濾泡於第 **<span style="color:#60a5fa">8 週</span>** 出現，膠體形成於第 **<span style="color:#60a5fa">11 週</span>**

### 發育異常

**甲狀腺舌管囊腫（Thyroglossal duct cyst）**：

- 最常見先天性頸部囊腫
- <span style="color:#60a5fa">80%</span> 位於 hyoid bone 附近
- **診斷**：理論上 <span style="color:#34d399">1-2 cm</span> 中線腫塊，舌頭伸出時上升
- **治療**：**Sistrunk operation**（en bloc cystectomy + 中央 hyoid bone 切除）
- 約 <span style="color:#f87171">1%</span> 含癌（85% 為乳頭狀）

**其他發育異常**：

| 異常 | 說明 |
|------|------|
| **Lingual thyroid** | 甲狀腺中線 anlage 未下降；可能為唯一甲狀腺組織；可致阻塞症狀或甲狀腺機能減退 |
| **Pyramidal lobe** | <span style="color:#60a5fa">50%</span> 個體存在；沿甲狀腺峽部向上延伸 |

### 甲狀腺解剖學

| 結構 | 說明 |
|------|------|
| 正常重量 | <span style="color:#34d399">~20 g</span> |
| 位置 | 甲狀腺軟骨兩側，峽部位於 cricoid cartilage 下方 |
| 血液供應 | **<span style="color:#60a5fa">上甲狀腺动脉</span>**（來自 external carotid）；**下甲狀腺动脉**（來自 thyrocervical trunk） |
| 靜脈引流 | 上、中甲狀腺靜脈 → internal jugular vein；下甲狀腺靜脈 → brachiocephalic veins |
| **<span style="color:#22d3ee">喉返神經（RLN）</span>** | 位於氣管食道溝；左側繞 aortic arch，右側繞 subclavian artery |
| RLN 與下甲狀腺动脉關係 | 神經可在动脉前方、後方或分叉間穿過 |
| 喉上神經 external branch | 支配 cricothyroid muscle；受損 → 發聲疲勞、無法發高音 |

- **RLN 損傷**：單側 → vocal cord 麻痺（聲音沙啞、咳嗽無力）；雙側 → 呼吸道阻塞（可能需氣切）
- <span style="color:#22d3ee">甲狀腺</span>與**strap muscles**相鄰；後方為**<span style="color:#22d3ee">Berry's ligament</span>**（甲狀腺韌帶），神經通過此處時易受傷

### 甲狀腺組織學

- 甲狀腺由 20-40 個濾泡組成的小葉構成
- 每個濾泡直徑約 **<span style="color:#60a5fa">30 μm</span>**，由立方上皮細胞圍繞膠體
- 成人甲狀腺約有 **<span style="color:#60a5fa">3 × 10⁶</span>** 個濾泡
- **C cells** 位於甲狀腺上極，分泌 calcitonin

### 甲狀腺生理學

#### 甲狀腺激素合成流程

1. **Iodide trapping**：Na⁺/I⁻ symporter (NIS) 主動運輸
2. **Oxidation**：<span style="color:#60a5fa">甲狀腺 peroxidase (TPO)</span> 將 I⁻ 氧化為 I₂
3. **Organification**：碘附著於甲狀腺球蛋白 (thyroglobulin, Tg) 上的酪氨酸
4. **Coupling**：MIT + DIT → T₃；DIT + DIT → T₄
5. **Hydrolysis**：Tg 水解釋放游離 T₃、T₄
6. **Deiodination**：MIT、DIT 去碘化回收

#### 甲狀腺激素分泌調控

- **TRH（下視丘）→ TSH（腦下垂體）→ 甲狀腺**
- T₃、T₄ 對下視丘/腦下垂體呈**負反饋**
- <span style="color:#60a5fa">80%</span> 的 T₃ 由**週邊組織**（肝、腎、肌肉）T₄ 去碘化產生
- **<span style="color:#60a5fa">T₃ 的效力為 T₄ 的 3-4 倍</span>**

#### 甲狀腺激素功能

| 功能 | 說明 |
|------|------|
| 基礎代謝 | 增加**基礎代謝率**、氧氣消耗、熱產生（刺激 Na⁺/K⁺ ATPase） |
| 心臟 | **正性變時/變力作用**（增加心臟 β-adrenergic receptors） |
| 呼吸 | 維持正常呼吸驅動 |
| 胃腸道 | 增加胃腸道蠕動 |
| 骨骼 | 增加骨骼/蛋白質周轉 |

### 甲狀腺疾病評估

#### 實驗室檢查

| 檢查 | 正常範圍 | 說明 |
|------|----------|------|
| **TSH** | <span style="color:#34d399">0.5-5 μU/mL</span> | 最敏感的甲狀腺功能篩檢 |
| Free T₄ | <span style="color:#34d399">12-28 pmol/L</span> | 游離 T₄，最準確 |
| Free T₃ | <span style="color:#34d399">3-9 pmol/L</span> | 早期甲狀腺機能亢進時最先升高 |
| Tg | — | 甲狀腺癌追蹤指標（術後需測 anti-Tg Ab） |
| Calcitonin | <span style="color:#34d399">0-4 pg/mL</span> | MTC 腫瘤標記 |

- **TRH test**：<span style="color:#60a5fa">500 μg IV</span> 後 30、60 分鐘測 TSH；正常應上升 ≥6 μIU/mL
- **甲狀腺抗體**：anti-Tg、anti-TPO（Hashimoto 甲狀腺炎 <span style="color:#60a5fa">80%</span> 升高）

#### 影像學

| 檢查 | 說明 |
|------|------|
| **甲狀腺掃描（¹²³I/⁹⁹ᵐTc）** | **Cold nodule**（攝取減少）→ 惡性風險較高（<span style="color:#f87171">20%</span>）；Hot/warm nodule → 惡性風險 <span style="color:#34d399"><5%</span> |
| **超音超** | 區分 solid vs cystic、評估淋巴結、導引 FNAB |
| **CT/MRI** | 大型/substernal goiter、評估與氣道/血管關係 |
| **PET-CT** | Tg 陽性但 RAI 陰性之甲狀腺癌追蹤 |

## 甲狀腺良性疾病 (Benign Thyroid Disorders)

### 甲狀腺機能亢進 (Hyperthyroidism)

| 病因 | RAIU | 說明 |
|------|-------|------|
| **<span style="color:#60a5fa">Graves' disease</span>** | ↑ | 最常見（60-80%）；自體免疫；TRab/TSI 陽性 |
| Toxic multinodular goiter | ↑ | 毒性多結節性甲狀腺腫 |
| Toxic adenoma | ↑ | 單一熱結節 |
| Thyroiditis | ↓ | 甲狀腺破壞後釋放激素 |
| Amiodarone-induced | ↑ or ↓ | 藥物引起 |

### Graves' Disease（瀰漫性毒性甲狀腺腫）

#### 臨床特徵

- **甲狀腺毒血症狀**：熱耐受不良、出汗、體重減輕、心悸、神經過敏、顫抖、腹瀉
- **眼部病變（<span style="color:#60a5fa">50%</span>）**：lid lag (von Graefe's sign)、Dalrymple's sign、stare、proptosis、conjunctival chemosis
- **皮膚病變（<span style="color:#60a5fa">1-2%</span>）**：pretibial myxedema（甲狀腺肢端病變）
- 甲狀腺瀰漫性對稱性腫大；可聽到**bruit/thrill**

#### 診斷

- **<span style="color:#60a5fa">Suppressed TSH + elevated free T₄/T₃</span>**
- **¹²³I scan**：瀰漫性攝取增加
- TSI (thyroid-stimulating immunoglobulin) 陽性

#### 治療

| 治療方式 | 說明 |
|----------|------|
| **藥物** | <span style="color:#fb923c">Thionamides</span>（PTU、MMI）— PTU 為孕婦首選（妊娠首三個月） |
| **放射性碘（¹³¹I）** | 禁忌於孕婦/哺乳；術後甲狀腺機能減退 |
| **手術** | 目前趨勢為 **<span style="color:#60a5fa">total/near-total thyroidectomy</span>** 而非 subtotal |

<span style="color:#fbbf24;font-weight:600">Key Point：</span>手術優點是復發率低、無放射性碘治療風險；需注意保護 RLN 和保留上位副甲狀腺。

## 甲狀腺結節 (Solitary Thyroid Nodule)

### 評估流程

1. **TSH**：低 → 掃描確認是否為 hot nodule；高/正常 → 超音超引導 FNAB
2. **超音超**：
   - **Suspicious features**：微鈣化、邊緣不規則、低回音、高 > 寬、淋巴結病變
   - **Bethesda 分類（6 組）**：對應不同惡性風險

### Bethesda System for Thyroid Cytopathology

| 等級 | 診斷 | 惡性風險 |
|------|------|----------|
| I | 無診斷價值 | — |
| II | 良性 | <span style="color:#34d399">0-3%</span> |
| III | AUS/FLUS | <span style="color:#fbbf24">5-15%</span> |
| IV | Follicular neoplasm | <span style="color:#f87171">15-30%</span> |
| V | 可疑惡性 | <span style="color:#f87171">60-75%</span> |
| VI | 惡性 | <span style="color:#f87171">97-99%</span> |

### 處理原則

| 等級 | 處理 |
|------|------|
| Bethesda I | 再次 FNAB |
| Bethesda II | 觀察 |
| Bethesda III/IV | Diagnostic lobectomy（切除患側確認） |
| Bethesda V/VI | Near-total/total thyroidectomy |

### 甲狀腺癌分類與治療

#### 乳頭狀甲狀腺癌（Papillary Thyroid Cancer）

- 最常見（<span style="color:#60a5fa">70-80%</span>）；預後佳
- **確診**：乳頭狀細胞核特徵（grooved、overlapping nuclei、"Orphan Annie" nuclei、intranuclear grooves、pseudoinclusions）
- **NIFTP**：舊稱 follicular variant of papillary carcinoma；預後極佳
- **治療**：Lobectomy 或 total thyroidectomy（低風險）；小的（<1 cm）低風險乳頭狀癌可**active surveillance**
- **RAI（¹³¹I）**：主要用於高風險、甲狀腺全切除術後

#### 濾泡性甲狀腺癌（Follicular Thyroid Cancer）

- 診斷需靠 **vascular/capsular invasion**（FNAB 無法確診）
- **治療**：Total thyroidectomy（因為常見多發病灶）
- 遠處轉移常見（骨、肺）

#### 甲狀腺髓質癌 (MTC)

- 起源自 **C cells**，分泌 **<span style="color:#fb923c">calcitonin</span>**
- **<span style="color:#60a5fa">25%</span> 為家族性**（MEN 2A/2B 症候群）
- **RET proto-oncogene 突變**：MEN 2A (M918T)、MEN 2B (M918T + A883F)
- **治療**：Total thyroidectomy + central neck lymph 結清掃
- **術後追蹤**：Calcitonin doubling time（復發指標）

#### 未分化甲狀腺癌（Anaplastic Thyroid Cancer）

- 極度惡性；預後極差
- 症狀快速進展：呼吸道阻塞、聲音沙啞、頸部腫塊快速增大
- **治療**：儘量手術切除 + 化放療（預後仍差）

### 甲狀腺癌分期（分化型，乳頭狀/濾泡癌）

| 分期 | 標準 |
|------|------|
| **I 期** | <55 歲：任何腫瘤，無遠處轉移；≥55 歲：腫瘤 ≤4 cm，侷限甲狀腺內 |
| **II 期** | <55 歲：遠處轉移；≥55 歲：腫瘤 >4 cm 或輕微甲狀腺外侵犯 |
| **III 期** | ≥55 歲，甲狀腺外侵犯至皮下軟組織、喉、氣管、食道或喉返神經 |
| **IVA 期** | 侵犯至 prevertebral fascia 或 surrounding structures |
| **IVB 期** | 遠處轉移 |

## 甲狀腺手術要點

### 術前準備

- 甲狀腺機能正常（euthyroid）再手術
- 聲帶檢查（間接/直接喉鏡）
- 懷孕：第二孕期手術最安全
- **巨大甲狀腺**：術前 CT 評估氣管

### 手術目標

- 避免 **<span style="color:#22d3ee">RLN 損傷</span>**（識別並顯露神經）
- 避免 **external branch of superior laryngeal nerve 損傷**
- 保留**<span style="color:#22d3ee">副甲狀腺</span>血供**（尤其上位副甲狀腺）

### 手術方式

| 方式 | 適應症 |
|------|--------|
| **Total thyroidectomy** | 甲狀腺癌、Graves' disease |
| **Near-total thyroidectomy** | 甲狀腺癌（保留小部分甲狀腺後方組織） |
| **Subtotal thyroidectomy** | Graves' disease（舊術式，現少用） |
| **Lobectomy** | 單側良性結節、低風險甲狀腺癌 |

### 術後併發症

| 併發症 | 說明 |
|--------|------|
| **RLN 損傷** | 單側 → 聲音沙啞；雙側 → 呼吸道阻塞（需氣切） |
| **副甲狀腺機能減退** | 低血鈣（症狀：四肢麻木、刺痛、肌肉痙攣、Chvostek's/Trousseau's sign） |
| **術後出血** | 呼吸道壓迫（需緊急再開刀） |
| **甲狀腺危象** | 術前未控制之甲狀腺機能亢進 |

## 副甲狀腺 (Parathyroid)

### 胚胎學

- **上位副甲狀腺**：起源於第四 branchial pouch
- **下位副甲狀腺**：起源於第三 branchial pouch（與 thymus 一起下降）
- <span style="color:#60a5fa">85%</span> 人有 **<span style="color:#60a5fa">4 個</span>** 副甲狀腺

### 副甲狀腺生理學

- **PTH（副甲狀腺激素）**：維持鈣磷平衡

| 靶器官 | 作用 |
|--------|------|
| **骨** | 刺激蝕骨、釋放鈣 |
| **腎** | 增加鈣回收、減少磷回收；刺激 1α-hydroxylase（增加 active vitamin D） |
| **腸** | 間接增加腸道鈣吸收 |

- **維生素 D**：增加腸道鈣吸收
- **Calcitonin**：甲狀腺 C cell 分泌；抑制蝕骨、降低血鈣

### 副甲狀腺血供

- 主要由**<span style="color:#60a5fa">下甲狀腺动脉</span>**分支供應
- 副甲狀腺位於 RLN 與下甲狀腺动脉交叉點 **<span style="color:#60a5fa">1 cm</span>** 範圍內
- 上位副甲狀腺：**背側（dorsal）**於 RLN
- 下位副甲狀腺：**腹側（ventral）**於 RLN

## 高副甲狀腺機能亢進症 (Hyperparathyroidism)

### 原發性（Primary Hyperparathyroidism）

#### 病因

| 病因 | 比例 |
|------|------|
| Parathyroid adenoma | <span style="color:#60a5fa">85%</span> |
| Hyperplasia | <span style="color:#60a5fa">15%</span> |
| Carcinoma | <span style="color:#f87171"><1%</span> |

#### 症狀（「Stones, Bones, Groans, and Psychiatric Overtones」）

| 類別 | 表現 |
|------|------|
| **Stones** | 腎結石、腎鈣化 |
| **Bones** | 骨質疏鬆、囊性纖維性骨炎 |
| **Groans** | 消化性潰痬、胰臟炎、便秘 |
| **Psychiatric** | 憂鬱、認知障礙、疲勞 |

#### 診斷標準

- **<span style="color:#60a5fa">血鈣升高 + PTH 升高（或不當正常）</span>**
- 25-OH Vitamin D 應同時檢測（缺乏時 PTH 可代償性升高）
- 24 小時尿鈣（排除家族性低尿鈣性高血鈣，FHH）

#### 定位診斷

| 檢查 | 說明 |
|------|------|
| **超音超** | 首選（非侵襲性） |
| **⁹⁹ᵐTc-sestamibi scan** | 最準確（敏感度 <span style="color:#60a5fa">85-95%</span>） |
| **CT/MRI** | 異位副甲狀腺（mediastinal） |
| **Selvester CTVS** | 4D-CT |

#### 手術治療

| 方式 | 說明 |
|------|------|
| **微創副甲狀腺切除術** | 單一腺瘤、定位確認後首選 |
| **雙側頸部探查** | 定位不確定或懷疑多發病灶 |
| **自體移植** | 甲狀腺全切除時可將副甲狀腺組織移植至胸鎖乳突肌 |

#### 手術適應症

**無症狀原發性高副甲狀腺機能亢進**：

| 適應症 | 說明 |
|--------|------|
| 血鈣 ><span style="color:#f87171">1 mg/dL</span> 高於正常上限 | — |
| **骨質密度減少** | T-score < <span style="color:#f87171">-2.5</span> |
| **肌酐清除率 <span style="color:#f87171"><60 mL/min</span>** | — |
| 骨質疏鬆且考慮 bisphosphonate 治療前 | — |

## 低副甲狀腺機能減退症 (Hypoparathyroidism)

- 甲狀腺/副甲狀腺手術後最常見
- **長期低血鈣症**：症狀包括感覺異常、肌肉痙攣、Chvostek's sign、Trousseau's sign、laryngospasm
- **治療**：<span style="color:#fb923c">維生素 D（calcitriol）</span>+ 鈣補充

## 腎上腺 (Adrenal)

### 腎上腺胚胎學

- **<span style="color:#22d3ee">皮質（cortex）</span>**：起源於**中胚層（mesoderm）**
- **<span style="color:#22d3ee">髓質（medulla）</span>**：起源於**神經外胚層（neural crest）**—與交感神經節同源

### 腎上腺解剖學

- 位於**<span style="color:#22d3ee">腎上內上方</span>**
- 右側：位於後腹膜，鄰近 liver、IVC
- 左側：位於後腹膜，鄰近 stomach tail、pancreas tail、left kidney
- **血液供應**：上、中、下腎上腺动脉（來自横膈动脉、主动脉、腎动脉）
- **靜脈引流**：右側 → IVC；左側 → 左腎靜脈

### 腎上腺皮質（Adrenal Cortex）

#### 皮質分區與激素

| 分區 | 激素 | 功能 |
|------|------|------|
| **Zona glomerulosa** | **<span style="color:#fb923c">Aldosterone</span>** | 鈉保留、鉀排泄 |
| **Zona fasciculata** | **<span style="color:#fb923c">Cortisol</span>** | 壓力反應、碳水化合物新生、脂肪分布 |
| **Zona reticularis** | **<span style="color:#fb923c">Androgens (DHEA)</span>** | 雄性激素前驅物 |

## 皮質醇過多症（Cushing's Syndrome）

### 病因分類

| 類型 | 病因 | ACTH |
|------|------|------|
| **ACTH-dependent** | Cushing's disease（腦下垂體腺瘤） | ↑ |
| **ACTH-dependent** | Ectopic ACTH（肺癌、胸腺瘤等） | ↑↑ |
| **ACTH-independent** | 腎上腺皮質腺瘤/癌 | ↓ |
| **ACTH-independent** | Iatrogenic（外源性類固醇） | ↓ |

### 診斷

| 檢查 | 說明 |
|------|------|
| **24 小時尿游離皮質醇（UFC）↑** | — |
| **深夜唾液皮質醇↑** | — |
| **Dexamethasone suppression test** | 1 mg overnight（或 2 mg 48 小時）；正常人：類固醇抑制皮質醇；Cushing's：不被抑制 |
| **ACTH** | 區分 ACTH-dependent vs independent |
| **CRH stimulation test** | 鑑別 Cushing's disease vs ectopic ACTH |

### 治療

| 病因 | 治療 |
|------|------|
| **Cushing's disease** | 經蝶竇腦下垂體手術 |
| **Ectopic ACTH** | 切除原發腫瘤 |
| **腎上腺皮質腺瘤** | 腹腔鏡切除 |
| **腎上腺皮質癌** | 手術切除（可能需化放療） |
| **Bilateral adrenal hyperplasia** | Bilateral adrenalectomy + 氫化皮質素替代 |

## 原發性醛固酮過多症（Primary Hyperaldosteronism）

### 病因

| 病因 | 比例 |
|------|------|
| Aldosterone-producing adenoma (Conn's syndrome) | 30-40% |
| Bilateral adrenal hyperplasia | 50-60% |
| Unilateral adrenal hyperplasia / 皮質癌 | 少見 |

### 診斷

- **難控制的高血壓**（通常需多種降壓藥）
- **<span style="color:#f87171">低血鉀</span>**（但 <span style="color:#60a5fa">30-50%</span> 血鉀正常）
- **血漿醛固酮濃度（PAC）↑ + 腎素活性（PRA）↓**
- **Aldosterone-to-renin ratio (ARR)**：≥30 為篩檢標準

### 治療

| 病因 | 治療 |
|------|------|
| **APA（腺瘤）** | 腹腔鏡單側腎上腺切除術 |
| **Bilateral hyperplasia** | 藥物治療（<span style="color:#fb923c">spironolactone</span>、<span style="color:#fb923c">eplerenone</span>） |
| **Subclinical Cushing's syndrome** | 可考慮腎上腺切除術 |

## 嗜鉻細胞瘤（Pheochromocytoma）

### 臨床特徵

- **<span style="color:#f87171">10-5-2 法則</span>**：<span style="color:#60a5fa">10%</span> 家族性、<span style="color:#60a5fa">10%</span> 雙側、<span style="color:#60a5fa">10%</span> 惡性、<span style="color:#60a5fa">5%</span> 發生在兒童、<span style="color:#60a5fa">2%</span> 為惡性
- **症狀**：陣發性高血壓（可達 <span style="color:#f87171">200+/120 mmHg</span>）、頭痛、出汗、心悸、蒼白
- **誘因**：情緒壓力、藥物（β-blocker、麻醉誘導）、觸摸腫瘤

### 診斷

| 檢查 | 說明 |
|------|------|
| **24 小時尿兒茶酚胺 / metanephrines ↑** | — |
| **血漿游離 metanephrines ↑** | 最敏感篩檢 |
| **CT/MRI** | 定位（腎上腺/腎上腺外） |
| **¹²³I-MIBG scan** | 功能性定位 |
| **基因檢測** | SDHB、SDHD、VHL、RET（多發性內分泌腫瘤） |

### 治療

| 階段 | 治療 |
|------|------|
| **術前 α-blockade（至少 <span style="color:#60a5fa">10-14 天</span>）** | <span style="color:#fb923c">Phenoxybenzamine</span>（不可逆性）或 prazosin/doxazosin（選擇性） |
| **術前 β-blocker（僅在 α-blockade 後）** | 控制心搏過速 |
| **術前靜脈輸液補充** | — |
| **術中** | 避免觸碰腫瘤 |
| **腫瘤切除** | — |
| **惡性** | ¹³¹I-MIBG、化療（cyclophosphamide + vincristine + dacarbazine） |

<span style="color:#f87171;font-weight:600">警告：</span>β-blocker 不可在 α-blockade 建立前使用，否則導致高血壓危象。

## 腎上腺偶發瘤（Adrenal Incidentaloma）

### 定義

- 無症狀、意外發現之腎上腺腫塊（>1 cm）

### 評估重點

1. **排除 malignancy**：CT 特徵（大小、邊緣、內部特徵）
   - **>4 cm**：惡性風險增加，建議切除
   - **<4 cm**：根據影像特徵決定
2. **排除 hormone excess**：
   - 測量 **24 小時尿皮質醇**（排除 subclinical Cushing's）
   - 測量 **plasma metanephrines** 或 24 小時尿（排除 pheochromocytoma）
   - 若有高血壓 + 低血鉀 → 測 aldosterone/renin ratio

### 處理原則

| 情況 | 處理 |
|------|------|
| 無功能性、無惡性特徵 | 6-12 個月後追蹤 CT |
| Subclinical Cushing's | 考慮切除（尤其年輕/糖尿病/骨質疏鬆患者） |
| 疑似 pheochromocytoma | 手術前完成 α-blockade |

## Summary

1. <span style="color:#60a5fa">甲狀腺 FNAB 依 Bethesda 分類</span>決定後續處理
2. **Graves' disease** 首選 **<span style="color:#60a5fa">total/near-total thyroidectomy</span>**
3. 甲狀腺乳頭狀癌：**<span style="color:#34d399">預後佳</span>**，小腫瘤可 active surveillance
4. **MTC**：術前基因檢測 **RET**（MEN 2）；甲狀腺全切除 + 淋巴結清掃
5. 原發性高副甲狀腺機能亢進：**<span style="color:#60a5fa">手術適應症</span>**包括高血鈣、骨質疏鬆、腎功能受損
6. **嗜鉻細胞瘤**：術前 **<span style="color:#60a5fa">α-blockade 至少 10-14 天</span>** 再手術
7. 腎上腺偶發瘤：需排除 **subclinical Cushing's** 和 **pheochromocytoma**
8. **腹腔鏡腎上腺切除術**：大多數腎上腺病灶的首選手術方式
