# CH31 肝臟
## Liver

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

肝臟是人體最大的實質器官，兼具代謝、解毒、合成、儲存等多重功能。外科臨床上，肝臟疾病的手術決策高度依賴肝功能儲備評估（CTP分數、MELD分數）。肝癌（尤其是HCC）是全球第5常見癌症，本章涵蓋從肝臟解剖、良性疾病到惡性腫瘤的手術治療原則，以及肝移植的適應症與結果。

---

## 肝臟解剖學 Hepatic Anatomy

### 分區

- 根據 **Couinaud 分類**，肝臟分為 <span style="color:#60a5fa">8 個功能區段</span>
- 每個區段有獨立的肝蒂（門靜脈、肝动脉、膽管分支）

### 血液供應

| 血管 | 供應比例 |
|------|---------|
| **<span style="color:#f87171">肝門靜脈</span>** | 約 <span style="color:#60a5fa">75%</span> 血流 |
| **<span style="color:#22d3ee">肝固有动脉</span>** | 約 <span style="color:#60a5fa">25%</span> 血流 |
| **肝靜脈** | 引流至下腔靜脈（IVC） |

### 膽管系統

- 左右肝管會合於肝門，形成總肝管
- **<span style="color:#22d3ee">肝蒂（Glissonian sheath）</span>**：包含門靜脈、肝动脉、膽管分支
- **<span style="color:#22d3ee">尾狀葉</span>**：解剖學特殊，直接引流至 IVC

## 肝臟生理學 Hepatic Physiology

### 膽紅素代謝

- 紅血球分解後形成未結合膽紅素
- 肝細胞攝取、結合、排泄至膽汁

| 類型 | 特性 |
|------|------|
| **未結合膽紅素** | 與白蛋白結合，親脂性 |
| **結合膽紅素** | 親水性，可經腎排泄 |

### 膽汁形成

- 膽鹽依賴性分泌
- 膽汁酸肝腸循環
- 協助脂肪和脂溶性維生素吸收

### 藥物代謝

- **<span style="color:#e2e8f0">細胞色素 P450 系統</span>**：主要藥物代謝途徑
- 營養因子和藥物影響代謝功能

## 急性肝衰竭 Acute Liver Failure

### 定義與病因

- **定義**：26 週內出現肝性腦病變，既往無肝病或門脈高壓
- **病因地理差異**：
  - 東方/開發中國家：病毒性肝炎（B、A、E）為主
  - 西方：65% 為藥物/毒素引起，**<span style="color:#f87171">acetaminophen 過量最常見</span>**

### 臨床表現

- 意識障礙（肝性腦病變）
- 顱內壓升高、腦水腫
- 感染（44% 培養確診）
- 凝血功能障礙
- 腎功能衰竭

### 診斷評估

| 檢查項目 | 目的 |
|----------|------|
| CBC | 評估貧血、血小板減少 |
| CMP、肝功能 | 膽紅素、白蛋白、轉胺酶 |
| PT/INR | 凝血功能 |
| Factor V | 肝合成功能 |
| 血氨 | 肝性腦病變 |
| 病毒性肝炎血清學 | 病因診斷 |
| 自體免疫標記 | 自體免疫性肝炎 |
| 毒物篩檢 | 藥物過量 |

### 治療原則

- **<span style="color:#fb923c">N-acetylcysteine (NAC)</span>**：acetaminophen 過量及不明原因 ALF
- 液體管理、血糖控制
- 預防感染
- 肝移植評估

### King's College 肝移植標準

| 病因 | 標準 |
|------|------|
| **Acetaminophen** | Arterial pH <span style="color:#f87171"><7.30</span>；或 PT >100s + Cr >3.4 mg/dL + Grade III/IV 腦病 |
| **非 Acetaminophen** | PT >100s；或以下三項：發病至昏迷 >7 天、PT >50s、膽紅素 >17.5 mg/dL、年齡 <10 或 >40 歲 |

## 肝硬化與門脈高壓 Cirrhosis and Portal Hypertension

### 肝硬化形態分類

| 類型 | 特點 |
|------|------|
| 微結節型 | 規則小結節，厚隔板 |
| 大結節型 | 大小不規則結節 |
| 混合型 | 兩者混合 |

### 病因

- **病毒性肝炎**：B 型、C 型、D 型
- **酒精性肝病**
- **非酒精性脂肪肝疾病（NAFLD/NASH）**
- **膽汁淤積**：原發性膽汁性肝硬化、原發性硬化性膽管炎
- **代謝異常**：血色沉著症、威爾森氏症、α1-抗胰蛋白酶缺乏
- **自體免疫肝炎**

### 臨床表現

- **<span style="color:#f87171">黃疸</span>**（膽紅素 >2-3 mg/dL）
- **<span style="color:#f87171">腹水</span>**
- **靜脈曲張出血**
- **肝性腦病變**
- **營養不良**
- **<span style="color:#60a5fa">肝細胞癌（HCC）篩檢</span>**：每 6 個月超聲 + AFP

### 肝功能儲備評估

#### Child-Turcotte-Pugh (CTP) 分數

| 參數 | 1 分 | 2 分 | 3 分 |
|------|------|------|------|
| 膽紅素 | <2 mg/dL | 2-3 mg/dL | >3 mg/dL |
| 白蛋白 | >3.5 g/dL | 2.8-3.5 g/dL | <2.8 g/dL |
| INR | <1.7 | 1.7-2.2 | >2.2 |
| 腦病變 | 無 | 控制中 | 無法控制 |
| 腹水 | 無 | 控制中 | 無法控制 |

- **<span style="color:#34d399">Class A（5-6 分）</span>**：手術死亡率 ~10%
- **<span style="color:#f87171">Class C（10-15 分）</span>**：手術死亡率 ~75-80%

#### MELD 分數

- **公式**：MELD = 9.57 × ln(Cr) + 3.78 × ln(膽紅素) + 11.2 × ln(INR) + 6.43
- MELD <10：可安全接受選擇性手術
- MELD 10-15：謹慎手術
- MELD >15：不建議選擇性手術

### 門脈高壓

#### 病理生理

- 正常門脈壓力：5-10 mmHg
- **臨床顯著門脈高壓**：HVPG >10 mmHg
- 側支循環形成（胃食道靜脈曲張、痔瘡等）

#### 病因分類

| 類別 | 病因 |
|------|------|
| 竇狀脈前 | 脾靜脈血栓、門靜脈血栓 |
| 竇狀脈性 | 肝硬化、病毒性肝炎 |
| 竇狀脈後 | Budd-Chiari 症候群、充血性心衰竭 |

### 胃食道靜脈曲張管理

#### 預防首次出血

- **非選擇性 β 受體阻斷劑**：propranolol、nadolol，減少 <span style="color:#60a5fa">45%</span> 出血風險
- **內視鏡靜脈曲張結紮術（EVL）**：用於中等至大型靜脈曲張

#### 急性出血治療

1. **液體復甦**：目標血紅素 ~8 g/dL
2. **抗菌素預防**：Ceftriaxone 1g/day IV
3. **血管活性藥物**：
   - **<span style="color:#fb923c">Octreotide</span>**：首選，作用於生長抑素受體
   - Vasopressin：效果更強但副作用大
4. **內視鏡治療**：靜脈曲張結紮
5. **Sengstaken-Blakemore 管**：用於難治性出血（最多 36 小時）

#### 進階治療

| 治療方式 | 適應症 |
|----------|---------|
| **TIPS** | 藥物/內視鏡治療失敗，門脈血栓風險 |
| **BRTO** | 胃靜脈曲張伴自發性胃腎分流 |
| **手術分流** | MELD <15，不適合 TIPS 或移植 |
| **肝移植** | 末期肝病變唯一根治方法 |

## 肝臟感染 Hepatic Infections

### 化膿性肝膿腫

- **病因**：膽道阻塞、門靜脈菌血症（闌尾炎、憩室炎）
- **常見菌種**：<span style="color:#c084fc">大腸桿菌</span>（2/3）、<span style="color:#c084fc">Klebsiella</span>、<span style="color:#c084fc">Streptococcus faecalis</span>、<span style="color:#c084fc">Bacteroides</span>
- **臨床**：發燒、右上腹痛、黃疸
- **診斷**：超聲、CT（敏感性高）
- **治療**：
  - IV <span style="color:#fb923c">抗菌素</span> 8 週
  - 經皮穿刺引流（如需要）
  - 手術引流（藥物/引流無效時）

### 阿米巴性膿腫

- **病原**：<span style="color:#c084fc">Entamoeba histolytica</span>
- **流行**：熱帶地區、衛生條件差
- **特點**：常位於肝右葉上部，接近橫膈
- **膿液特徵**：厚重、棕紅色，如「鱷魚醬」
- **治療**：<span style="color:#fb923c">Metronidazole</span> 750 mg tid × 7-10 天（95% 有效）

### 棘球囊蟲病（Hydatid Disease）

- **病原**：<span style="color:#c084fc">Echinococcus granulosus</span>（絛蟲幼蟲）
- **傳染途徑**：狗 → 糞便 → 羊/人的食物鏈
- **部位**：70% 位於肝右葉
- **診斷**：
  - ELISA（敏感性 85%）
  - 超聲、CT：囊腫壁鈣化

- **治療**：
  - <span style="color:#fb923c">Albendazole</span>：小型無症狀囊腫
  - 手術切除：首選（腹腔鏡或開腹）
  - 避免囊腫破裂以防過敏反應

### 蟯蟲症（Ascariasis）

- **病原**：<span style="color:#c084fc">Ascaris lumbricoides</span>
- **途徑**：逆行進入膽管
- **併發症**：膽管阻塞、膽囊炎、胰臟炎、肝膿腫
- **治療**：<span style="color:#fb923c">Albendazole</span> + 內視鏡取出

### 血吸蟲病（Schistosomiasis）

- **病原**：<span style="color:#c084fc">Schistosoma mansoni/japonicum</span>
- **病理**：蟲卵阻塞門脈分支，導致竇狀脈前門脈高壓
- **特點**：肝臟縮小、脾臟增大，但肝功能相對保存
- **治療**：<span style="color:#fb923c">Praziquantel</span> 40-75 mg/kg 單次劑量

## 病毒性肝炎 Viral Hepatitis

### B 型肝炎

- **現況**：全球常見，我國重要議題
- **併發症**：慢性感染 → 肝硬化 → HCC
- **治療**：
  - Pegylated interferon
  - Nucleoside analogs（<span style="color:#fb923c">Entecavir</span>、<span style="color:#fb923c">Tenofovir</span>）
  - 目標：病毒抑制，預防肝硬化和 HCC

### C 型肝炎

- **現況**：美國肝移植首要適應症
- **治療**：
  - Genotype 1：Pegylated interferon + Ribavirin + Protease inhibitor（Telaprevir/Boceprevir）
  - Genotype 2, 3：Interferon + Ribavirin
  - 目標：持續病毒學反應（SVR）

## 肝臟囊腫 Hepatic Cysts

### 先天性囊腫（Simple Cysts）

- **特點**：薄壁、內容清澈、血漿性液體
- **治療**：無症狀不需處理；有症狀則經皮囊腫穿刺 + 硬化劑注射（90% 有效）

### 膽管囊腺瘤（Biliary Cystadenoma）

- **特點**：生長緩慢、厚壁、有軟組織結節和間隔
- **惡性風險**：可發生惡性轉化
- **治療**：手術切除

### 多囊肝（PCLD）

- **遺傳**：自體顯性遺傳，PKD1/PKD2 基因突變
- **特點**：多發囊腫，肝臟變大但功能保存
- **併發症**：囊腫出血、感染、破裂
- **治療**：
  - 症狀輕微：觀察
  - 症狀明顯：囊腫穿刺硬化、囊腫窗開術
  - 末期：**肝移植**

### Caroli 病

- **特點**：先天性肝內膽管擴張
- **併發症**：膽結石、膽管炎、膿腫
- **治療**：膽道引流（ERCP/PTC）、肝葉切除

## 良性肝臟腫瘤 Benign Liver Tumors

### 血管瘤（Hemangioma）

- **特點**：最常見良性肝實質腫瘤，<span style="color:#60a5fa">2-20%</span> 人口
- **表現**：通常無症狀，偶有腹痛
- **影像**：CT/MRI 有典型周邊結節狀強化
- **治療**：無症狀觀察；有症狀或破裂風險大手術切除

### 肝腺瘤（Hepatic Adenoma）

- **特點**：與口服避孕藥相關
- **惡性風險**：可惡性轉化為 HCC
- **併發症**：自發性破裂（10-25%）
- **治療**：>4-5 cm 建議手術切除

### 局部結節性增生（FNH）

- **特點**：對異常动脉的增生反應
- **特徵**：典型中央疤痕
- **特點**：不破裂、無惡性風險
- **治療**：無症狀觀察

## 惡性肝臟腫瘤 Malignant Liver Tumors

### 肝細胞癌（HCC）

#### 流行病學

- 全球第 5 常見癌症，第 3 致死癌症
- **主要風險因素**：病毒性肝炎（B、C）、酒精性肝硬化、血色沉著症、NASH

#### 影像學特點

- **CT/MRI 特徵**：
  - 动脉期高密度（hypervascular）
  - 延遲期快速沖洗（washout）
  - 靜脈/門脈侵犯

#### TNM 分期（AJCC 第 8 版）

| 分期 | 腫瘤特點 |
|------|----------|
| T1a | ≤2 cm，無血管侵犯 |
| T1b | >2 cm，無血管侵犯 |
| T2 | 單一腫瘤 >5 cm，或任何腫瘤伴血管侵犯 |
| T3 | 多發腫瘤，至少 1 個 >5 cm |
| T4 | 侵犯臟器或穿透臟層腹膜 |

#### 治療原則

| 情況 | 治療選擇 |
|------|----------|
| 非肝硬化/早期肝硬化 | 手術切除 |
| 符合 Milan 標準（≤1 個 ≤5 cm 或 ≤3 個 ≤3 cm） | 肝移植 |
| 超出 Milan 標準 | 局部治療（ablation、TACE）、系統治療 |

#### Milan 標準

- 單一腫瘤 ≤5 cm
- 或最多 3 個腫瘤，每個 ≤3 cm
- 無大血管侵犯
- 無遠處轉移

#### 局部治療

| 治療 | 說明 |
|------|------|
| **RFA（射頻消融）** | 熱消融，早期 HCC 首選 |
| **乙醇注射** | 小腫瘤，經濟但效果較 RFA 差 |
| **TACE（經導管動注化療）** | 晚期 HCC，生存獲益 |
| **Yttrium-90 微球** | 放射性栓塞，化療失敗後 |

#### 系統治療

- **<span style="color:#fb923c">Sorafenib</span>**：晚期 HCC 第一線，延長生存 2.8 月
- **其他標靶藥物**：Lenvatinib、Regorafenib

### 膽管癌（Cholangiocarcinoma）

#### 分類

| 類型 | 特點 |
|------|------|
| 肝門部（Klatskin 瘤） | 總肝管會合處，阻塞性黃疸 |
| 遠端膽管癌 | 膽總管，表現類似胰頭癌 |
| 肝內膽管癌 | 周邊型，類似 HCC |

#### 治療

- **肝門部膽管癌**：手術切除（肝葉切除 + 膽管切除）
- **無法切除**：Mayo Clinic Protocol（放化療 + 肝移植）
- **周邊型**：手術切除為主

### 膽囊癌

- **特點**：90% 與膽結石相關，預後差
- **分期**：T1a（黏膜）、T1b（肌肉層）、T2（漿膜層）、T3/T4（侵犯）
- **治療**：
  - T1a：單純膽囊切除
  - T1b 以上：根治性膽囊切除（肝楔形切除 + 淋巴結清除）

### 轉移性大腸癌

- **特點**：最常見肝轉移腫瘤，<span style="color:#60a5fa">50-60%</span> 大腸癌發生
- **預後因素**：原發淋巴結陽性、DFS <12 月、>1 個腫瘤、腫瘤 >5 cm、CEA >200 ng/mL
- **治療**：
  - **可切除**：手術切除（5 年生存 <span style="color:#60a5fa">25-40%</span>）
  - **化療後可切除**：新輔助化療
  - **無法切除**：化療、標靶治療

### 神經內分泌腫瘤肝轉移

- **特點**：生長緩慢，預後較好
- **治療**：
  - 減積手術（Debulking）：控制症狀、延長生存
  - 肝移植（選擇性病例）
  - RFA、化療栓塞

## 肝臟手術治療 Hepatic Surgery

### 手術方式（Brisbane 2000 術語）

| 傳統名稱 | Brisbane 2000 名稱 |
|----------|------------------|
| 右肝葉切除 | 右半肝切除（右肝葉） |
| 左肝葉切除 | 左半肝切除（左肝葉） |
| 右肝三段切除 | 右三區切除（擴大右半肝） |
| 左外側段切除 | 左外側區切除（II、III 段） |

### 血流控制

- **Pringle 手法**：阻斷肝蒂（腸系膜上靜脈和肝總动脉）
  - 連續阻斷：最多 60 分鐘
  - 間歇性阻斷：15 分鐘開/5 分鐘關
- **半肝血流阻斷**：減少肝缺血

### 術前門靜脈栓塞（PVE）

- **目的**：誘導剩餘肝葉肥大
- **適應**：FLR <25-30% 預期
- **時機**：手術前 4 週

### 術後併發症

- **肝衰竭**：死亡率主要因素
- **膽汁漏**
- **出血**
- **感染**

---

## 肝移植 Liver Transplantation

### 適應症

- 末期肝病
- 小 HCC（Milan 標準）
- 急性肝衰竭
- 膽汁淤積性疾病

### 結果

- 1 年生存率：<span style="color:#60a5fa">80-90%</span>

- 肝臟<span style="color:#60a5fa">8個功能區段</span>（Couinaud分類），<span style="color:#22d3ee">肝門靜脈</span>供應<span style="color:#60a5fa">75%</span>血流
- 急性肝衰竭：**<span style="color:#fb923c">NAC</span>**為acetaminophen及不明原因ALF的治療
- CTP Class A的手術死亡率<span style="color:#34d399">~10%</span>，Class C達<span style="color:#f87171">~75-80%</span>
- MELD >15：<span style="color:#f87171">不建議選擇性手術</span>
