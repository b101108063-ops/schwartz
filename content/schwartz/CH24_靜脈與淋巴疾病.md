# CHAPTER 24 VENOUS AND LYMPHATIC DISEASE 靜脈與淋巴疾病

source: Schwartz's Principles of Surgery, 11th Edition

## Chronic Venous Disease (CVD) 慢性靜脈疾病

### CEAP Classification CEAP分類

| Class 分期 | Description 描述 |
|-----------|----------------|
| **C0** | No visible or palpable signs 無可見或可觸及的徵象 |
| **C1** | Telangiectasia, reticular veins 微血管擴張、網狀靜脈 |
| **C2** | Varicose veins 靜脈曲張 |
| **C3** | Edema 水腫 |
| **C4a** | Pigmentation, eczema 色素沉著、濕疹 |
| **C4b** | Lipodermatosclerosis, atrophie blanche 脂肪皮膚硬化、白色萎縮 |
| **C5** | Healed venous ulcer 已癒合靜脈潰瘤 |
| **C6** | Active venous ulcer 活動性靜脈潰瘤 |

### Clinical Symptoms 臨床症狀

| Symptom 症狀 | Description 描述 |
|-------------|----------------|
| **Aching pain** 脹痛 | Worsens with standing, improves with elevation 站立加重、抬高改善 |
| **Heaviness** 沉重感 | End of day, with prolonged standing 一天結束時、長期站立 |
| **Swelling** 腫脹 | Ankle, worse at end of day 踝、一天結束時加劇 |
| **Itching** 癢 | Over varicose veins 靜脈曲張處 |
| **Restless legs** 腿部不安 | At night, relieved by walking 夜間、走路可緩解 |

### Physical Findings 身體檢查發現

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Varicose veins** 靜脈曲張 | Tortuous, dilated superficial veins 彎曲、擴張的淺層靜脈 |
| **Corona phlebectatica** | Dilated subdermal venules at medial ankle 內踝擴張的皮下小靜脈 |
| **Edema** 水腫 | Pitting, brawny 按壓凹陷、堅韌 |
| **Hyperpigmentation** 色素過度沉著 | Brown hemosiderin staining 棕色血鐵質沉著 |
| **Eczema** 濕疹 | Stasis dermatitis (C4a) 鬱積性皮膚炎 |
| **Lipodermatosclerosis** 脂肪皮膚硬化 | Fibrotic, hardened skin/subcutaneous (C4b) 纖維化、變硬的皮膚/皮下組織 |
| **Atrophie blanche** 白色萎縮 | White, scarred patches 白色、疤痕樣斑塊 |
| **Ulceration** 潰瘤 | Typically near medial malleolus (gaiter area) 通常在內踝附近(靜脈曲張區) |

### Venous Insufficiency Pathophysiology 靜脈功能不全病理生理

1. **Venous reflux** → valve incompetence (superficial, deep, perforator) 靜脈逆流→瓣膜功能不全
2. **Venous hypertension** → capillary leakage → edema 靜脈高壓→毛細血管滲漏→水腫
3. **Fibrin cuff deposition** → impaired nutritional exchange 纖維蛋白袖口沉積→營養交換受損
4. **WBC trapping** → inflammation → tissue destruction 白血球被困→發炎→組織破壞
5. **Lipodermatosclerosis** → fibrosis, fat necrosis 脂肪皮膚硬化→纖維化、脂肪壞死
6. **Ulceration** → breakdown of ischemic skin 潰瘤→缺血皮膚崩解

## Varicose Veins 靜脈曲張

### Anatomy 解剖學

| System 系統 | Veins 靜脈 |
|------------|-----------|
| **Superficial 淺層** | Great saphenous (GSV), small saphenous (SSV), tributaries 大隱靜脈、小隱靜脈、分支 |
| **Deep 深層** | Femoral, popliteal, tibial, gastrocnemius 股靜脈、膕靜脈、脛靜脈、腓腸靜脈 |
| **Perforators 穿透靜脈** | Connect superficial to deep; contain valves 連接淺層與深層；內有瓣膜 |

### Great Saphenous Vein (GSV) 大隱靜脈

- **Origin:** Medial foot dorsum 起始：足內側背面
- **Course:** Medial leg → behind medial femoral condyle → femoral triangle 路徑：小腿內側→股骨內側踝後方→股三角
- **Tributaries:** Medial marginal, superficial epigastric, superficial circumflex iliac, external pudendal 分支：內側緣、腹壁淺、旋髂淺、外陰部

### Small Saphenous Vein (SSV) 小隱靜脈

- **Origin:** Lateral foot dorsum 起始：足外側背面
- **Course:** Lateral Achilles → posterior calf → popliteal fossa 路�de：外側跟腱→小腿後側→膕窩
- **Joins:** Popliteal vein (usually) 會合：膕靜脈(通常)

### Perforator Veins 穿透靜脈

- **Cockett perforators** (lower leg): Connect GSV to posterior tibial veins 連接大隱靜脈至後脛靜脈
- **Boyd perforators** (mid-leg): Connect GSV to femoral vein 連接大隱靜脈至股靜脈
- **Dodd perforators** (upper leg): Connect GSV to femoral vein 連接大隱靜脈至股靜脈

### Treatment Options 治療選項

#### Conservative Management 保守治療

| Treatment 治療 | Details 詳情 |
|-------------|-----------|
| **Compression stockings** 壓迫襪 | Class I-II for mild-moderate; Class III for severe 輕中度用I-II級；重度用III級 |
| **Leg elevation** 抬高腿部 | Above heart level when resting 休息時高於心臟水平 |
| **Exercise** 運動 | Walking improves calf muscle pump 走路改善腓腸肌泵功能 |
| **Weight management** 體重管理 | Reduces venous pressure 減少靜脈壓力 |

#### Interventional/Surgical 介入/手術治療

| Treatment 治療 | Indication 適應症 | Details 詳情 |
|-------------|----------------|-------------|
| **GSV stripping** 大隱靜脈剝離 | Traditional, effective 傳統、有效 | High ligation + stripping to knee 高位結紮+剝離至膝蓋 |
| **Endovenous ablation (RFA, EVLT)** 血管內消融 | GSV reflux 對大隱靜脈逆流 | Thermal ablation; preferred over surgery 熱消融；優於手術 |
| **Ambulatory phlebectomy** 門診靜脈切除 | Tributary varicosities 分支靜脈曲張 | Stab avulsion under local 局部麻醉下穿刺抽取 |
| **Sclerotherapy** 硬化劑注射 | Spider veins, small varicosities 蜘蛛靜脈、小靜脈曲張 | Liquid or foam (polidocanol, STS) |
| **CHIVA** | Conservation approach 保存方法 | Ligation + hemodynamic correction 結紮+血流動力學校正 |
| **SEPS** | Perforator incompetence 穿透靜脈功能不全 | Subfascial endoscopic perforator surgery 筋膜下內視鏡穿透靜脈手術 |

#### Endovenous Thermal Ablation 血管內熱消融

| Method 方法 | Energy Source 能量來源 |
|-----------|---------------------|
| **Radiofrequency ablation (RFA)** 射頻消融 | Heat (120°C) |
| **Endovenous laser therapy (EVLT)** 靜脈內雷射治療 | Laser (810-1470 nm) |
| **Steam vein sclerosis** 蒸汽靜脈硬化 | Steam |

### Recurrence Causes 復發原因

- **Neovascularization** (most common) 新生血管(最常見)
- **Incomplete ablation of GSV** 大隱靜脈消融不完全
- **New reflux in tributaries** 分支新發逆流
- **Deep vein insufficiency** (if not addressed) 深靜脈功能不全(如有未處理)

## Deep Vein Thrombosis (DVT) 深層靜脈血栓

### Virchow's Triad

| Factor 因素 | Effect 作用 |
|------------|-----------|
| **Stasis** 鬱滯 | Immobility, venous obstruction 活動不便、靜脈阻塞 |
| **Endothelial injury** 內皮損傷 | Trauma, surgery, catheter 外傷、手術、導管 |
| **Hypercoagulability** 高凝固性 | Cancer, inherited thrombophilia, inflammation 癌症、遺傳性血栓體質、發炎 |

### Risk Factors 危險因子

- Surgery (especially orthopedic, pelvic, abdominal) 手術(尤其是骨科、骨盆、腹腔)
- Immobilization 活動不便
- Cancer 癌症
- Pregnancy, estrogen use 懷孕、使用雌激素
- Inherited thrombophilia 遺傳性血栓體質
- Prior DVT 之前DVT
- Obesity 肥胖
- Age >60 年齡>60

### Wells Score for DVT DVT威爾斯積分

| Finding 發現 | Points 積分 |
|-------------|-----------|
| Active cancer 活躍癌症 | +1 |
| Paralysis/recent immobilization 麻痺/近期活動不便 | +1 |
| Recently bedridden >3 days/major surgery <12 weeks 近期臥床>3天/大手術<12週 | +1 |
| Localized tenderness along deep veins 沿深靜脈局部壓痛 | +1 |
| Entire leg swollen 整腿腫脹 | +1 |
| Calf swelling >3cm vs asymptomatic 腓腸腫脹>3cm相對於無症狀 | +1 |
| Pitting edema 凹陷性水腫 | +1 |
| Collateral superficial veins 側枝淺靜脈 | +1 |
| Previously documented DVT 之前記錄的DVT | +1 |
| Alternative diagnosis as likely (-2) 替代診斷可能性 (-2) | -2 |

- **Score ≥2:** DVT likely → anticoagulation + ultrasound 可能→抗凝+超音
- **Score <2:** Consider D-dimer 考慮D-雙體

### Diagnosis 診斷

| Test 檢查 | Details 詳情 |
|----------|-----------|
| **D-dimer** | Sensitive but not specific; negative helps rule out 敏感但非特異；陰性有助排除 |
| **Compression ultrasound** 壓迫超音 | Gold standard; near 100% sensitivity for proximal DVT 黃金標準；近端DVT敏感度近100% |
| **Venography** 靜脈造影 | Gold standard historical; rarely needed now 歷史黃金標準；現已少用 |

### DVT Locations DVT位置

| Location 位置 | Clinical Significance 臨床意義 |
|-------------|----------------------------|
| **Calf (distal)** 腓腸(遠端) | Lower risk of PE; may propagate PE風險較低；可能蔓延 |
| **Popliteal** 膕靜脈 | Moderate PE risk 中度PE風險 |
| **Femoral** 股靜脈 | Higher PE risk 較高PE風險 |
| **Iliac** 髂靜脈 | Highest PE risk; May cause limb swelling 最高PE風險；可致肢體腫脹 |
| **IVC** 下腔靜脈 | Filter may be needed; bilateral iliofemoral = phlegmasia 可能需要濾網；雙側髂股=股白腫 |

### Phlegmasia 股白腫

| Type 類型 | Description 描述 |
|----------|----------------|
| **Alba (white)** 白型(白色) | Venous obstruction + arterial spasm; pale, painful leg 靜脈阻塞+動脉痙攣；蒼白、疼痛的腿 |
| **Cerulea (blue)** 藍型(藍色) | Severe venous congestion; blue, cyanotic 嚴重靜脈充血；藍色、發紺 |

### Anticoagulation Treatment 抗凝血治療

| Phase 階段 | Duration 期間 | Options 選項 |
|----------|-------------|-------------|
| **Initial (first 5-10 days)** 初始(前5-10天) | Hospital 住院 | LMWH (enoxaparin), UFH, fondaparinux |
| **Long-term** 長期 | 3-12 months 3-12個月 | Warfarin (INR 2-3), DOACs (apixaban, rivaroxaban, dabigatran, edoxaban) |
| **Extended** 延長 | >12 months or indefinite >12個月或無限期 | For recurrent, cancer, thrombophilia 用於復發、癌症、血栓體質 |

### Thrombolysis (Catheter-Directed) 溶栓(導管定向)

| Indication 適應症 | Consideration 考量 |
|-----------------|-----------------|
| **Iliofemoral DVT** 髂股DVT | May prevent PTS 可能預防PTS |
| **Acute massive swelling** 急性大量腫脹 | Limb threat 肢體威脅 |
| **Acute DVT <14 days** 急性DVT<14天 | Better outcomes 預後較佳 |

### Inferior Vena Cava (IVC) Filter 下腔靜脈濾網

| Indication 適應症 | Details 詳情 |
|----------------|-------------|
| **Absolute** 絕對 | Contraindication to anticoagulation + DVT/PE 抗凝禁忌+ DVT/PE |
| **Relative** 相對 | Failed anticoagulation, PE despite anticoagulation 抗凝失敗、抗凝下仍發生PE |
| **Prophylactic** 預防性 | High-risk surgical patients (controversial) 高風險手術患者(有爭議) |

### Complications 併發症

| Complication 併發症 | Long-term Consequence 長期後果 |
|-------------------|----------------------------|
| **Pulmonary embolism** 肺栓塞 | Acute PE, chronic thromboembolic disease 急性PE、慢性血栓栓塞疾病 |
| **Post-thrombotic syndrome (PTS)** 血栓後症候群 | 30-50% after proximal DVT 近端DVT後30-50% |
| **Recurrent DVT** 復發性DVT | 5-10% per year without treatment 不治療每年5-10% |
| **Phlegmasia** 股白腫 | Rare but limb-threatening 罕見但肢體威脅 |

## Post-Thrombotic Syndrome (PTS) 血栓後症候群

### Pathophysiology 病理生理

- Valvular damage from DVT → venous reflux DVT引起的瓣膜損傷→靜脈逆流
- Persistent venous obstruction → hypertension 持續性靜脈阻塞→高壓
- Combined reflux + obstruction → severe PTS 逆流+阻塞合併→嚴重PTS

### Clinical Features 臨床特徵

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Chronic leg heaviness/aching** 慢性腿部沉重/疼痛 | Worsens with standing 站立加劇 |
| **Swelling** 腫脹 | Persistent, worse end of day 持續、一天結束時加劇 |
| **Varicose veins** 靜脈曲張 | Secondary 續發性 |
| **Skin changes** 皮膚變化 | Pigmentation, eczema, lipodermatosclerosis 色素沉著、濕疹、脂肪皮膚硬化 |
| **Ulceration** 潰瘤 | Recurrent, difficult to heal 復發、難癒合 |

### CEAP for PTS

- Same as general CVD classification 與一般CVD分類相同
- **Symptoms attributed to prior DVT** documented by ultrasound 症狀歸因於之前DVT並經超音證實

### Prevention 預防

| Strategy 策略 | Evidence 證據 |
|-------------|-------------|
| **Early anticoagulation** 早期抗凝 | Prevents extension/recurrence 防止蔓延/復發 |
| **Elastic compression** 彈性壓迫 | Reduces PTS risk 降低PTS風險 |
| **Catheter-directed thrombolysis** 導管定向溶栓 | May reduce PTS (CaVenT trial) 可能降低PTS |

### Treatment 治療

| Treatment 治療 | Indication 適應症 |
|--------------|-----------------|
| **Compression stockings (30-40 mmHg)** 壓迫襪 | All patients with symptoms 所有有症狀患者 |
| **Venous ulcer care** 靜脈潰瘤照護 | Dressings, compression, elevation 敷料、壓迫、抬高 |
| **Endovenous ablation** 血管內消融 | Superficial reflux 淺層逆流 |
| **Iliac vein stenting** 髂靜脈支架 | May-Thurner, chronic iliac obstruction |
| **Pulmonary rehabilitation** 肺部復健 | For severe disease 嚴重疾病 |

## Pulmonary Embolism (PE) 肺栓塞

### Classification 分類

| Severity 嚴重度 | Hemodynamics 血流動力學 | Management 處理 |
|----------------|----------------------|---------------|
| **Massive (High-risk)** 大量(高風險) | SBP <90 mmHg, shock 休克 | Thrombolysis, embolectomy 溶栓、取栓 |
| **Submassive (Intermediate)** 亞大量(中度) | RV dysfunction, normal BP | Anticoagulation, monitor 抗凝、監測 |
| **Low-risk** 低風險 | No RV strain, normal BP | Outpatient possible 可能門診 |

### Diagnosis (Wells Criteria for PE) 診斷

| Criterion 標準 | Points 積分 |
|--------------|-----------|
| Clinical signs of DVT DVT臨床徵象 | +3.0 |
| PE as likely or more likely than DVT PE可能性≥DVT | +3.0 |
| HR >100 | +1.5 |
| Immobilization >3 days or surgery <4 weeks 活動不便>3天或手術<4週 | +1.5 |
| Prior DVT/PE 之前DVT/PE | +1.5 |
| Hemoptysis 咳血 | +1.0 |
| Malignancy 惡性腫瘤 | +1.0 |
| Alternative explanation less likely than PE 替代解釋較PE可能性低 | +3.0 |

### Diagnostic Workup 診斷檢查

| Test 檢查 | Finding 發現 |
|----------|------------|
| **CT pulmonary angiography (CTPA)** | Gold standard; visualizes emboli 黃金標準；可見栓塞 |
| **V/Q scan** | If CT contraindicated (renal failure, contrast allergy) 如CT禁忌(腎衰竭、對比劑過敏) |
| **Echocardiography** | RV strain, McConnell's sign |
| **Troponin, BNP** | Elevated in submassive/massive |
| **Lower extremity ultrasound** | Proximal DVT confirmation 近端DVT確認 |

### Treatment 治療

| Situation 情況 | Treatment 治療 |
|--------------|--------------|
| **Massive PE** 大量PE | Thrombolysis (tPA 100mg IV over 2h), surgical embolectomy if failed/contraindicated 溶栓，失敗/禁忌時手術取栓 |
| **Submassive PE** 亞大量PE | Anticoagulation, consider catheter-directed thrombolysis 抗凝、考慮導管定向溶栓 |
| **Low-risk** 低風險 | Outpatient anticoagulation (DOAC preferred) 門診抗凝(DOAC優先) |

## Venous Ulcers 靜脈潰瘤

### Characteristics 特徵

| Feature 特色 | Description 描述 |
|------------|----------------|
| **Location** 位置 | Medial malleolus (gaiter area) 內踝(靜脈曲張區) |
| **Shape** 形狀 | Irregular, shallow 不規則、淺 |
| **Base** 潰瘤底 | Granulation tissue, may expose tendon 肉芽組織、可能暴露肌腱 |
| **Edge** 邊緣 | Sloping, irregular 傾斜、不規則 |
| **Pain** 疼痛 | Mild-moderate 輕中度 |
| **Skin changes** 皮膚變化 | Surrounding pigmentation, eczema, lipodermatosclerosis 周圍色素沉著、濕疹、脂肪皮膚硬化 |

### Differential Diagnosis 鑑別診斷

| Condition 疾病 | Features 特色 |
|-------------|-------------|
| **Arterial ulcer** 動脉潰瘤 | Painful, distal (toes, lateral malleolus), punched out, pale base 疼痛、遠端(腳趾、外踝)、打洞樣、蒼白底 |
| **Neuropathic ulcer** 神經病變潰瘤 | Pressure points (sole), callus, painless 壓力點(足底)、胖胼、無疼痛 |
| **Vasculitic ulcer** 血管炎潰瘤 | Multiple, painful, associated with systemic disease 多發、疼痛、關聯全身性疾病 |

### Treatment 治療

| Treatment 治療 | Details 詳情 |
|-------------|------------|
| **Compression** 壓迫 | Unna boot, layered compression, 30-40 mmHg |
| **Elevation** 抬高 | Legs above heart when resting 休息時腿高於心臟 |
| **Wound care** 傷口照護 | Debridement, moist dressings, skin substitutes 清創、保濕敷料、皮膚替代品 |
| **Antibiotics** 抗生素 | Only for active infection 只用於活動性感染 |
| **Treat underlying reflux** 治療根本逆流 | Ablation of refluxing veins after ulcer healing 潰瘤癒合後消融逆流靜脈 |
| **Pentoxifylline** | May improve healing 可能改善癒合 |

### Dressings 敷料

| Type 類型 | Use 用途 |
|----------|---------|
| **Foam** 泡棉 | Moderate exudate 中度滲出 |
| **Hydrocolloid** 水膠 | Light exudate, promotes granulation 低滲出、促進肉芽 |
| **Alginate** 藻酸鹽 | Heavy exudate 高滲出 |
| **Silver** 銀 | Infected wounds 感染傷口 |
| **Collagen** 膠原蛋白 | Non-healing wounds 不癒合傷口 |

## Lymphedema 淋巴水腫

### Classification 分類

| Type 類型 | Cause 病因 | Examples 範例 |
|----------|----------|--------------|
| **Primary** 原發性 | Congenital malformation 先天性發育不良 | Milroy disease, Meige disease |
| **Secondary** 續發性 | Acquired damage 後天損傷 | Post-surgical (node dissection), radiation, filariasis, infection |

### Stages 分期

| Stage 分期 | Description 描述 |
|-----------|----------------|
| **Stage 0** | Latent; no swelling but impaired lymph transport 潛伏；無腫脹但淋巴傳遞受損 |
| **Stage I** | Pitting edema, reversible with elevation 可凹陷水腫、抬高可逆 |
| **Stage II** | Non-pitting, spontaneous not reversible 非凹陷、無法自行逆轉 |
| **Stage III** | Elephantiasis; non-pitting, fibrotic, skin changes 象皮腫；非凹陷、纖維化、皮膚變化 |

### Pathophysiology 病理生理

1. Lymph transport impaired → accumulation of protein-rich fluid 淋巴傳遞受損→蛋白質豐富液體積聚
2. Chronic inflammation → adipose deposition, fibrosis 慢性發炎→脂肪沉積、纖維化
3. Skin/subcutaneous tissue changes → thickened, hyperkeratotic 皮膚/皮下組織變化→變厚、角化過度

### Clinical Features 臨床特徵

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Non-pitting edema** 非凹陷水腫 | Late finding (vs. venous which is pitting) 晚期發現(相對於靜脈性為凹陷性) |
| **Stemmer sign** | Unable to pinch skin at base of 2nd toe 無法捏起第二腳趾根部皮膚 |
| **Kaposi-Stemmer** | Thickened skin folds 皮膚皺褶變厚 |
| **Skin thickening** 皮膚變厚 | Hyperkeratosis, papillomatosis 角化過度、乳頭瘤樣變化 |
| **Fungal infections** 徽菌感染 | Intertrigo, tinea pedis 擦爛、腳癬 |

### Diagnosis 診斷

| Test 檢查 | Use 用途 |
|----------|---------|
| **Clinical** 臨床 | Characteristic presentation 典型表現 |
| **Lymphoscintigraphy** 淋巴閃爍造影 | Gold standard; delayed tracer uptake, dermal backflow 黃金標準；延遲追蹤劑攝取、真皮逆流 |
| **MRI/CT** | Excludes obstruction, shows fat/fibrosis 排除阻塞、顯示脂肪/纖維化 |
| **Bioimpedance spectroscopy** 生物阻抗頻譜 | Quantifies fluid vs. fat 量化的液體相對於脂肪 |

### Treatment (Complete Decongestive Therapy - CDT) 治療(完整消腫治療)

| Component 組成 | Description 描述 |
|--------------|----------------|
| **Manual lymphatic drainage** 徒手淋巴引流 | Specialized massage technique 特殊按摩技術 |
| **Compression** 壓迫 | Multi-layer bandaging → compression garments 多層繃帶→壓迫衣 |
| **Meticulous skin care** 嚴格皮膚照護 | Prevent infection, moisturize 預防感染、保濕 |
| **Exercise** 運動 | Muscle pumping with compression 穿壓迫配合肌肉泵作用 |
| **Pneumatic compression** 氣動壓迫 | Adjunct to CDT CDT的輔助 |

### Surgical Options 手術選項

| Procedure 術式 | Indication 適應症 |
|--------------|-----------------|
| **Liposuction** 抽脂 | Fixed, non-pitting lymphedema 固定性、非凹陷淋巴水腫 |
| **Lymphovenous anastomosis** 淋巴靜脈吻合 | Early stage, supermicrosurgery 早期、超顯微手術 |
| **Vascularized lymph node transfer** 帶血管淋巴結移植 | Selected cases 特定病例 |
| **Debulking** 減積 | Severe (elephantiasis) 嚴重(象皮腫) |

### Complications 併發症

| Complication 併發症 | Risk 風險 |
|------------------|----------|
| **Cellulitis** 蜂窩組織炎 | Recurrent infections 復發性感染 |
| **Lymphangitis** 淋巴管炎 | Acute inflammation 急性發炎 |
| **Skin cancers** 皮膚癌 | Rare (Stewart-Treves syndrome - lymphangiosarcoma) 罕見 |

## Superior Vena Cava Syndrome (SVCS) 上腔靜脈症候群

### Etiology 病因

| Cause 病因 | Frequency 頻率 |
|----------|--------------|
| **Malignancy** 惡性腫瘤 | 70-80% (lung cancer, lymphoma) |
| **Benign** 良性 | 20-30% (thrombosis from catheters/pacemakers, goiter, fibrosis) |

### Clinical Features 臨床特徵

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Facial swelling** 面部腫脹 | Worse in morning 早晨較重 |
| **Arm swelling** 手臂腫脹 | Bilateral 雙側 |
| **Cough, dyspnea** 咳嗽、呼吸困難 | Upper airway congestion 上呼吸道充血 |
| **Hoarseness** 聲音嘶啞 | Laryngeal edema 喉部水腫 |
| **HA, visual changes** 頭痛、視力變化 | Cerebral edema 腦水腫 |
| **Dilated chest wall veins** 胸壁靜脈擴張 | Collateral circulation 側枝循環 |

### Diagnosis 診斷

| Test 檢查 | Finding 發現 |
|----------|------------|
| **CT with contrast** CT對比 | Tumor, thrombosis, collaterals 腫瘤、血栓、側枝 |
| **Biopsy** 切片 | For malignancy (bronchoscopy, mediastinoscopy) 確認惡性 |

### Treatment 治療

| Treatment 治療 | Indication 適應症 |
|-------------|-----------------|
| **Treat underlying cause** 治療根本原因 | Chemo/radiation for malignancy 惡性腫瘤化療/放療 |
| **Endovascular stenting** 血管內支架 | Rapid relief, preferred 快速緩解、優先 |
| **Anticoagulation** 抗凝血 | For catheter-related thrombus 導管相關血栓 |
| **Steroids** 類固醇 | Temporizing, reduces edema 暫時性、減少水腫 |
| **Diuretics** 利尿劑 | Symptomatic relief 症狀緩解 |

## Budd-Chiari Syndrome 巴吉氏症候群

### Definition 定義

- Hepatic vein outflow obstruction 肝靜脈出口阻塞
- From hepatic veins to right atrium 從肝靜脈到右心房

### Etiology 病因

| Cause 病因 | Mechanism 機制 |
|----------|--------------|
| **Hypercoagulable states** 高凝固狀態 | Polycythemia vera, PNH, Factor V Leiden, protein C deficiency |
| **Tumors** 腫瘤 | HCC, renal cell, adrenal 肝細胞癌、腎細胞、腎上腺 |
| **Membranous webs** 膜性蹼 | Congenital (more common in Asia) 先天性(亞洲較常見) |
| **Compression** 壓迫 | Tumor, abscess 腫瘤、膿場 |
| **Idiopathic** 特發性 | 30% |

### Clinical Presentation 臨床表現

| Presentation 表現 | Features 特色 |
|-----------------|--------------|
| **Acute** 急性 | RUQ pain, hepatomegaly, ascites 右上腹痛、肝腫大、腹水 |
| **Subacute** 亞急性 | Progressive hepatomegaly, varices 進行性肝腫大、静脈曲張 |
| **Chronic** 慢性 | Cirrhosis, portal hypertension, variceal bleeding 肝硬化、門脈高壓、静脈曲張出血 |
| **Fulminant** 猛爆性 | Hepatic failure, encephalopathy 肝衰竭、肝性腦病變 |

### Diagnosis 診斷

| Test 檢查 | Finding 發現 |
|----------|------------|
| **Doppler ultrasound** 都卜勒超音 | Absent/reversed flow in hepatic veins 肝靜脈流場消失/逆轉 |
| **CT/MRI** | Tumor, webs, caudate hypertrophy 腫瘤、蹼、尾狀葉肥大 |
| **Hepatic venography** 肝靜脈造影 | Gold standard; pressure measurement 黃金標準；壓力測量 |

### Treatment 治療

| Treatment 治療 | Indication 適應症 |
|-------------|-----------------|
| **Anticoagulation** 抗凝血 | All patients 所有患者 |
| **Thrombolysis (catheter-directed)** 導管定向溶栓 | Acute, <4 weeks 急性、<4週 |
| **IVC stent** 下腔靜脈支架 | IVC obstruction 下腔靜脈阻塞 |
| **TIPS** | Refractory ascites, variceal bleeding 頑抗性腹水、静脈曲張出血 |
| **Liver transplant** 肝移植 | Fulminant, cirrhosis with failure 猛爆性、併發衰竭的肝硬化 |

## Venous Malformations 靜脈畸形

### Types 類型

| Type 類型 | Features 特色 |
|----------|--------------|
| **Capillary (port-wine stain)** 毛細血管(酒紅色斑) | Flat, red-purple; associated with Sturge-Weber 扁平、紅紫色；關聯斯特奇-韋伯 |
| **Venous** 靜脈型 | Bluish, compressible; low-flow 藍色、可壓縮；低血流 |
| **Lymphatic** 淋巴型 | Cystic hygroma, macromastia, cobblestone 囊性水瘤、巨乳、鵝卵石樣 |
| **Arteriovenous** 動靜脈型 | High-flow; may cause high-output cardiac failure 高血流；可致高輸出心衰竭 |

### Treatment 治療

| Modality 方式 | Indication 適應症 |
|-------------|-----------------|
| **Observation** 觀察 | Asymptomatic 無症狀 |
| **Compression** 壓迫 | Symptomatic 有症狀 |
| **Sclerotherapy** 硬化劑注射 | First-line for venous/lymphatic malformations 靜脈/淋巴畸形的首選 |
| **Surgery** 手術 | Refractory, large lesions 頑抗性、大病灶 |
| **Laser** 雷射 | Superficial capillary malformations 淺層毛細血管畸形 |

## Superficial Thrombophlebitis 淺層血栓靜脈炎

### Types 類型

| Type 類型 | Features 特色 |
|----------|--------------|
| **Spontaneous** 自發性 | Varicose veins; self-limiting 靜脈曲張；自限性 |
| **Migratory (Trousseau)** 游走性(特魯梭) | May indicate underlying cancer 可能暗示潛在癌症 |
| **Iatrogenic** 醫源性 | IV catheter related 靜脈導管相關 |
| **Suppurative** 化膿性 | Infection; requires antibiotics 感染；需要抗生素 |

### Treatment 治療

| Situation 情況 | Treatment 治療 |
|--------------|--------------|
| **Uncomplicated** 無併發症 | NSAIDs, compression, ambulation |
| **With varicose veins** 伴靜脈曲張 | Consider GSV high ligation if near saphenofemoral junction 如靠近隱股交界考慮高位結紮 |
| **Suppurative** 化膿性 | IV antibiotics, debridement, remove catheter 靜脈抗生素、清創、移除導管 |
| **Extending toward deep system** 蔓延向深層系統 | Anticoagulation consideration 考慮抗凝血 |
