# CH42 神經外科學 (Neurosurgery)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

神經外科學涵蓋顱內壓升高、創傷、腫瘤、血管疾病及功能性疾病的診斷與治療。本章重點包括：顱內壓監測與腦疝類型、Glasgow 昏迷量表（GCS）的應用、脊椎創傷的穩定性評估，以及顱內血管瘤的手術與血管內治療決策。

---

## 顱內壓升高（Raised Intracranial Pressure, ICP）

### 正常值與病理

- **正常ICP：** <span style="color:#34d399">4-14 mmHg</span>
- 持續 ><span style="color:#f87171">20 mmHg</span> 可損傷腦組織
- **Monro-Kellie 原則：** 顱腔為剛性結構，內容物總體積決定ICP

### 顱內壓監測

| 方式 | 說明 |
|------|------|
| **腦室外引流（EVD/Ventriculostomy）** | 可引流CSF降低ICP；可取CSF化驗 |
| **顱內監測導管（Intraparenchymal bolt）** | 置入腦實質；較不具侵入性 |

### 腦疝類型

| 類型 | 說明 |
|------|------|
| **<span style="color:#22d3ee">小腦幕切跡疝</span>（Uncal herniation）** | 顳葉內側向內移位→壓迫中腦；可阻斷大腦後动脉→枕葉梗塞 |
| **<span style="color:#22d3ee">大腦鐮下疝</span>（Subfalcine herniation）** | 扣帶回從大腦鐮下通過；可阻斷大腦前动脉 |
| **<span style="color:#22d3ee">中央小腦幕疝</span>（Central transtentorial herniation）** | 間腦/中腦向下通過小腦幕切跡 |
| **<span style="color:#22d3ee">小腦扁桃體疝</span>（Tonsillar herniation）** | 小腦扁桃體向下通過枕骨大孔 |

### 表現

- 頭痛、噁心、嘔吐、進行性意識下降
- **<span style="color:#f87171">Cushing三聯徵：</span>** 高血壓、心搏過緩、不規則呼吸（顱內壓危機標誌）

### 治療

1. 確保氣道和足夠通氣
2. **<span style="color:#fb923c">Mannitol：</span>** <span style="color:#60a5fa">1g/kg</span> 靜脈推註（20分鐘後生效）；血清滲透壓目標 >300 mOsm/L
3. **過度換氣：** 將 PaCO2 降至 <span style="color:#60a5fa">25-30 mmHg</span>
4. **腦室引流或開顱減壓：** 內科治療失敗時

## Glasgow 昏迷量表（GCS）

| 項目 | 分數 |
|------|------|
| **睜眼** | 自發<span style="color:#34d399">4</span> / 對言語<span style="color:#34d399">3</span> / 對疼痛<span style="color:#fbbf24">2</span> / 無<span style="color:#f87171">1</span> |
| **言語** | 有定向感<span style="color:#34d399">5</span> / 困惑<span style="color:#34d399">4</span> / 不當言語<span style="color:#fbbf24">3</span> / 無法理解<span style="color:#f87171">2</span> / 無<span style="color:#f87171">1</span> |
| **運動** | 遵從指令<span style="color:#34d399">6</span> / 對疼痛定位<span style="color:#34d399">5</span> / 對疼痛回縮<span style="color:#fbbf24">4</span> / 屈曲<span style="color:#f87171">3</span> / 伸直<span style="color:#f87171">2</span> / 無<span style="color:#f87171">1</span> |

- **GCS總分：** 3-15
- **GCS ≤ 8 為<span style="color:#f87171">重度頭部創傷</span>**：需插管保護氣道

## 創傷

### 頭部創傷（Head Trauma）

**處理原則：**

- 防止**<span style="color:#f87171">二次傷害</span>**（缺氧、低血壓）
- 維持收縮壓 ><span style="color:#60a5fa">90 mmHg</span>
- 維持氧合（PaO2 ><span style="color:#60a5fa">60 mmHg</span>）
- **重度頭部創傷：** ICP監測

### 脊椎創傷（Spine Trauma）

**穩定性評估（two-column theory）：**

| 柱子 | 組成 |
|------|------|
| 前柱 | 前縱韌帶、椎體、椎間盤、後縱韌帶前半 |
| 後柱 | 後縱韌帶後半、小關節面、椎弓根、棘突 |

**影像學：**

- CT：用於骨折評估（**金標準**）
- MRI：用於韌帶損傷、椎間盤脫出

## 顱內腫瘤

### 原發性腦腫瘤

| 類型 | 特點 |
|------|------|
| **神經膠質瘤（Gliomas）** | 最常見原發性惡性腦瘤 |
| **腦膜瘤（Meningioma）** | 最常見**良性**腦瘤；女性較多 |
| **神經鞘瘤（Schwannoma）** | 聽神經瘤最常見 |

### 轉移性腫瘤

- **最常見顱內惡性腫瘤**（比原發性更常見）
- **常見原發：** 肺癌、乳腺癌、黑色素瘤、腎細胞癌、結直腸癌

## 功能性神經外科

### 深部腦刺激（DBS）

| 適應症 | 靶點 |
|--------|------|
| **帕金森氏病** | 視丘下核（STN）、GPi |
| **原發性顫抖** | 視丘腹側中間核（VIM） |
| **肌張力不全** | GPi |

### 立體定位放射外科（Stereotactic Radiosurgery）

- **Gamma Knife：** 201個鈷-60源聚焦照射

**適應症：** 腦膜瘤、神經鞘瘤、轉移性腫瘤、動靜脈畸形、三叉神經痛

---

## 顱內血管疾病

### 顱內血管瘤

| 類型 | 特點 |
|------|------|
| **囊狀血管瘤** | 蜘蛛膜下腔出血；高死亡率；治療：血管內線圈栓塞或手術夾閉 |
| **海綿狀血管瘤（Cavernoma）** | 良性；MRI梯度迴聲序列確診 |

### 缺血性中風

- <span style="color:#60a5fa">4.5小時</span>內靜脈 tPA
- <span style="color:#60a5fa">6-8小時</span>內行動脈機械取栓

## Summary

1. **<span style="color:#f87171">GCS ≤ 8 為重度頭部創傷</span>**，需要插管保護氣道
2. **顱內壓升高**：正常 <span style="color:#34d399">4-14 mmHg</span>；持續 ><span style="color:#f87171">20 mmHg</span> 需積極處理
3. **<span style="color:#60a5fa">DBS（深部腦刺激）</span>** 已成為治療帕金森氏症和原發性顫抖的標準照護
3. **創傷性腦和脊椎損傷的主要治療目標：** 防止缺氧和低血壓的二次傷害
4. **囊狀血管瘤的蜘蛛膜下腔出血**：是高死亡率神經外科疾病；血管內治療越來越重要
5. **缺血性中風**：4.5小時內靜脈 tPA，6-8小時內行動脈機械取栓
6. **功能性神經外科**：DBS 已成為治療藥物難治性帕金森氏症和原發性顫抖的標準照護
