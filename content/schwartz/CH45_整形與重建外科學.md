# CH45 整形與重建外科學 (Plastic and Reconstructive Surgery)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

整形與重建外科涵蓋傷口癒合、皮膚修復、先天顱顏異常、燒傷及美容手術。本章以傷口癒合生理為基礎，介紹重建階梯策略，並系統整理顏面部創傷、燒傷處理、壓瘡、乳房重建及顯微手術的關鍵原則。

---

## <span style="color:#60a5fa">傷口癒合（Wound Healing）</span>

### 四階段

| 階段 | 時間 | 關鍵事件 |
|------|------|---------|
| **止血（Hemostasis）** | 立即 | <span style="color:#22d3ee">血小板</span>聚集、<span style="color:#e2e8f0">纖維蛋白</span> clot 形成 |
| **炎症（Inflammation）** | 0-3天 | <span style="color:#c084fc">PMN</span>、<span style="color:#c084fc">巨噬細胞</span>浸潤；清除壞死組織 |
| **增生（Proliferation）** | 3天-2週 | <span style="color:#22d3ee">纖維母細胞</span>、膠原蛋白沉積、血管新生 |
| **重塑（Remodeling）** | 2週-1年 | 膠原蛋白重組；傷口收縮 |

### 影響癒合因素

| 促進癒合 | 延遲癒合 |
|---------|---------|
| 年輕、營養良好 | <span style="color:#f87171">老年人、糖尿病、血管功能不全、肥胖</span> |
| 良好血液供應 | <span style="color:#f87171">感染、菸草、放射治療</span> |
| | <span style="color:#f87171">慢性疾病（糖尿病、血管疾病）</span> |

### 異常疤痕

| 類型 | 特點 |
|------|------|
| **肥厚性疤痕（Hypertrophic scar）** | 6個月後停止生長；在傷口範圍內 |
| **<span style="color:#f87171">疤痕疙瘩（Keloid）</span>** | 超過傷口邊界持續生長；<span style="color:#f87171">復發率高</span> |

---

## <span style="color:#60a5fa">皮膚切口與縫合原則</span>

### Langer線（皮膚張力線）

- 切口平行於張力線 → 疤痕較不明顯
- 垂直於張力線 → 疤痕變寬

### 切口技巧

- 表皮和淺層真皮：銳利切除
- 切口垂直於皮膚表面
- 避免在皮下組織造成多條路徑

### 縫合原則

- **真皮層是最重要的閉合層：** 包含癒合元素（血液供應、細胞）
- 深層真皮縫合（可吸收或不可吸收）
- 避免傷口邊緣台階（step-off）
- 表皮縫線：淺層 → <span style="color:#34d399">5-7天</span>拆除；深層 → <span style="color:#34d399">7-10天</span>

---

## <span style="color:#60a5fa">重建策略</span>

### 重建階梯（Reconstructive Ladder）

1. 延遲閉合
2. 一次癒合
3. 二次癒合
4. 皮膚移植
5. 組織擴張
6. 局部皮瓣
7. 區域皮瓣
8. <span style="color:#60a5fa">游離皮瓣</span>

### 皮瓣類型

| 類型 | 說明 |
|------|------|
| **局部皮瓣（Local flap）** | 傷口旁組織；旋轉、推進、易位 |
| **區域皮瓣（Regional flap）** | 鄰近區域 |
| **遠端皮瓣（Distant flap）** | 距離較遠（如游離皮瓣）|
| **<span style="color:#60a5fa">游離皮瓣（Free flap）</span>** | 微血管吻合；可移植到任意位置 |

## <span style="color:#60a5fa">顏面部創傷</span>

### 臉部切片原則

- 遵循自然皺紋/張力線
- 避免跨越美學單位（如眉毛、眼皮邊緣）

### 額竇骨折

| 類型 | 治療 |
|------|------|
| **前壁線性骨折（無位移）** | 保守 |
| **前壁凹陷骨折** | 開放復位 |
| **後壁骨折** | 考慮腦外科會診；可能需要顱底重建 |

### 眼眶骨折（Orbital Fractures）

**特點：**

- 眼球內陷、複視、眶下神經感覺減退
- 類型：眼眶底（blowout）、內壁、上壁

**手術適應症：**

- Large defect (>50% floor)
- 眼球內陷<span style="color:#f87171">>2mm</span>
- 肌肉嵌頓

### 顴骨復合體骨折（Zygomaticomaxillary Complex）

- **tripod fracture（四點骨折）：** <span style="color:#22d3ee">顴骨、額骨、上頜骨、顳骨</span>
- **治療：** <span style="color:#f87171">ORIF</span>

### 上頜骨/鼻眶篩竇骨折（NOE/Midface fractures）

- 複雜創傷
- **治療：** 手術重建

### 下頜骨骨折

- **治療：** <span style="color:#f87171">ORIF</span>（開放復位內固定）
- **配件：** 牙弓夾板、頜間固定（MMF）

---

## <span style="color:#60a5fa">先天性顱顏異常</span>

### 唇腭裂（Cleft Lip and Palate）

**治療：** 多專科團隊（整形外科、口腔顎面外科、耳鼻喉科、語言治療、牙科）

**序列治療：**

- 嬰兒期<span style="color:#60a5fa">唇裂修復</span>
- <span style="color:#60a5fa">腭裂修復</span>（9-18月）
- 言語評估
- 學齡前期鼻整形

### Robin序列（Robin Sequence）

- <span style="color:#22d3ee">小頜畸形、舌後墜、呼吸道阻塞</span>

**治療選項：**

- 俯臥位
- 舌-唇黏連
- 下頜骨延長（distraction）
- 氣管切開術

### 顱縫早閉（Craniosynostosis）

- 一或多條顱縫過早閉合
- **治療：** 顱骨切開術

### 血管瘤（Hemangioma）

- 嬰兒期常見
- **<span style="color:#60a5fa">高風險血管瘤一線治療：</span>** <span style="color:#fb923c">Oral propranolol</span>（比類固醇副作用更少）

---

## <span style="color:#f87171">燒傷</span>

### 燒傷深度分類

| 深度 | 名稱 | 癒合時間 | 疤痕 |
|------|------|---------|------|
| **I度** | 表皮 | <span style="color:#34d399">5-7天</span> | 無 |
| **II度** | 淺層真皮 | <span style="color:#34d399">7-14天</span> | 可能輕微 |
| **III度** | 深層真皮 | 2-4週 | 明顯疤痕 |
| **IV度** | 全層/更深 | <span style="color:#f87171">不自行癒合</span> | 攣縮 |

### 燒傷評估：Rule of Nines（成人）

| 部位 | 百分比 |
|------|--------|
| 頭頸 | <span style="color:#60a5fa">9%</span> |
| 每上肢 | <span style="color:#60a5fa">9%</span> |
| 每下肢 | <span style="color:#60a5fa">18%</span> |
| 軀幹前面 | <span style="color:#60a5fa">18%</span> |
| 軀幹後面 | <span style="color:#60a5fa">18%</span> |
| 會陰 | <span style="color:#60a5fa">1%</span> |

### 燒傷處理

**液體復甦：**

- <span style="color:#60a5fa">Parkland公式：</span>4mL × 體重(kg) × %燒傷面積（第一個24小時）

**傷口處理：**

- 局部抗菌藥膏（<span style="color:#fb923c">Silver sulfadiazine</span>）
- 生物敷料

**其他：**

- **切除和植皮：** 早期切除（deep burns）
- **感染預防：** 破傷風預防

---

## <span style="color:#60a5fa">壓瘡（Pressure Sores）</span>

### 病因

- 長期壓迫 → 組織缺血 → 壞死
- **常見部位：** <span style="color:#22d3ee">骶骨、大轉子、足跟、坐骨結節</span>

### 治療

- 減壓（翻身、特殊床墊）
- 清創
- **重建手術（皮瓣覆蓋）：** 筋膜皮瓣、肌皮瓣

---

## <span style="color:#60a5fa">乳房重建</span>

### 方式

| 方式 | 說明 |
|------|------|
| **植入物重建（Implant-based）** | 擴張器→植入物；兩階段或一次完成 |
| **自體組織重建（Autologous）** | 游離皮瓣（<span style="color:#60a5fa">DIEP flap</span>、<span style="color:#60a5fa">TRAM flap</span>、SIEA flap、臀部皮瓣）|
| **混合重建（Hybrid）** | 植入物＋自體脂肪移植 |

### 自體組織皮瓣

| 皮瓣 | 組織來源 |
|------|---------|
| **<span style="color:#60a5fa">DIEP（深下腹壁穿支皮瓣）</span>** | 下腹壁游離皮瓣；<span style="color:#34d399">保留肌肉</span> |
| **<span style="color:#60a5fa">TRAM（橫向腹直肌皮瓣）</span>** | 下腹壁；帶部分肌肉 |
| **游離臀部皮瓣（SGAP/IGAP）** | 臀部穿支皮瓣 |

---

## <span style="color:#60a5fa">軀幹與腹壁重建</span>

### 腹壁疝氣

- 網片修補（合成或生物網片）
- 組織結構分離技術（Component separation）

### 胸壁重建

- 惡性腫瘤切除後
- 網片或肌肉皮瓣覆蓋

---

## <span style="color:#60a5fa">會陰部重建</span>

### 適應症

- 直腸癌術後
- 婦科惡性腫瘤術後
- 先天性異常

---

## <span style="color:#60a5fa">醫學美容</span>

### 臉部美容

| 手術 | 說明 |
|------|------|
| **拉皮（Rhytidectomy）** | 面部提升 |
| **眼瞼整形（Blepharoplasty）** | 眼皮手術 |
| **鼻整形（Rhinoplasty）** | 鼻子整形 |
| **下巴整形（Mentoplasty）** | 下巴增大或減小 |

### 臉部填充/注射

- **<span style="color:#fb923c">BoNTA（肉毒桿菌素）</span>：** 動力紋
- **玻尿酸：** 組織填充
- **自體脂肪移植**

### 乳房美容

- **隆乳（Augmentation mammaplasty）**
- **縮胸（Mammaplasty/Reduction）**
- **提乳（Mastopexy）**

### 身體輪廓

- **抽脂（Suction lipectomy）**
- **腹部整形（Abdominoplasty）**
- **手臂/大腿整形**

---

## <span style="color:#60a5fa">顯微手術與超顯微手術</span>

### 游離皮瓣

- 將皮瓣的血管與接受區血管吻合
- 需要顯微縫線（<span style="color:#60a5fa">9-0, 10-0</span>）
- 失敗率低（<span style="color:#34d399"><5%</span>）

### 超顯微手術（Supramicrosurgery）

- 直徑<span style="color:#60a5fa">0.3-0.8mm</span>血管
- 用於<span style="color:#22d3ee">淋巴水腫</span>手術（lymphaticovenous anastomosis）

---

## Summary

- <span style="color:#60a5fa">傷口癒合四階段：</span>止血→炎症→增生→重塑；糖尿病/血管疾病/吸菸延遲癒合
- <span style="color:#60a5fa">重建階梯：</span>從延遲閉合到游離皮瓣；游離皮瓣是可移植到任意位置的微血管手術
- <span style="color:#60a5fa">唇腭裂：</span>多專科團隊序列治療；Robin序列可用俯臥位到氣管切開術處理
- <span style="color:#60a5fa">高風險血管瘤一線治療：</span><span style="color:#fb923c">Oral propranolol</span>（比類固醇副作用更少）
- <span style="color:#f87171">燒傷深度判斷：</span>IV度燒傷不自行癒合，需要切除和植皮；Parkland公式計算液體復甦
- <span style="color:#60a5fa">DIEP皮瓣：</span>乳房重建的金標準自體組織方式，保留腹直肌
- <span style="color:#60a5fa">顯微手術：</span>游離皮瓣失敗率<5%；超顯微手術用於淋巴水腫（0.3-0.8mm血管）
