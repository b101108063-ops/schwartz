# CH11 手部外科 (Surgery of the <span style="color:#22d3ee">Hand</span> and <span style="color:#22d3ee">Wrist</span>)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## Key Points

1. **Hand infections** require prompt treatment; tetanus prophylaxis is essential for all hand wounds
2. **Fractures and dislocations** require evaluation of displacement, rotation, and angulation; MP joints at 90°, IP joints at 0° (intrinsic plus position)
3. **Scaphoid fractures** are prone to nonunion due to precarious blood supply; treat nondisplaced with cast, consider ORIF for displaced
4. **Flexor and extensor tendon injuries** require meticulous repair and early mobilization
5. **Compartment syndrome of the hand** requires urgent fasciotomy
6. **Replantation** should be considered for thumb loss, multiple digit loss, or wrist-level amputation

## 手部感染 (<span style="color:#22d3ee">Hand</span> Infections)

### 治療原則

- **<span style="color:#fb923c">Tetanus prophylaxis</span>（破傷風預防）：**
  - <span style="color:#34d399">Clean</span> wounds with ≥3 prior <span style="color:#fb923c">tetanus toxoid</span> doses → TD booster
  - Other wounds → TD + TIG (<span style="color:#fb923c">tetanus immunoglobulin</span>)
- **Empiric antibiotics：** first-generation cephalosporin (MSSA coverage)；human bites 需覆蓋 Pasteurella
- **早期引流 (early drainage)** for abscesses
- **抬高患肢**

### 常見感染

| 感染類型 | 內容 |
|---|---|
| **<span style="color:#60a5fa">Paronychia</span>（甲溝炎）** | 指甲周圍感染；warm soaks, antibiotics, I&D if abscess |
| **<span style="color:#60a5fa">Felon</span>（指腹膿腫）** | 指尖膿腫；I&D through lateral incision |
| **<span style="color:#60a5fa">Cellulitis</span>（蜂窩組織炎）** | 口服 antibiotics；IV if severe |
| **Deep space infection（深層空間感染）** | 需緊急引流；可能導致功能障礙 |
| **Human bites（人咬傷）** | Eikenella corrodens；<span style="color:#fb923c">amoxicillin-clavulanate</span> |
| **<span style="color:#22d3ee">Tendon</span> sheath infection（腱鞘感染）** | 緊急引流；否則肌腱壞死 |

## 手部骨折與脫位 (Fractures and Dislocations)

### 評估要點

評估骨折重點：
- **Deformity：** displacement, rotation, angulation
- **Comminution** and number of fragments
- **Open vs. closed**
- **Associated neurovascular injury**

### 常見骨折

| 骨折類型 | 治療 |
|---|---|
| **Distal phalanx tuft fractures** | 保守治療；保護 distal tuft |
| **Phalangeal fractures (displaced)** | <span style="color:#60a5fa">ORIF</span> or closed reduction + splinting |
| **<span style="color:#22d3ee">Scaphoid</span> fractures** | 拇指 spica cast (nondisplaced)；<span style="color:#60a5fa">ORIF</span> (displaced) — 注意避免骨壞死 |
| **<span style="color:#22d3ee">Metacarpal</span> neck fractures ("boxer's fracture")** | 保守治療或 closed reduction；<span style="color:#60a5fa">Jahss maneuver</span> |
| **<span style="color:#60a5fa">Bennett fracture</span>** | <span style="color:#60a5fa">ORIF</span>（不穩定） |
| **<span style="color:#60a5fa">Rolando fracture</span>** | <span style="color:#60a5fa">ORIF</span>（always） |
| **Distal <span style="color:#22d3ee">radius</span> fractures** | Closed reduction + cast；<span style="color:#60a5fa">ORIF</span> if unstable |

### <span style="color:#22d3ee">Scaphoid</span> 骨折的特殊考量

**血供特點：** 近端血供最差（retrograde blood supply）。可達 20% nonunion 風險。

**治療：**
- Nondisplaced → 拇指 spica cast 6-12 weeks
- Displaced → <span style="color:#60a5fa">ORIF</span>（Herbert screw or headless compression screw）
- 延遲診斷 → 可能需 <span style="color:#22d3ee">bone</span> graft

### <span style="color:#60a5fa">Jahss Maneuver</span>

用於复位 <span style="color:#22d3ee">metacarpal</span> neck fractures（boxer's fracture）：

1. 屈曲 MP joint 至 90°
2. 向下按压 proximal phalanx base
3. 向上推 distal fragment

## 肌腱損傷 (<span style="color:#22d3ee">Tendon</span> Injuries)

### <span style="color:#60a5fa"><span style="color:#22d3ee">Flexor</span> <span style="color:#22d3ee">Tendon</span></span> 修復

**原則：**
- **早期被動/主動運動 (early mobilization)** — 減少粘連
- **4-strand repair technique** preferred
- **Pulley preservation** essential

**術後康復：**
- 屈肌腱：place-and-hold exercises, blocking exercises
- 恢復時間：8-12 weeks for full use

### <span style="color:#60a5fa"><span style="color:#22d3ee">Extensor</span> <span style="color:#22d3ee">Tendon</span></span> 修復

| Zone | 損傷位置 | 治療 |
|---|---|---|
| **I (<span style="color:#22d3ee">DIP</span>)** | <span style="color:#60a5fa">Mallet finger</span> | 伸直夾板 6-8 weeks |
| **III (<span style="color:#22d3ee">PIP</span>)** | <span style="color:#60a5fa"><span style="color:#60a5fa">Boutonniere</span> deformity</span> | 伸直夾板；可能需手術 |
| **V (MP)** | 中央 slip 損傷 | 手術修復 |

### <span style="color:#c084fc">Laceration</span> at Different Levels

- **No man's land (Zone II)：** <span style="color:#60a5fa">FDS</span> and <span style="color:#60a5fa">FDP</span> 同時受損。最具挑戰的手術區域。
- **<span style="color:#22d3ee">Tendon</span> grafting** vs. **primary repair** depending on injury
- **Free <span style="color:#22d3ee">tendon</span> graft** for extensive damage

## 腕部韌帶損傷 (<span style="color:#22d3ee">Wrist</span> <span style="color:#22d3ee">Ligament</span> Injuries)

### 舟月韌帶損傷 (<span style="color:#60a5fa">Scapholunate</span> <span style="color:#22d3ee">Ligament</span> Injury)

- **Mechanism：** Fall on outstretched <span style="color:#22d3ee">hand</span> (FOOSH)
- **Radiographs：** 失去 Gilula's arcs, Terry Thomas sign（<span style="color:#60a5fa">scapholunate</span> gap >3mm）
- **Arthroscopy** gold standard for diagnosis

**治療：**
- Partial → arthroscopic <span style="color:#60a5fa">debridement</span>
- Complete → <span style="color:#22d3ee">ligament</span> repair or reconstruction

### <span style="color:#60a5fa">Mayfield</span> Classification (Progressive <span style="color:#60a5fa">Perilunate</span> Dislocation)

| Type | 內容 |
|---|---|
| **I** | <span style="color:#60a5fa">Scapholunate</span> <span style="color:#c084fc">disruption</span> |
| **II** | Lunocapitate <span style="color:#c084fc">disruption</span> |
| **III** | Lunotriquetral <span style="color:#c084fc">disruption</span> |
| **IV** | <span style="color:#22d3ee">Lunate</span> dislocation into <span style="color:#60a5fa"><span style="color:#22d3ee">carpal</span> tunnel</span> |

**需评估：** median <span style="color:#22d3ee">nerve</span> function（可能需要緊急減壓）

## 腔室綜合徵 (<span style="color:#60a5fa">Compartment Syndrome</span>)

### 臨床表現（5 P's）

- **Pain：** out of proportion, pain with passive stretch
- **Paresthesias**
- **Paralysis**
- **Pallor**
- **Pulselessness**（晚期）

### 診斷

- **臨床評估**（most important）
- **<span style="color:#60a5fa">Compartment pressure</span>：** >30 <span style="color:#f87171">mmHg</span> 或 <span style="color:#60a5fa">Δ pressure</span> <30 <span style="color:#f87171">mmHg</span>（diastolic BP – <span style="color:#60a5fa">compartment pressure</span>）

### 治療

- **緊急筋膜切開術 (<span style="color:#60a5fa">Fasciotomy</span>)** — 4 compartments of <span style="color:#22d3ee">hand</span>
- **傷口延遲關閉 (delayed closure)** or <span style="color:#22d3ee">skin</span> graft

## 再植與移植 (<span style="color:#60a5fa">Replantation</span> and Transplantation)

### 適應症

| 情況 | 建議 |
|---|---|
| **Single digit <span style="color:#60a5fa">amputation</span> (not thumb)** | 通常不建議 replant（功能結局差） |
| **Thumb <span style="color:#60a5fa">amputation</span>** | 建議 replant（功能重要） |
| **Multiple digit <span style="color:#60a5fa">amputation</span>** | 考慮 replant |
| **<span style="color:#22d3ee">Wrist</span>-level or more proximal** | 考慮 replant（可能有好功能） |
| **<span style="color:#34d399">Clean</span> cut (guillotine)** | 更好的候選 |

### 禁忌症

- 嚴重 crush injury
- Prolonged warm ischemia (<span style="color:#f87171">>12h</span>) or cold ischemia (<span style="color:#f87171">>24h</span>)
- 嚴重其他創傷
- 精神問題

### 再植技術

順序：
1. 先固定骨骼（K-wires or plates）
2. 修復屈/伸肌腱
3. 修復神經（primary neurorrhaphy）
4. 修復血管（首要 — 恢復血流）
5. 修復皮膚（可能需植皮）

## 常見手部疾病

### 腕管綜合徵 (<span style="color:#60a5fa"><span style="color:#22d3ee">Carpal</span> Tunnel</span> Syndrome)

- **正中神經在腕部受壓**
- **表現：** 拇指/食指/中指麻木、夜間麻木、<span style="color:#60a5fa">thenar</span> <span style="color:#c084fc">atrophy</span>
- **診斷：** Tinel's sign, Phalen's test, EMG/NCS
- **治療：**
  - 保守 → <span style="color:#22d3ee">wrist</span> splint, NSAIDs
  - 手術 → <span style="color:#60a5fa"><span style="color:#22d3ee">carpal</span> tunnel</span> release（open or endoscopic）

### 尺神經麻痺 (Ulnar <span style="color:#22d3ee">Nerve</span> Palsy)

- **Claw <span style="color:#22d3ee">hand</span> deformity：** MP 過伸，IP 屈曲（lumbricals 功能喪失）
- **Grip weakness**
- **治療：** ulnar <span style="color:#22d3ee">nerve</span> decompression/transposition

### 扳機指 (<span style="color:#60a5fa">Trigger Finger</span>)

- **A1 pulley thickening → <span style="color:#60a5fa">FDP</span> <span style="color:#22d3ee">tendon</span> 卡住**
- **表現：** clicking, locking, pain
- **治療：** steroid injection, A1 pulley release

### <span style="color:#60a5fa">De Quervain</span>'s Tenosynovitis

- **First <span style="color:#22d3ee">dorsal</span> compartment（abductor pollicis longus, <span style="color:#22d3ee">extensor</span> pollicis brevis）炎症**
- **Finkelstein test positive**
- **治療：** thumb spica splint, NSAIDs, steroid injection

## 手部康復原則 (Rehabilitation)

### 夾板原則 (Splinting)

| 情況 | 位置 |
|---|---|
| **<span style="color:#60a5fa"><span style="color:#22d3ee">Flexor</span> <span style="color:#22d3ee">tendon</span></span> repair** | <span style="color:#60a5fa">Intrinsic plus</span>（MP 90°, IP 0°） |
| **<span style="color:#60a5fa"><span style="color:#22d3ee">Extensor</span> <span style="color:#22d3ee">tendon</span></span> repair** | 伸直位 |
| **<span style="color:#22d3ee">Scaphoid</span> fracture** | 拇指 spica |
| **Colles' fracture** | 腕部伸直位 |
| **Protection after surgery** | 根據手術類型 |

### 運動康復

- **Early mobilization**（within limits of repair）
- **Place-and-hold exercises** for <span style="color:#22d3ee">flexor</span> tendons
- **肌力和功能訓練 (strengthening)**
- **回歸運動：** 通常 4-6 months
