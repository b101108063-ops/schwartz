# CH18 乳房 (The Breast)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 乳房解剖學 (Breast Anatomy)

### 解剖位置

- **位置：** 胸壁（第 2-6 肋骨），位於皮膚和皮下組織深層。
- **象限：** Upper outer（最常見癌症部位）、upper inner、lower outer、lower inner、central。
- **Retroglandular (subglandular)** vs. **retromuscular (submuscular)** placement。

### 結構

- **15-20 葉**，呈放射狀排列。
- **Lobules** → 產生乳汁的腺體。
- **Ducts** → lactiferous sinuses → 乳頭。
- **Cooper's ligaments** → 結締組織支撐。

### 淋巴引流

- **腋窩淋巴結**（主要引流 — levels I, II, III）。
- **內乳淋巴結**（內側腫瘤）。
- **鎖骨上淋巴結。**
- **胸肌間（Rotter's）淋巴結。**

---

## 乳房影像學 (Breast Imaging)

### 乳房攝影

- **篩檢：** 40-50 歲開始（每年或隔年）。
- **診斷：** 懷疑發現、觸摸到的腫塊。
- **BI-RADS 分類：** 0-6（0=不完整，6=已確認惡性）。
- **Microcalcifications：** 常與 DCIS 相關。

### 超音波

- **乳房攝影的輔助**（緻密乳房）。
- **囊腫 vs. 實心** 鑑別。
- **影像引導切片**（非觸摸得到的病變）。

### MRI

- **高敏感度** 但特異性較低。
- **適應症：**
  - 隱匿原發（腋窩淋巴結陽性，乳房原發不明）。
  - 新輔助治療反應評估。
  - BRCA 突變攜帶者（補充篩檢）。
  - 乳房植入物評估。
  - 術後重建。
- **注意：** COMICE trial — MRI 不能減少再手術率。

### 影像引導切片

| 方式 | 適應症 |
|------|--------|
| **Ultrasound-guided** | 超音波可見的腫塊 |
| **Stereotactic** | Microcalcifications、architectural distortion |
| **MRI-guided** | 僅 MRI 可見的發現 |

## 乳房切片 (Breast Biopsy)

### 細針抽吸 (FNA)

- **22-gauge needle**，10 mL 注射器。
- 細胞學評估。
- **敏感度/特異度：** 當臨床和乳房攝影懷疑時可達 ~100%。
- **限制：** 無法區分侵犯性 vs. 原位癌。

### 核心切片 (CNB)

- **14-gauge needle** (Tru-Cut)。
- **優於 FNA** — 保留組織架構。
- 可區分**侵犯性 vs. 原位**癌。
- Vacuum-assisted（8-10 gauge）：每次插入可取多個樣本。

### 切除性切片

- 當經皮切片不足時的**黃金標準**。
- **標本 X 光**（非觸摸得到的病變）。

### 標本定位

- **Hookwire localization**（鉤絲定位）— 非觸摸得到的病變。
- **Clip placement**（夾子放置）— 切片後供日後定位。

## 乳房癌症生物標記與亞型 (Breast Cancer Biomarkers & Subtypes)

###  essential Biomarkers

| 生物標記 | 檢測 | 臨床意義 |
|---------|------|---------|
| **ER (Estrogen receptor)** | IHC | ER+ → 內分泌治療有效 |
| **PR (Progesterone receptor)** | IHC | PR+ → 較好預後 |
| **HER2/neu** | IHC, FISH | HER2+ → 抗 HER2 治療（trastuzumab） |
| **Ki-67** | IHC | 增殖指數 — 越高預後越差 |

### 分子亞型（Intrinsic）

| 亞型 | ER | PR | HER2 | Ki-67 | 治療 |
|------|----|----|------|-------|------|
| **Luminal A** | + | + | - | Low | 內分泌 ± 化療 |
| **Luminal B (HER2-)** | + | -/+ | - | High | 內分泌 + 化療 |
| **Luminal B (HER2+)** | + | -/+ | + | Any | 化療 + 抗 HER2 + 內分泌 |
| **HER2-enriched** | - | - | + | High | 化療 + 抗 HER2 |
| **Basal-like (TNBC)** | - | - | - | High | 化療 |

### 基因表達檢測

| 檢測 | 適應症 | 臨床應用 |
|------|--------|---------|
| **Oncotype DX (21-gene)** | 節結陰性、ER+ | 復發分數 → 化療獲益 |
| **MammaPrint (70-gene)** | Stage I-II、節結陰性 | 高/低風險分類 |
| **DCIS Score** | DCIS | 10 年復發風險 |

## 原位癌 (Stage 0) (In Situ Breast Cancer)

### DCIS (Ductal Carcinoma In Situ)

**表現：** 通常為乳房攝影發現（microcalcifications），少數可觸摸。

**治療選擇：**

| 選項 | 適應症 |
|------|--------|
| **Lumpectomy + radiation** | 有限疾病（單一象限） |
| **Lumpectomy alone** | 選定的低等級、≤2.5 cm、邊界 ≥3 mm（ECOG 5194） |
| **Mastectomy** | 廣泛 DCIS（>4 cm、多象限） |
| **± Sentinel node biopsy** | 乳房切除時（20% 升級為侵犯性） |

**放療：** SSO/ASTRO/ASCO 指南 — BCS + 放療需 **2 mm 邊界**。

**輔助內分泌治療：**
- **Tamoxifen** 用於 ER+ DCIS（NSABP B-24）。
- 為期 5 年。

**局部復發：** 10-15%（50% 侵犯性，50% DCIS）。

### LCIS (Lobular Carcinoma In Situ)

- **不是真正的惡性腫瘤** — 風險標記。
- 侵犯性癌症的**雙側風險**（25-35%）。
- **治療選擇：**
  - 觀察。
  - 化學預防（tamoxifen, raloxifene）。
  - 雙側乳房切除（少見）。
- **不需要切除** — 瀰漫性雙側受累。

## 早期侵犯性乳癌 (Stage I-II) (Early Invasive Breast Cancer)

### 手術選擇

| 手術 | 適應症 | 局部復發 |
|------|--------|---------|
| **Breast-conserving surgery (BCS) + radiation** | 單灶、早期 | 放療後 1-2%/年 |
| **Mastectomy** | 多灶、大腫瘤、患者偏好 | <2% |
| **Skin-sparing mastectomy** | 預防、特定癌症 | 與傳統相當 |
| **Nipple-sparing mastectomy** | 選定的患者 | 需要仔細選擇患者 |

### BCS 原則

- **廣泛局部切除**，陰性邊界。
- **邊界狀態：** SSO/ASTRO 指南 — 腫瘤上無墨水（No ink on tumor）。
- **禁忌症：** 多灶性疾病、BRCA 突變（相對）、先前胸部放療、妊娠（相對）、膠原血管疾病（相對）。

### NSABP B-06 Trial（關鍵發現）

- **相等存活：** BCS + 放療 vs. 乳房切除。
- **20 年追蹤：** DFS 或 OS 無差異。
- **同側復發：** BCS alone 14.3% vs. BCS + 放療 2-4%。
- **關鍵：** 所有 BCS 患者都應該接受放療。

### BCS 後放療

- **EBCTCG 統合分析：**
  - 15 年存活獲益：節結陰性 5.1%、節結陽性 7.1%。
  - 減少局部復發和遠處轉移。
- **可省略放療的選定患者：** Age >70、小腫瘤 ER+、使用 tamoxifen（CALGB C9343）。

## 腋下淋巴結處理 (Axillary Lymph Node Management)

### 前哨淋巴結切片 (SLNB)

**適應症：**
- 臨床節結陰性（cN0）。
- T1-T2 腫瘤。
- 未接受過新輔助化療（除非化療前已證實節結陰性）。

**技術：**
1. 術前行淋巴閃爍顯影（technetium-sulfur colloid）。
2. 術中使用藍染（isosulfan blue 或亞甲藍）。
3. 識別第一站淋巴結。

**成功率：** 95-98%。

**發現與處理：**

| SLNB 結果 | 處理 |
|-----------|------|
| **陰性** | 不需進一步腋窩手術 |
| **1-2 微轉移** | 可觀察（ACOSOG Z0011） |
| **≥3 轉移** | 完成性腋窩廓清 |
| **Gross extracapsular extension** | 考慮廓清 |

### ACOSOG Z0011 Trial

- **cT1-2, cN0** 患者伴 1-2 個陽性的 SLN。
- 有無完成性 ALND **局部復發或存活無差異**。
- **標準照護：** 選定患者可省略完成性 ALND。

### 腋窩廓清層次

| 層次 | 位置 |
|------|------|
| **I** | 胸大肌外側 |
| **II** | 胸大肌下方 |
| **III** | 胸大肌內側 |

## 局部晚期乳癌 (Stage III) (Locally Advanced Breast Cancer)

### 定義

- T4 腫瘤（侵犯胸壁/皮膚）。
- N2-N3 淋巴結疾病。
- 發炎性乳癌。

### 治療方法

**多模式治療 — 順序方法：**

```
新輔助化療 → 手術 → 放療 → 輔助治療
```

### 新輔助化療

- **目標：** 縮小腫瘤以利手術/BCS。
- **典型方案：** Anthracycline + taxane（AT）、AC-T。
- **HER2+：** 加用 trastuzumab + pertuzumab。
- **病理完全緩解 (pCR)：** 最佳預後指標。

### 發炎性乳癌

- **臨床：** 快速發病、紅斑、"peau d'orange"、無明確腫塊。
- **T 分類：** T4d。
- **診斷：** 臨床 + 病理（dermal lymphatic invasion）。
- **治療：** 新輔助化療 → 乳房切除（不做 BCS）+ 放療。
- **預後：** 比非發炎性 LABC 差。

---

## 轉移性乳癌 (Stage IV) (Metastatic Breast Cancer)

### 表現

- 最常見：骨 > 肺 > 肝 > 腦。
- 可表現為區域淋巴結復發。

### 手術考量

- **原發腫瘤：** 可考慮乳房切除以局部控制。
- **轉移灶：** 通常為全身治療。
- **緩和手術：** 處理併發症（病理性骨折、脊髓壓迫）。

### 治療

- **內分泌治療**（ER+ 疾病）。
- **化療**（ER-、侵襲性、有症狀）。
- **標靶治療**（抗 HER2、CDK4/6 抑制劑、PARP 抑制劑）。
- **骨骼導向治療**（雙磷酸鹽、denosumab）。

## 輔助治療概述 (Adjuvant Therapy Overview)

### 風險評估工具

- **Adjuvant! Online。**
- **Nottingham Prognostic Index。**
- **PREDICT。**

### 化療適應症

| 因子 | 考量 |
|------|------|
| **ER 狀態** | ER- → 建議化療 |
| **HER2 狀態** | HER2+ → 加用 trastuzumab |
| **腫瘤大小** | >0.5-1 cm 考慮化療 |
| **節結狀態** | 節結+ → 建議化療 |
| **分化** | 低分化 → 考慮化療 |
| **Oncotype DX/MammaPrint** | 可幫助指導決策 |

### 內分泌治療 (ER+)

| 藥物 | 族群 | 持續時間 |
|------|------|---------|
| **Tamoxifen** | 停經前/後 | 5-10 年 |
| **Aromatase inhibitors (AI)** | 僅停經後 | 5-10 年 |
| **Ovarian suppression** | 停經前（高風險） | 與 AI 或 tamoxifen 合併 |

### 抗 HER2 治療

- **Trastuzumab**（Herceptin）— HER2+ 輔助 1 年。
- **Pertuzumab** — 與 trastuzumab 合併用於較高風險。
- **心臟毒性監測**（MUGA scan/echocardiogram）。

## 特殊考量 (Special Considerations)

### 懷孕相關乳癌

- **分期：** 避免 CT/MRI，除非必要。
- **手術：** 任何孕期都安全。
- **放療：** 懷孕期間避免。
- **化療：** 第一孕期後安全（anthracyclines）。
- **內分泌：** 懷孕期間禁用。

### 男性乳癌

- **罕見**（<1% 的乳癌）。
- **通常 ER+。**
- **表現：** 乳頭下腫塊。
- **治療：** Modified radical mastectomy ± SLNB。

### Paget's Disease of Nipple

- **臨床：** 乳頭濕疹樣改變。
- **通常與潛在 DCIS 或侵犯性癌症相關。**
- **治療：** 根據潛在病變。
