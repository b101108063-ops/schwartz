# CH15 輸血治療與圍手術期止血 (Transfusion Therapy and Perioperative Hemostasis)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 輸血基礎 (Blood Transfusion Basics)

### 輸血適應症

- **傳統準則（已不再有效：** Hct >30%
- **目前做法：**
  - 有症狀的貧血
  - 重大心臟疾病
  - 危重症需要增加氧氣攜帶能力
  - **決定閾值：Hgb ≤7 g/dL 或 Hct ≤21%**

### 血品

| 血品 | 內容 | 用途 |
|------|------|------|
| **Packed RBCs** | 紅血球、血漿、白血球 | 貧血、失血 |
| **Fresh Frozen Plasma (FFP)** | 所有凝血因子 | 凝血病、warfarin 逆轉 |
| **Platelets** |  Buffy coat、血漿 | 血小板減少症 |
| **Cryoprecipitate** | Fibrinogen、Factor VIII、vWF、Factor XIII | 低纖維蛋白原血症 |
| **Whole Blood** | 所有成分 | 大量出血 |

### 輸血反應

| 類型 | 機制 | 症狀 | 治療 |
|------|------|------|------|
| **Febrile non-hemolytic** | Cytokines, WBC antibodies | Fever, chills | 停止輸血、退燒藥 |
| **Allergic** | IgE to donor proteins | Urticaria, pruritus | 抗組織胺 |
| **Acute hemolytic** | ABO incompatibility | 背痛、低血壓、血紅蛋白尿、DIC | 停止輸血、輸液、支持性照護 |
| **Delayed hemolytic** | Anamnestic response (5-7 days) | 發燒、黃疸、低 haptoglobin | 觀察；可能需要輸血 |
| **TRALI** | Donor anti-HLA/neutrophil antibodies | 呼吸窘迫、低氧血症 | 停止輸血、支持性照護 |
| **TACO** | Volume overload | 肺水腫 | 利尿劑 |
| **Bacterial contamination** | Cold-growing organisms (Yersinia) | 休克、高燒 | 經驗性抗生素 |

### 輸血傳染風險

| 病原 | 每單位風險 |
|------|-----------|
| **HIV** | 1:1,900,000 |
| **HBV** | 1:137,000 |
| **HCV** | 1:1,000,000 |
| **Bacterial** | 比病毒高 50-250× |

## 凝血檢驗 (Coagulation Testing)

### 傳統檢驗

| 檢驗 | 測量 | 正常範圍 |
|------|------|---------|
| **Platelet count** | 血小板數量 | 150,000-400,000/μL |
| **PT/INR** | 外在路徑（Factors VII, X, V, II, I） | INR 0.8-1.2 |
| **aPTT** | 內在路徑（Factors XII, XI, IX, VIII, X, V, II, I） | 25-35 seconds |
| **Thrombin time** | 纖維蛋白原轉換 | 10-15 seconds |

### 血小板計數閾值

| 血小板計數 | 臨床意義 |
|-----------|---------|
| >1,000,000/μL | 出血或血栓風險 |
| <50,000/μL | 重大手術出血風險 |
| <30,000/μL | 小手術出血風險 |
| <20,000/μL | 自發性出血風險 |

### 黏彈性檢測 (TEG/ROTEM)

| 參數 | 代表意義 | 延長表示 |
|------|---------|---------|
| **R (reaction time)** | 血塊起始 | 因子缺乏 |
| **K (kinetics)** | 血塊傳播 | 低纖維蛋白原血症、因子缺乏 |
| **Alpha angle** | 纖維蛋白 cross-linking | 纖維蛋白原 level、血小板功能 |
| **MA (max amplitude)** | 血塊強度 | 血小板功能、纖維蛋白原 |
| **LY30** | 30 分鐘時纖維蛋白溶解 | 高度纖維蛋白溶解 |

## 抗凝血管理 (Anticoagulation Management)

### Warfarin 逆轉

| 藥物 | 劑量 | 作用時間 | 備註 |
|------|------|---------|------|
| **Vitamin K (IV)** | 10 mg | 6-24 小時 | 半緊急逆轉 |
| **FFP** | 2-4 units | 立即 | 需要大體積 |
| **4-Factor PCC** | 體重調整 | 立即 | 偏好；不劣於 FFP |
| **3-Factor PCC** | — | 立即 | 效果較差（缺乏 Factor VII） |

### 直接口服抗凝血劑 (DOACs) 逆轉

| DOAC | 逆轉劑 |
|------|--------|
| **Dabigatran** | Idarucizumab (Praxbind) |
| **Rivaroxaban/Apixaban** | Andexanet alfa |
| **Fondaparinux** | 無特定逆轉劑 |

### Heparin 逆轉

| Heparin 類型 | 逆轉劑 | 劑量 |
|--------------|--------|------|
| **UFH** | Protamine sulfate | 1 mg per 100 U heparin（max 50 mg） |
| **LMWH** | Protamine | 1 mg per 100 anti-Xa units（部分逆轉） |

### 抗血小板藥物逆轉

| 藥物 | 處理方式 |
|------|---------|
| **Aspirin** | DDAVP (1-desamino-8-D-arginine vasopressin) 0.3 μg/kg |
| **Clopidogrel** | 血小板輸注 |
| **GP IIb/IIIa inhibitors** | 血小板輸注；24-48 小時內避免操作 |

## 圍手術期抗凝血管理 (Perioperative Anticoagulation Management)

### 橋接抗凝血 (Bridging Anticoagulation)

- **DOAC 使用者：** 通常**不需要橋接**（PERIOP-2 trial）。
- **Warfarin 使用者（高血栓風險）：** 考慮 LMWH 橋接。
- **Warfarin 使用者（低風險）：** 手術前 5 天停止 warfarin。

### 血栓栓塞風險分層

| 高風險（>10%/年） | 中風險（5-10%/年） | 低風險（<5%/年） |
|------------------|------------------|-----------------|
| 任何機械心臟瓣膜 | CHADS₂ 5-6 | CHADS₂ 0-1 |
| 心房顫動 + 中風病史 | 風濕性心臟瓣膜疾病 | 無中風病史 |
| 3 個月內 VTE | 3-12 個月內 VTE | |

## 大量輸血 (Massive Transfusion)

### 大量輸血協定 (MTP)

- **定義：** 24 小時內 >10 units pRBC 或 1 小時內 >4 units。
- **比例：** 1:1:1 (pRBC:FFP:Platelets) — PROMMTT/PROPPR trials。
- **目標：** 穩定患者 Hgb 7-9 g/dL。

### 創傷誘導凝血病 (TIC)

- **早期急性凝血病：** 受傷後立即發生。
- **機制：** 低灌注 → 抗凝血 + 高度纖維蛋白溶解。
- **診斷：** PT/aPTT >1.5× 正常、fibrinogen <150 mg/dL、BE >-6。
- **治療：** MTP + 損傷控制手術。

### 大量輸血輔助製劑

| 製劑 | 適應症 | 劑量 |
|------|--------|------|
| **Tranexamic acid** | 高度纖維蛋白溶解 | 1 g bolus → 1 g over 8h（受傷後 3 小時內） |
| **Fibrinogen (Cryo)** | 低纖維蛋白原血症 | 最初 4-6 g |
| **Calcium** | 低血鈣（citrate toxicity） | 每 1000 mL 血液給 1 g CaCl₂ |

## 特定凝血疾病 (Specific Coagulation Disorders)

### Heparin 誘導血小板減少症 (HIT)

| 特徵 | 描述 |
|------|------|
| **類型** | Type II（免疫媒介） |
| **時間** | Heparin 暴露後 5-14 天 |
| **機制** | 抗 PF4/heparin 抗體 → 血小板活化 |
| **4 T's Score** | Thrombocytopenia, Timing, Thrombosis, oTher causes |
| **治療** | 停止所有 heparin；改用 argatroban/bivalirudin |
| **避免** | Warfarin（導致皮膚壞死、肢體壞疽） |

### 瀰漫性血管內凝血 (DIC)

| 特徵 | 描述 |
|------|------|
| **病理生理** | 全身性凝血活化 → 消耗 + 出血 |
| **原因** | 敗血症、外傷、產科急症、惡性腫瘤 |
| **實驗室發現** | ↓血小板、↓纖維蛋白原、↑D-dimer、↑PT/aPTT、裂紅血球 |
| **治療** | 治療根本原因、支持性（FFP, platelets, cryo） |
| **rFVIIa** | 通常不建議（CONTROL trial 顯示無益處） |

### 重症患者血小板減少症

| 原因 | 機制 | 治療 |
|------|------|------|
| **敗血症** | 消耗、稀釋 | 治療感染 |
| **HIT** | 免疫媒介 | 停止 heparin、argatroban |
| **DITP** | 藥物誘導 | 停止致病因 |
| **ITP** | 自體免疫 | 類固醇、IVIG、脾臟切除 |
| **輸血後** | TRALI, TACO | 支持性 |

## 手術出血併發症 (Surgical Bleeding Complications)

### 過度術中/術後出血原因

1. **無效止血**（技術失敗）
2. **未發現的凝血病**
3. **消耗性凝血病 (DIC)**
4. **纖維蛋白溶解**
5. **大量輸血** → 稀釋性凝血病、低溫、酸中毒

### 再探查適應症

- 前 2-3 小時每小時 >150 mL
- 接下來每小時 >100 mL
- 任何突然增加的引流
- 無法用其他原因解釋的血流動力學不穩定

## 局部止血劑 (Topical Hemostatic Agents)

| 製劑 | 機制 | 用途 |
|------|------|------|
| **Gelfoam** | 血塊形成的支架 | 腔室、USS、軟組織 |
| **Surgicel** | Cellulose → acid → 血管收縮 | 輕微出血 |
| **Avitene** | 膠原蛋白顆粒 | 活躍出血表面 |
| **FloSeal** | 膠原蛋白 + thrombin | 活躍動靜脈出血 |
| **Tisseel** | 纖維蛋白密封膠 | 縫合線密封、組織黏合 |
| **Evicel** | 纖維蛋白密封膠（不含 aprotinin） | 與 Tisseel 相同 |
| **Recothrom** | 外用 thrombin | 直接塗抹 |
| **Vistusertib** | Serpin + thrombin inhibitor | 研究中 |

## 圍手術期管理清單 (Perioperative Management Checklist)

### 術前

- [ ] 審視抗凝血/抗血小板藥物
- [ ] 若為高出血風險手術，手術前 5 天停止 warfarin
- [ ] 高血栓風險者考慮橋接
- [ ] 根據腎功能，手術前 24-48 小時停止 DOACs
- [ ] 視情況檢查 CBC, PT, aPTT, fibrinogen

### 術中

- [ ] 精確止血
- [ ] 減少失血（低血壓麻醉、血液回收）
- [ ] 維持正常體溫（>36°C）
- [ ] 有條件時用 TEG/ROTEM 監測
- [ ] 凝血病時及早補充因子

### 術後

- [ ] 監測引流管和血紅蛋白
- [ ] 根據症狀而非任意數字輸血
- [ ] 根據出血風險恢復抗凝血（通常 24-72 小時）
- [ ] DVT 預防（機械 + 安全時的藥物）
