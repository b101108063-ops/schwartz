## Peripheral Arterial Disease (PAD) 周邊動脈疾病

### Risk Factors 危險因子

- **Smoking** (strongest modifiable risk factor) 吸菸(最強可改變危險因子)
- **Diabetes mellitus** 糖尿病
- **Hypertension** 高血壓
- **Hyperlipidemia** 血脂異常
- **Age >50** 年齡>50歲
- **Family history** 家族史

### Clinical Presentation (Fontaine Classification) 臨床表現(丰塔納分類)

| Stage 分期 | Description 描述 |
|-----------|----------------|
| **I** | Asymptomatic 無症狀 |
| **IIa** | Mild claudication (>200m) 輕度跛行(>200公尺) |
| **IIb** | Moderate-severe claudication (<200m) 中重度跛行(<200公尺) |
| **III** | Ischemic rest pain 缺血性靜息痛 |
| **IV** | Tissue loss (ulcer, gangrene) 組織流失(潰瘤、壞疽) |

### ABI (Ankle-Brachial Index) 踝臂指數

| ABI Value ABI值 | Interpretation 判讀 |
|----------------|-------------------|
| >1.3 | Noncompressible (calcified) 不可壓縮(鈣化) |
| 1.0-1.29 | Normal 正常 |
| 0.91-0.99 | Borderline 邊界值 |
| 0.41-0.90 | Mild-moderate PAD 輕中度PAD |
| ≤0.40 | Severe PAD 嚴重PAD |

### Rutherford Classification 路瑟福分類

| Grade 分級 | Category 分類 | Description 描述 |
|-----------|--------------|-----------------|
| **0** | 0 | Asymptomatic 無症狀 |
| **I** | 1-3 | Mild-moderate claudication 輕中度跛行 |
| **II** | 4 | Severe claudication 重度跛行 |
| **III** | 5-6 | Critical limb ischemia (CLI) 嚴重肢體缺血 |

### Medical Management 內科治療

| Treatment 治療 | Details 詳情 |
|--------------|-----------|
| **Smoking cessation** 戒菸 | Most important intervention 最重要介入 |
| **Exercise therapy** 運動治療 | Supervised walking program (30-45 min, 3x/week) 監督下步行計畫 |
| **Statins** 史他汀 | LDL target <70 mg/dL LDL目標<70 |
| **Antiplatelet** 抗血小板 | Aspirin 75-325 mg or clopidogrel 75 mg |
| **ACE inhibitors** ACE抑制劑 | For hypertension, diabetes 用於高血壓、糖尿病 |
| **Cilostazol** | PDE-3 inhibitor; improves walking distance (contraindicated in HF) |
| **BP control** 血壓控制 | <140/90 mmHg (<130/80 in DM) |

### Revascularization 血管重建

| Indication 適應症 | Procedure 術式 |
|-----------------|--------------|
| **Lifestyle-limiting claudication** 生活受限跛行 | Endovascular or surgical bypass 血管內或手術繞道 |
| **Critical limb ischemia (CLI)** 嚴重肢體缺血 | Revascularization required 需要血管重建 |
| **Acute limb ischemia** 急性肢體缺血 | Emergency intervention 緊急介入 |

### Endovascular Options 血管內選項

| Technique 技術 | Indication 適應症 |
|--------------|-----------------|
| **Angioplasty (PTA)** 氣球擴張術 | Focal stenosis 局灶性窄狹 |
| **Stenting** 支架置放 | Long lesions, recoil-prone lesions 長病灶、易彈性回彈病灶 |
| **Atherectomy** 斑塊切除 | Calcified lesions, device selection varies 鈣化病灶、裝置選擇各異 |
| **Cryoplasty** 冷斑塊切除 | Some balloon-resistant lesions 部分耐氣球治療病灶 |

## Critical Limb Ischemia (CLI) 嚴重肢體缺血

### Definition 定義

- Ischemic rest pain, non-healing ulcers, gangrene 缺血性靜息痛、不癒合潰瘤、壞疽
- **ABI typically <0.4** 通常<0.4
- **Transcutaneous oxygen pressure (TcPO₂) <30 mmHg**

### Presentation 表現

| Finding 發現 | Description 描述 |
|-------------|----------------|
| **Rest pain** 靜息痛 | Typically forefoot, worse at night, relieved by dependency 通常前足、夜間較重、垂腿可緩解 |
| **Ulceration** 潰瘤 | Typically on toes, heel, pressure points 通常在腳趾、足跟、壓力點 |
| **Gangrene** 壞疽 | Dry (preferred) or wet 乾性(較好)或濕性 |
| **Pallor** 蒼白 | On elevation; rubor on dependency 抬高時蒼白；下垂時充血 |
| **Hair loss, nail dystrophy** 脫毛、指甲營養不良 | Chronic ischemia 慢性缺血 |
| **Weak/absent pulses** 脈搏弱/消失 | Bilateral femoral, popliteal, pedal 雙側股、膕、足背 |

### Treatment 治療

| Strategy 策略 | Details 詳情 |
|-------------|-----------|
| **Revascularization** 血管重建 | Required in >90%; angioplasty, stenting, or bypass >90%需要；氣球擴張、支架或繞道 |
| **Wound care** 傷口照護 | Debridement, wet-to-dry dressings 清創、濕至乾敷料 |
| **Antibiotics** 抗生素 | For infected ulcers (wet gangrene) 用於感染潰瘤(濕壞疽) |
| **Amputation** 截肢 | If revascularization not possible; levels: toe, transmetatarsal, below-knee, above-knee 如血管重建不可能；平面：腳趾、經蹠骨、膝下、膝上 |

### Limb Salvage Outcomes 肢體挽救預後

- **30-day mortality:** 2-5% 30天死亡率
- **Major amputation:** 5-10% 主要截肢率
- **Wound healing:** 60-80% with successful revascularization 成功血管重建後傷口癒合率

## Acute Limb Ischemia (ALI) 急性肢體缺血

### "6 P's"

| Sign 徵象 | Description 描述 |
|----------|----------------|
| **Pain** 疼痛 | Sudden, severe 突發、劇烈 |
| **Pallor** 蒼白 | White, waxy 白色、蠟樣 |
| **Pulselessness** 無脈 | Absent pulse 脈搏消失 |
| **Poikilothermia** 溫度變化 | Cool extremity 肢體冰冷 |
| **Paresthesia** 感覺異常 | Numbness, tingling 麻木、刺痛 |
| **Paralysis** 麻痺 | Motor deficit (late) 運動缺損(晚期) |

### Rutherford Classification 路瑟福分類

| Class 分類 | Prognosis 預後 | Findings 發現 |
|----------|--------------|-------------|
| **I** | Viable 可存活 | Not immediately threatened 非立即威脅 |
| **IIa** | Marginally threatened 邊緣威脅 | Salvageable if promptly treated 適時治療可挽救 |
| **IIb** | Immediately threatened 立即威脅 | Salvageable with immediate treatment 立即治療可挽救 |
| **III** | Irreversible 不可逆 | Major tissue loss/amputation inevitable 必然的重大組織流失/截肢 |

### Etiology 病因

| Cause 病因 | Frequency 頻率 | Features 特徵 |
|----------|--------------|-------------|
| **Embolism** 栓塞 | 40-50% | Cardiac (AF, MI, valve), sudden onset 心源性(房顫、心肌梗塞、瓣膜)、突發 |
| **Thrombosis** 血栓形成 | 50-60% | Atherosclerosis, graft occlusion, native artery 粥狀硬化、移植片阻塞、本身動脉 |
| **Trauma** 外傷 | Rare 罕見 | Penetrating, blunt, iatrogenic 穿刺、鈍傷、醫源性 |
| **Aortic dissection** 主動服剝離 | Rare 罕見 | Can cause bilateral lower extremity ischemia 可致雙側下肢缺血 |

### Treatment 治療

| Situation 情況 | Management 處理 |
|--------------|--------------|
| **Viable (Class I)** 可存活 | Heparinize, semi-elective intervention 肝素化、半緊急介入 |
| **Marginally threatened (IIa)** 邊緣威脅 | Urgent revascularization (<6h) 緊急血管重建(<6小時) |
| **Immediately threatened (IIb)** 立即威脅 | Emergency revascularization (<3-6h) 緊急血管重建(<3-6小時) |
| **Irreversible (III)** 不可逆 | Primary amputation 初次截肢 |

### Surgical Options 手術選項

| Procedure 術式 | Use 用途 |
|--------------|---------|
| **Embolectomy (Fogarty)** 栓塞切除術 | Acute embolism, thrombus 急性栓塞、血栓 |
| **Thrombolysis (catheter-directed)** 導管定向溶栓 | Acute-on-chronic thrombosis 急性慢性血栓 |
| **Bypass grafting** 繞道移植 | Failed embolectomy, long-segment occlusion 栓塞切除失敗、長段阻塞 |
| **Stenting** 支架置放 | Underlying stenotic lesion 基礎窄狹病灶 |

### Complications Post-Revascularization 重建後併發症

| Complication 併發症 | Mechanism 機制 |
|------------------|--------------|
| **Reperfusion injury** 再灌注損傷 | Myoglobin release, hyperkalemia, acidosis 肌球蛋白釋放、高鉀血症、酸中毒 |
| **Compartment syndrome** 腔室症候群 | Muscle swelling in fascial compartments 筋膜腔內肌肉腫脹 |
| **Renal failure** 腎衰竭 | Myoglobinuria 肌球蛋白尿 |
| **Death** 死亡 | 15-25% (especially with delayed presentation) 延遲就診者尤其高 |

## Carotid Artery Disease 頸動脈疾病

### Stroke Risk Related to Stenosis 窄狹相關中風風險

| Stenosis 窄狹度 | Annual Stroke Risk 年度中風風險 | Treatment 治療 |
|----------------|---------------------------|-------------|
| **<50%** | <1%/year | Medical management 內科治療 |
| **50-69%** | 1-2%/year | Consider CEA if symptomatic 如有症狀考慮CEA |
| **≥70%** | >2%/year | CEA recommended (if surgical risk acceptable) 建議CEA(如果手術風險可接受) |

### Carotid Endarterectomy (CEA) Indications CEA適應症

| Indication 適應症 | Stenosis 窄狹度 | Timing 時機 |
|----------------|---------------|-----------|
| **Symptomatic TIA/stroke** 有症狀暫時性腦缺血/中風 | ≥70% (Class I) | Within 2 weeks of event 事件後2週內 |
| **Symptomatic** 有症狀 | 50-69% (Class IIa) | Consider CEA 考慮CEA |
| **Asymptomatic** 無症狀 | ≥60-70% (Class IIa) | If surgical risk <3% 如手術風險<3% |

### CEA Procedure CEA手術

- **Approach:** Cervical incision along SCM 頸部沿胸鎖乳突肌切開
- **Shunting:** Selective based on EEG/SSEP monitoring or stump pressure 選擇性分流基於腦電圖/體感誘發電位監測或殘株壓力
- **Patch angioplasty:** Preferred closure method 補片血管整形：優先閉合方式
- **Eversion CEA:** Alternative technique for high lesions 翻轉式CEA：高病灶的替代技術

### CEA Complications CEA併發症

| Complication 併發症 | Risk 風險 |
|-------------------|----------|
| **Stroke/death** 中風/死亡 | 2-3% (asymptomatic), 5-7% (symptomatic) |
| **Cranial nerve injury** 顱神經損傷 | 5-10% (usually transient) 通常短暫 |
| **MI** 心肌梗塞 | 1-2% |
| **Restenosis** 再窄狹 | 5-10% at 5 years 5年時5-10% |

### CAS (Carotid Artery Stenting) 頸動脉支架

| Indication 適應症 | Consideration 考量 |
|------------------|-----------------|
| **High surgical risk** 高手術風險 | Radiation neck, prior CEA, contralateral vocal cord paralysis |
| **Anatomic high risk** 解剖高風險 | High bifurcation, contralateral occlusion 高分叉、對側阻塞 |
| **Post-radiotherapy** 放療後 | Prior neck radiation 之前頸部放療 |

## Aortoiliac Disease 主髂動脉疾病

### Leriche Syndrome 萊里奇症候群

- **Classic triad:** Claudication, absent femoral pulses, erectile dysfunction 經典型三聯：跛行、股脈消失、勃起障礙
- **Cause:** Infrarenal aortic/bilateral iliac occlusion 病因：腎下主動服/雙側髂動脉阻塞

### TASC II Classification TASC II分類

| Type 類型 | Description 描述 | Treatment 治療 |
|----------|---------------|--------------|
| **A** | Focal stenosis <3cm (CIA or EIA) | PTA/stent 氣球擴張/支架 |
| **B** | Stenosis 3-10cm, not extending to CFA | Preferred endovascular 優先血管內 |
| **C** | Stenosis >10cm or bilateral CIA occlusion | Surgery if endovascular fails 血管內失敗則手術 |
| **D** | Complete aortic/bilateral CIA occlusion | Surgery (aortobifemoral bypass) 手術(主雙股繞道) |

### Revascularization Options 血管重建選項

| Procedure 術式 | Indication 適應症 |
|--------------|-----------------|
| **Aortobifemoral bypass** 主雙股繞道 | Complete aortoiliac occlusion, young patients 完全主髂阻塞、年輕患者 |
| **Axillofemoral bypass** 腋股繞道 | Hostile abdomen, infection, high risk 不良腹側、感染、高風險 |
| **iliofemoral bypass** 髂股繞道 | Unilateral iliac disease 單側髂疾病 |
| **PTA + stent** 氣球擴張+支架 | Most TASC A/B lesions; increasingly C 大部分TASC A/B病灶；越來越多C |
| **CFA endarterectomy + patch** 股總動脉內膜切除+補片 | Common femoral artery disease 股總動脉疾病 |

### Complications 併發症

| Complication 併發症 | Risk 風險 |
|-------------------|----------|
| **Graft infection** 移植片感染 | 1-5% |
| **Anastomotic aneurysm** 吻合口動瘤 | 5-10% at 10 years 10年時5-10% |
| **Graft thrombosis** 移植片血栓 | 5-10% at 5 years 5年時5-10% |
| **Sexual dysfunction** 性功能障礙 | 10-20% |

## Femoral-Popliteal Disease 股膕動脉疾病

### Indications for Revascularization 血管重建適應症

- Lifestyle-limiting claudication despite medical therapy 內科治療後仍生活受限的跛行
- Critical limb ischemia 嚴重肢體缺血

### Endovascular Options 血管內選項

| Technique 技術 | Best For 最適合 |
|--------------|---------------|
| **PTA alone** 僅氣球擴張 | Short (<5cm) lesions 短病灶(<5公分) |
| **Stenting** 支架 | Longer lesions, dissection 長病灶、剝離 |
| **Drug-coated balloon** 藥物球囊 | In-stent restenosis, native vessel 支架內再窄狹、本身血管 |
| **Atherectomy** 斑塊切除 | Calcified lesions 鈣化病灶 |

### Surgical Bypass 手術繞道

| Bypass 繞道 | Conduit 導管 | 5-Year Patency 5年通暢率 |
|------------|-------------|----------------------|
| **Femoral-popliteal (above knee)** 股膕(膝上) | Saphenous vein 大隱靜脈 | 70-80% |
| **Femoral-popliteal (below knee)** 股膕(膝下) | Saphenous vein 大隱靜脈 | 50-65% |
| **Femoral-femoral crossover** 股股交叉 | PTFE or saphenous | 50-70% |

### Prosthetic vs. Autologous Vein 人工對自體靜脈

- **Saphenous vein preferred** for below-knee bypass 膝下繞道偏好使用大隱靜脈
- **PTFE** acceptable for above-knee with short lesions PTF E可接受用於短病灶的膝上繞道
- **Composite bypass** (vein cuff) improves prosthetic below-knee outcomes 複合繞道(靜脈袖口)改善人工膝下預後

## Visceral Artery Disease 內臟動脉疾病

### Chronic Mesenteric Ischemia 慢性腸繫膜缺血

- **"Intestinal angina"** - postprandial abdominal pain "腸道心絞痛"-飯後腹痛
- **Weight loss** (fear of eating) 體重減輕(怕進食)
- **Diagnosis:** CTA, duplex, mesenteric angiography 診斷：CTA、都卜勒、腸繫膜血管攝影
- **Treatment:** Mesenteric bypass (SMA most important) or PTA/stent 治療：腸繫膜繞道(上腸繫膜動脉最重要)或氣球擴張/支架

### Renovascular Disease 腎血管疾病

| Condition 疾病 | Features 特徵 |
|--------------|-------------|
| **Atherosclerotic RAS** 粥狀硬化性RAS | Older patients, ARAS (atherosclerotic renal artery stenosis) 老年患者、粥狀硬化性腎動脉窄狹 |
| **Fibromuscular dysplasia** 纖維肌性發育不良 | Young women, "string of beads" on angiography 年輕女性、血管攝影上"串珠狀" |

### Renal Artery Stenosis Treatment 腎動脉窄狹治療

| Indication 適應症 | Treatment 治療 |
|----------------|--------------|
| **HTN + RAS** | Medical management first; angioplasty if refractory 優先內科治療；頑抗時氣球擴張 |
| **Flash pulmonary edema** 閃發肺水腫 | Angioplasty + stenting 氣球擴張+支架置放 |
| **Renal dysfunction + bilateral RAS** 腎功能障礙+雙側RAS | Consider intervention 考慮介入 |
| **Progressive renal failure** 進行性腎衰竭 | Angioplasty ± stent 氣球擴張±支架 |

## Upper Extremity Arterial Disease 上肢動脉疾病

### Subclavian Steal Syndrome 鎖骨下竊血症候群

- **Anatomy:** Proximal subclavian stenosis → vertebral artery reversal 解剖：近端鎖骨下窄狹→椎動脉逆流
- **Presentation:** Arm claudication, vertebrobasilar symptoms with arm exercise 表現：手臂跛行、手臂運動時椎基底症狀
- **Treatment:** Carotid-subclavian bypass, subclavian angioplasty/stenting 治療：頸總-鎖骨下繞道、鎖骨下氣球擴張/支架

### Thoracic Outlet Syndrome (TOS) 胸廓出口症候群

| Type 類型 | Compression 壓迫 | Symptoms 症狀 |
|----------|----------------|-------------|
| **Neurogenic** 神經性 | Brachial plexus 臂神經叢 | Hand numbness, weakness (most common) 手麻、無力(最常見) |
| **Venous (Paget-Schroetter)** 靜脈性 | Subclavian vein 鎖骨下靜脈 | Arm swelling, cyanosis 手臂腫脹、發紺 |
| **Arterial** 動脉性 | Subclavian artery 鎖骨下動脉 | Ischemia, emboli to fingers 缺血、指頭栓塞 |

### Raynaud Phenomenon 雷諾現象

| Type 類型 | Features 特徵 |
|----------|--------------|
| **Primary (Raynaud's disease)** 原發性 | Idiopathic, symmetric, no tissue damage 特發性、對稱、無組織損傷 |
| **Secondary (Raynaud syndrome)** 續發性 | Associated with CTD, arterial disease; may cause digital ulceration 關聯結締組織病、動脉疾病；可致指端潰瘤 |

### Buerger's Disease (Thromboangiitis Obliterans) 伯格氏病

- **Young male smokers** 年輕男性吸菸者
- **Small/medium vessels** of extremities 四肢中小血管
- **Segmental thrombosis** with skip lesions 節段性血栓伴跳躍式病變
- **Treatment:** Smoking cessation is essential 治療：戒菸是根本

## Vascular Trauma 血管創傷

### Blunt vs. Penetrating 鈍傷對穿刺傷

| Mechanism 機制 | Common Injuries 常見損傷 |
|---------------|--------------------|
| **Blunt** 鈍傷 | Intimal injury → thrombosis; pseudoaneurysm; dissection 內膜損傷→血栓；假性動瘤；剝離 |
| **Penetrating** 穿刺傷 | Direct injury → hemorrhage, pseudoaneurysm, AVF 直接損傷→出血、假性動瘤、動靜脈瘻 |

### Diagnostic Approach 診斷方法

| Study 檢查 | Indication 適應症 |
|----------|-----------------|
| **Duplex ultrasound** 都卜勒超音 | Stable patients, near vessels 穩定患者、血管附近 |
| **CT angiography** CTA | Most trauma patients; fast, accurate 大部分創傷患者；快速、準確 |
| **Angiography** 血管攝影 | Blunt aortic injury, equivocal cases 鈍性主動服損傷、難以確診病例 |
| **Surgical exploration** 手術探查 | Unstable, hard signs 不穩定、明確徵象 |

### Hard Signs (Require Immediate Surgery) 明確徵象(需立即手術)

- Expanding/pulsatile hematoma 擴大/搏動性血腫
- Active hemorrhage 活動性出血
- Absent pulses 脈搏消失
- Audible bruit 可聞及雜音
- Shock not explained by other injuries 無法以其他損傷解釋的休克

### Soft Signs (Require Further Imaging) 模糊徵象(需進一步影像)

- History of significant hemorrhage 重大出血病史
- Proximity to major vessels 靠近主要血管
- Neurological deficit 神經缺損
- Nonexpanding hematoma 非擴大性血腫

### Repair Techniques 修復技術

| Technique 技術 | Use 用途 |
|--------------|---------|
| **Primary repair** 初步修復 | Short injury, minimal tension 短損傷、最小張力 |
| **Patch angioplasty** 補片整形 | Segmental defect 節段性缺損 |
| **Interposition graft** 置換移植 | Long defect (autologous vein preferred) 長缺損(偏好自體靜脈) |
| **Ligation** 結紮 | (Rarely) non-critical vessels (罕見)非關鍵血管 |
| **Endovascular stent-graft** 血管內支架移植 | Selected injuries (blunt aortic, pseudoaneurysm) 特定損傷(鈍性主動服、假性動瘤) |

### Damage Control 損傷控制

- **Temporary shunt** (Pringle maneuver for porta hepatis, others) 臨時分流(肝門蒂氏操作法及其他)
- **Ligation** for hemorrhage control 止血用結紮
- **Resuscitation** first, definitive repair when stable 先復甦，穩定後確定修復

## Vasospastic Disorders 血管痙攣疾病

### Primary (Raynaud's Disease) 原發性

- **Young women** (15-30 years) 年輕女性(15-30歲)
- **Bilateral, symmetric** involvement 雙側、對稱侵犯
- **No underlying cause** 無根本原因
- **Triphasic color change:** White → Blue → Red 三相顏色變化：白→藍→紅

### Secondary (Raynaud Syndrome) 續發性

- **Connective tissue diseases:** SLE, scleroderma, MCTD 結締組織疾病
- **Arterial occlusive disease** 動脉阻塞性疾病
- **Thoracic outlet syndrome** 胸廓出口症候群
- **Drug-induced:** Beta-blockers, ergotamines 藥物引起：β受體阻斷劑、麥角鹼

### Treatment 治療

| Treatment 治療 | Indication 適應症 |
|--------------|-----------------|
| **Cold avoidance** 避免寒冷 | All patients 所有患者 |
| **Smoking cessation** 戒菸 | Essential 根本 |
| **CCB (nifedipine)** | First-line pharmacotherapy 第一線藥物治療 |
| **Topical nitroglycerin** 局部硝化甘油 | Digital ulcers 指端潰瘤 |
| **Prostaglandins (IV iloprost)** 靜脈前列腺素 | Severe, refractory 重度、頑抗性 |
| **Sympathectomy** 交感神經切除 | Refractory cases (limited benefit) 頑抗性病例(效果有限) |

## Amputation Levels 截肢平面

| Level 平面 | Indication 適應症 | Primary Healing 初步癒合 |
|-----------|-----------------|--------------------|
| **Toe** 腳趾 | Gangrene limited to toe 僅限腳趾壞疽 | Good 良好 |
| **Transmetatarsal** 經蹠骨 | Multiple toe gangrene, forefoot necrosis 多腳趾壞疽、前足壞死 | Good 良好 |
| **Below-knee (BKA)** 膝下 | Extensive foot gangrene, failed revascularization 廣泛足部壞疽、血管重建失敗 | 70-80% |
| **Above-knee (AKA)** 膝上 | Non-ambulatory patients, poor BK soft tissue 無行走能力患者、膝下軟組織差 | 80-90% |
| **Hip disarticulation** 髖關節離斷 | Extensive thigh soft tissue loss 大腿軟組織嚴重流失 | Rare 罕見 |

### Rehabilitation 復健

- **Prosthetic fitting:** 2-4 weeks post-op 義肢裝配：術後2-4週
- **Early mobilization** reduces complications 早期活動減少併發症
- **Mortality:** 30-day ~5-10%; 1-year ~20-30% 死亡率

## Graft Complications 移植血管併發症

### Early Complications (<30 days) 早期併發症

| Complication 併發症 | Presentation 表現 | Treatment 治療 |
|------------------|-----------------|--------------|
| **Graft thrombosis** 移植片血栓 | Acute limb ischemia 急性肢體缺血 | Thrombolysis, thrombectomy, redo bypass 溶栓、血栓切除、重做繞道 |
| **Graft infection** 移植片感染 | Fever, sepsis, bleeding 發燒、敗血症、出血 | Antibiotics, graft excision ± extra-anatomic bypass |
| **Anastomotic bleed** 吻合口出血 | Hemorrhage 出血 | Return to OR 回手術室 |

### Late Complications (>30 days) 晚期併發症

| Complication 併發症 | Presentation 表現 | Treatment 治療 |
|------------------|-----------------|--------------|
| **Restenosis** 再窄狹 | Recurrent claudication/CLI 復發跛行/CLI | PTA, redo bypass 氣球擴張、重做繞道 |
| **True aneurysm** 真性動瘤 | Swelling, found on exam/imaging 腫脹、檢查/影像發現 | Excision + graft replacement 切除+移植片置換 |
| **Pseudoaneurysm** 假性動瘤 | Pulsatile mass, bleeding 搏動性腫塊、出血 | Surgical repair 手術修復 |
| **Graft-enteric fistula** 移植片腸道瘻 | GI bleeding, sepsis 胃腸出血、敗血症 | Graft excision + repair 移植片切除+修復 |
| **AV fistula** 動靜脈瘻 | Ischemia, high-output HF 缺血、高輸出心衰竭 | Surgical repair 手術修復 |
