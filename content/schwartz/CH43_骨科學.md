# CH43 骨科學 (Orthopedic Surgery)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 骨折治療基本原則

### 骨折分類（圖43-1）

| 類型 | 說明 |
|------|------|
| **横行（Transverse）** | 橫向断裂 |
| **斜行（Oblique）** | 斜向断裂 |
| **螺旋（Spiral）** | 螺旋断裂 |
| **分段（Segmental）** | 兩處以上断裂 |
| **粉碎（Comminuted）** | 多塊碎片 |

### 內固定原則

- 建立穩定結構，使骨折在正確長度、對齊和旋轉下癒合

**常用方法：**

| 方法 | 說明 |
|------|------|
| **骨髓內釘（Intramedullary nail）** | 長骨骨折（如股骨、脛骨）最常用 |
| **鋼板螺絲（Plate & screw）** | 提供壓縮和穩定 |
| **螺絲** | 穿過骨折處產生加壓促進癒合 |
| **靜態鎖定（Static locking）** | 骨折近端和遠端皆鎖定 |

### 外固定器（External Fixator）

**適應症：**

- 嚴重創傷
- 軟組織腫脹無法安全手術
- 傷口污染

- 最終治療延遲至傷口足夠清潔後

### 開放性骨折（Gustilo-Anderson分類）

| 類型 | 能量 | 傷口大小 | 軟組織損傷 |
|------|------|---------|-----------|
| **Type I** | 低能量 | <1 cm | 輕度 |
| **Type II** | 中能量 | 2-10 cm | 中度 |
| **Type III** | 高能量 | >10 cm | 嚴重（涵蓋III-A、III-B、III-C）|

**治療原則：**

- 盡速給予抗生素
- 沖洗和清創
- 早期傷口覆蓋
- Type IIIB/IIIC：游離皮瓣覆蓋

## 腔室症候群（Compartment Syndrome）

### 病因

- 受傷肢體腔室內顯著腫脹 → 危及血流和微循環

### 診斷（5P）

| 項目 | 說明 |
|------|------|
| **Pain** | 疼痛超出預期 |
| **Passive stretch** | 被動伸展疼痛 |
| **Pressure** | 壓力 |
| **Paresthesia** | 感覺異常 |
| **Paralysis** | 麻痺 |

- 晚期：無脈搏
- **診斷標準：** 腔室壓力在舒張壓30 mmHg以內

### 治療

- **緊急筋膜切開術（Fasciotomy）：** 釋放緊繃筋膜
- 延遲治療 → 不可逆肌肉和神經壞死 → **Volkmann's缺血性攣縮**

## 創傷處理

### 鎖骨骨折

- 最常見骨折之一
- 80%位於中1/3

**治療：**

- **保守治療（三角巾）** 適用於大多數
- 手術適應症：明顯移位/短縮、或開放性骨折
- 手術方式：開放復位鋼板內固定（ORIF）

### 肩關節脫位

- **最常見脫位的大關節**
- **前脫位最常見（90%）**

**併發損傷：**

- Bankart lesion（關節唇撕裂）
- Hill-Sachs lesion（肱骨頭凹陷骨折）
- **腋神經損傷風險**

**後脫位：**

- 與癲癇或電擊相關
- 易漏診

**治療：** 閉合復位＋三角巾制動

### 近端肱骨骨折（Neer分類）

- 四部分：肱骨頭、大結節、小結節、肱骨幹

**治療選擇：**

| 情況 | 治療 |
|------|------|
| 大多數輕度位移 | 保守治療 |
| 位移骨折或頭部骨折 | ORIF |
| 老年骨質疏鬆、複雜骨折 | 人工關節置換（半肩或全肩置換） |

### 肱骨幹骨折

- 大多可保守治療
- **橈神經損傷風險**（繞過肱骨幹）；檢查手腕下垂

### 肘關節脫位

- 後脫位常見
- **治療：** 閉合復位

### 前臂骨折

- 橈骨和尺骨同時骨折
- **治療：** 通常需要手術（ORIF）

### 橈骨遠端骨折（Colles/Smith骨折）

- 跌倒時伸手撐地常見
- **治療：** 閉合復位＋石膏固定

### 舟狀骨骨折

- 跌倒伸手撐地
- **易漏診**（需特殊視角X光）
- **併發症：** 骨壞死（AVN）、不癒合

### 骨盆骨折

- **可危及生命的出血**
- **緊急處理：** 骨盆綁帶/夾板固定減少出血
- 穩定性評估重要

### 髖關節脫位

- **創傷性髖關節脫位：** 車禍常見
- **後脫位常見**（膝蓋撞擊儀表板）
- **緊急閉合復位（6小時內）**
- **併發症：** 股骨頭缺血性壞死

### 髖關節骨折

| 類型 | 治療 |
|------|------|
| **股骨頸骨折（Garden I/II）** | 內固定（年輕患者）或半髖/全髖置換（老年） |
| **轉子間骨折** | 動力髖螺絲（DHS）或髓內釘 |

### 股骨幹骨折

- **髓內釘固定（金標準）**

### 膝關節脫位

- 高能量損傷
- **併發症：** 血管損傷（膕動脈）、神經損傷
- **緊急評估血管狀態**

### 脛骨平台骨折

- 膝關節骨折常見
- 涉及關節面需要精確復位

### 脛骨幹骨折

- 髓內釘或鋼板固定

### 踝關節骨折

- **Weber分類：**

| 類型 | 說明 |
|------|------|
| **A** | 下胫腓聯合以下 |
| **B** | 經下胫腓聯合 |
| **C** | 下胫腓聯合以上 |

- 治療取決於穩定性

### 跟骨骨折

- 跌落高度創傷
- 關節面受累需要手術

### 距骨骨折

- **併發症：** 缺血性壞死

## 膝關節

### 半月板（Menisci）

- 內側C形、外側盤狀
- 受傷機制：扭轉
- **McMurray test**
- **治療：** 關節鏡部分切除或修補

### 韌帶

| 韌帶 | 受傷機制 |
|------|---------|
| **前十字韌帶（ACL）** | 減速、扭轉；"pop"聲；不穩定；MRI確診 |
| **後十字韌帶（PCL）** | 直接撞擊（儀表板損傷） |
| **內側副韌帶（MCL）** | 外翻壓力 |
| **外側副韌帶（LCL）** | 內翻壓力 |

- **ACL重建：** 移植韌帶（自体或異體）
- **PCL重建：** 移植韌帶

### 後外側角落（Posterolateral Corner）

- **包括：** 腘肌腱、外側副韌帶、腓腸肌豆形韌帶
- 受傷導致膝關節後外側不穩定

## 髖關節

### 股骨髖臼撞擊症（FAI）

| 類型 | 說明 |
|------|------|
| **Cam type** | 股骨頭/頸交界處骨質增生 |
| **Pincer type** | 髖臼過度覆蓋 |
| **混合型** | 兩者皆有 |

- **治療：** 關節鏡微創手術

## 脊椎創傷

### 評估

- **穩定性評估**非常重要
- **CT比X光更可靠**

### Jefferson骨折（C1爆裂骨折）

- C1雙側前、後弓骨折
- 評估橫韌帶完整性（"Rule of Spence"）

### 齒突骨折（C2）

- 治療取決於骨折類型
- 可能需要手術固定

### Hangman's骨折（C2）

- C2椎弓根骨折
- 創傷性脊椎滑脫

### 頸椎壓迫骨折

- 骨質疏鬆老年人常見
- **微創椎體成形術**

### 爆裂骨折（Burst fracture）

- 椎體嚴重壓迫
- 可能需要手術減壓和固定

### 安全帶損傷（Flexion-distraction injuries）

- Chance fracture（腰椎）
- 屈曲牽拉損傷

### 胸腰椎損傷

- 手術或保守治療取決於神經損傷和穩定性

### 椎間盤突出

- 頸椎或腰椎
- 保守治療或手術（椎間盤切除術、融合術）

### 馬尾症候群（Cauda equina syndrome）

- **緊急：** 大小便功能障礙、馬鞍區感覺喪失、下肢無力
- **需緊急手術減壓**

### 脊椎狹窄

- 頸椎或腰椎
- 保守或手術（椎板切除術、融合術）

## 運動醫學

### 肩關節

| 問題 | 說明 |
|------|------|
| **旋轉袖（Rotator Cuff）** | 肩穩定肌群（棘上肌、棘下肌、小圓肌、肩胛下肌） |
| **夾擊症候群（Impingement syndrome）** | 手臂抬高時肌腱受壓 |
| **肩關節不穩定** | Bankart repair、Latarjet procedure |
| **SLAP lesion** | 上關節唇前後撕裂 |

### 肘關節

- 網球肘（橈側副韌帶外上髁炎）
- 高爾夫球肘（內上髁炎）

## 關節置換（Arthroplasty）

### 關節炎手術治療

| 置換類型 | 適應症 |
|---------|--------|
| **全關節置換（Total joint）** | 末期關節炎、疼痛、功能障礙 |
| **半關節置換（Hemiarthroplasty）** | 股骨頭骨折、局部關節炎 |
| **微創關節置換** | 傷口小、恢復快；但可能有部件位置不良風險 |

### 假體周圍骨折

- Vancouver分類
- **治療：** 鋼板固定、翻修置換

## 肌肉骨骼腫瘤

### 良性骨腫瘤

| 腫瘤 | 特點 |
|------|------|
| **骨軟骨瘤（Osteochondroma）** | 最常見良性骨腫瘤；切除後不復發 |
| **內生軟骨瘤（Enchondroma）** | 透明軟骨腫瘤；手部常見 |
| **骨樣骨瘤（Osteoid osteoma）** | 夜間疼痛；NSAIDs有效 |
| **骨囊腫（Bone cyst）** | 病理性骨折常見 |

### 惡性骨腫瘤

| 腫瘤 | 特點 |
|------|------|
| **骨肉瘤（Osteosarcoma）** | 最常見原發性惡性骨腫瘤；青少年；好發膝部附近 |
| **軟骨肉瘤（Chondrosarcoma）** | 成年人；好發骨盆和肩帶 |
| **尤文氏肉瘤（Ewing's sarcoma）** | 兒童/青少年；"洋蔥皮"表現 |
| **惡性纖維組織細胞瘤（MFH）** | 成年人 |
| **骨髓瘤（Myeloma）** | 中老年人；多發性；"穿孔"樣骨病變 |

### 轉移性骨腫瘤

- **常見原發：** 乳腺癌、肺癌、前列腺癌、腎細胞癌、甲狀腺癌

**治療：** 減痛放療、手术固定、病理性骨折預防

## 兒童骨科

### 生長板損傷（Physeal injuries）

- **Salter-Harris分類：** I-V型
- 治療取決於生長板受累程度

### 發育性髖關節發育不良（DDH）

- 以前稱先天性髖關節脫位
- **新生兒篩檢：** Ortolani/Barlow test
- **治療：** Pavlik吊帶 → 闭合/開放復位

### Legg-Calvé-Perthes病

- 股骨頭缺血性壞死（兒童）
- 治療取決於年齡和嚴重程度

### 成長期股骨骺滑脫（SCFE）

- 青少年；肥胖
- **治療：** 原位固定或手術

### 馬蹄內翻足（Clubfoot）

- **治療：** Ponseti method（序列石膏）+ 手術（如必要）

### 兒童骨折特點

- 癒合快
- 強大的重塑能力
- **生長板損傷**需要準確復位

## 脊椎

### 脊椎側彎（Scoliosis）

| 類型 | 特點 |
|------|------|
| **特發性** | 最常見（80%）；青少年 |
| **先天性** | 椎體發育異常 |
| **神經肌肉性** | 腦癱、肌肉營養不良等 |

- **Cobb角度：** >10°為側彎；>25-40°需要治療

**治療：**

| 嚴重程度 | 治療 |
|---------|------|
| 輕度 | 觀察 |
| 中度 | 背架 |
| 重度 | 手術融合 |

### 椎間盤疾病

- 退化改變
- 椎間盤突出
- 保守或手術治療

### 下背痛

- **保守治療（一線）：** NSAIDs、物理治療、減重
- **手術（保守失敗後）：** 融合術或人工椎間盤置換

## 重點摘要（Key Points）

1. **內固定主要原則：** 建立穩定結構，使骨折在正確長度、對齊和旋轉下癒合（最常用骨髓內釘或鋼板螺絲）
2. **開放性骨折：** 早期靜脈抗生素很重要；外固定器常用於污染傷口；早期傷口覆蓋很重要
3. **腔室症候群：** 早期診斷和治療很重要；緊急筋膜切開術是救命的手術
4. **肩胛骨骨折：** 通常是高能量創傷，伴隨胸部損傷率高（肋骨和肺部）
5. **肩關節：** 最常見脫位的大關節；大多數是前脫位；後脫位可能漏診
6. **孤立性肱骨幹骨折：** 通常保守治療；橈神經繞過肱骨，有損傷風險
7. **骨盆創傷出血：** 可危及生命；第一步是骨盆綁帶/固定
8. **脊椎損傷：** 需評估穩定性；CT比X光更可靠
9. **脊髓損傷：** 可為完全或不完全；創傷中心照護可減少癱瘓和改善預後
10. **退化性關節疾病：** 55百萬成年人被診斷；非類固醇抗炎藥、物理治療、減重是一線治療
11. **微創手術技術：** 改善美觀和早期康復；但可能有部件位置不良和神經血管損傷風險
