# CH43 骨科學 (Orthopedic Surgery)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

骨科學涵蓋骨折治療、關節疾病、脊椎創傷、骨腫瘤及小兒骨科。本章重點包括：骨折內固定原則（<span style="color:#60a5fa">骨髓內釘</span>、<span style="color:#60a5fa">鋼板螺絲</span>）、開放性骨折的 <span style="color:#60a5fa">Gustilo-Anderson 分級</span>與處理、腔室症候群的診斷（5P 原則）與緊急筋膜切開術，以及常見骨腫瘤（<span style="color:#22d3ee">骨肉瘤</span>、<span style="color:#22d3ee">軟骨肉瘤</span>、<span style="color:#22d3ee">尤文氏肉瘤</span>）的診斷要點。

---

## 骨折治療基本原則

### 骨折分類

| 類型 | 說明 |
|------|------|
| **<span style="color:#22d3ee">横行（Transverse）</span>** | 橫向断裂 |
| **<span style="color:#22d3ee">斜行（Oblique）</span>** | 斜向断裂 |
| **<span style="color:#22d3ee">螺旋（Spiral）</span>** | 螺旋断裂（扭轉暴力） |
| **<span style="color:#22d3ee">分段（Segmental）</span>** | 兩處以上断裂 |
| **<span style="color:#22d3ee">粉碎（Comminuted）</span>** | 多塊碎片 |

### 內固定原則

- 建立穩定結構，使骨折在正確長度、對齊和旋轉下癒合

**常用方法：**

| 方法 | 說明 |
|------|------|
| **<span style="color:#60a5fa">骨髓內釘</span>（Intramedullary nail）** | 長骨骨折（如<span style="color:#22d3ee">股骨</span>、<span style="color:#22d3ee">脛骨</span>）**最常用** |
| **<span style="color:#60a5fa">鋼板螺絲</span>（Plate & screw）** | 提供壓縮和穩定 |
| **螺絲** | 穿過骨折處產生加壓促進癒合 |

### 開放性骨折（<span style="color:#60a5fa">Gustilo-Anderson</span>分類）

| 類型 | 能量 | 傷口大小 | 軟組織損傷 |
|------|------|---------|-----------|
| **Type I** | 低能量 | <1 cm | 輕度 |
| **Type II** | 中能量 | 2-10 cm | 中度 |
| **Type III** | 高能量 | >10 cm | 嚴重（涵蓋III-A、III-B、III-C）|

**治療原則：**

- 盡速給予<span style="color:#fb923c">預防性抗生素</span>
- 沖洗和清創
- 早期傷口覆蓋
- Type IIIB/IIIC：游離皮瓣覆蓋

<span style="color:#fbbf24;font-weight:600">Key Point：</span>開放性骨折的感染預防，時機是關鍵——應在受傷後儘快給予抗生素並進行清創。

## 腔室症候群（<span style="color:#60a5fa">Compartment Syndrome</span>）

### 病因

- 受傷肢體腔室內顯著腫脹 → 危及血流和微循環

### 診斷（5P）

| 項目 | 說明 |
|------|------|
| **<span style="color:#f87171">Pain</span>** | 疼痛超出預期 |
| **<span style="color:#f87171">Passive stretch</span>** | 被動伸展疼痛 |
| **Pressure** | 壓力 |
| **Paresthesia** | 感覺異常 |
| **Paralysis** | 麻痺 |

- **診斷標準：** 腔室壓力在舒張壓 <span style="color:#60a5fa">30 mmHg</span> 以內

### 治療

- **緊急<span style="color:#fb923c">筋膜切開術</span>（Fasciotomy）：** 釋放緊繃筋膜

<span style="color:#f87171;font-weight:600">警告：</span>延遲治療 → 不可逆肌肉和神經壞死 → **Volkmann's缺血性攣縮**

## 創傷處理

### 鎖骨骨折

- 最常見骨折之一
- <span style="color:#60a5fa">80%</span> 位於<span style="color:#22d3ee">中1/3</span>

**治療：**

- **保守治療（三角巾）** 適用於大多數
- 手術適應症：明顯移位/短縮、或開放性骨折

### 肩關節脫位

- **最常見脫位的大關節**
- **前脫位最常見（<span style="color:#60a5fa">90%</span>）**

**併發損傷：**

- <span style="color:#22d3ee">Bankart lesion</span>（關節唇撕裂）
- <span style="color:#22d3ee">Hill-Sachs lesion</span>（肱骨頭凹陷骨折）
- **<span style="color:#f87171">腋神經損傷風險</span>**

### 肘關節脫位

- 後脫位常見
- **治療：** 閉合復位

### 前臂骨折

- <span style="color:#22d3ee">橈骨</span>和<span style="color:#22d3ee">尺骨</span>同時骨折
- **治療：** 通常需要手術（ORIF）

### 髖關節脫位

- **創傷性髖關節脫位：** 車禍常見
- **後脫位常見**（膝蓋撞擊儀表板）
- **<span style="color:#f87171">緊急閉合復位（6小時內）</span>**
- **併發症：** 股骨頭缺血性壞死

### 髖關節骨折

| 類型 | 治療 |
|------|------|
| **股骨頸骨折（Garden I/II）** | 內固定（年輕患者）或半髖/全髖置換（老年） |
| **轉子間骨折** | 動力髖螺絲（DHS）或髓內釘 |

### 股骨幹骨折

- **<span style="color:#60a5fa">髓內釘固定（金標準）</span>**

### 踝關節骨折

**Weber分類：**

| 類型 | 說明 |
|------|------|
| **A** | 下胫腓聯合以下 |
| **B** | 經下胫腓聯合 |
| **C** | 下胫腓聯合以上 |

## 膝關節

### 半月板（Menisci）

- 內側C形、外側盤狀
- 受傷機制：扭轉
- **McMurray test**
- **治療：** 關節鏡部分切除或修補

### 韌帶

| 韌帶 | 受傷機制 |
|------|---------|
| **<span style="color:#60a5fa">前十字韌帶（ACL）</span>** | 減速、扭轉；"pop"聲；不穩定；MRI確診 |
| **後十字韌帶（PCL）** | 直接撞擊（儀表板損傷） |
| **內側副韌帶（MCL）** | 外翻壓力 |
| **外側副韌帶（LCL）** | 內翻壓力 |

- **ACL重建：** 移植韌帶（自体或異體）

## 脊椎創傷

### 評估

- **穩定性評估**非常重要
- **CT比X光更可靠**

### Jefferson骨折（<span style="color:#22d3ee">C1</span>爆裂骨折）

- C1雙側前、後弓骨折
- 評估橫韌帶完整性

### 齒突骨折（<span style="color:#22d3ee">C2</span>）

- 治療取決於骨折類型

### 頸椎壓迫骨折

- 骨質疏鬆老年人常見
- **微創椎體成形術**

### 馬尾症候群（Cauda equina syndrome）

- **<span style="color:#f87171">緊急：</span>** 大小便功能障礙、馬鞍區感覺喪失、下肢無力
- **需緊急手術減壓**

## 關節置換（Arthroplasty）

| 置換類型 | 適應症 |
|---------|--------|
| **全關節置換（Total joint）** | 末期關節炎、疼痛、功能障礙 |
| **半關節置換（Hemiarthroplasty）** | 股骨頭骨折、局部關節炎 |

## 肌肉骨骼腫瘤

### 良性骨腫瘤

| 腫瘤 | 特點 |
|------|------|
| **<span style="color:#22d3ee">骨軟骨瘤</span>（Osteochondroma）** | 最常見良性骨腫瘤；切除後不復發 |
| **<span style="color:#22d3ee">內生軟骨瘤</span>（Enchondroma）** | 透明軟骨腫瘤；手部常見 |
| **<span style="color:#22d3ee">骨樣骨瘤</span>（Osteoid osteoma）** | 夜間疼痛；NSAIDs有效 |
| **骨囊腫（Bone cyst）** | 病理性骨折常見 |

### 惡性骨腫瘤

| 腫瘤 | 特點 |
|------|------|
| **<span style="color:#22d3ee">骨肉瘤</span>（Osteosarcoma）** | 最常見原發性惡性骨腫瘤；青少年；好發<span style="color:#22d3ee">膝部</span>附近 |
| **<span style="color:#22d3ee">軟骨肉瘤</span>（Chondrosarcoma）** | 成年人；好發<span style="color:#22d3ee">骨盆</span>和肩帶 |
| **<span style="color:#22d3ee">尤文氏肉瘤</span>（Ewing's sarcoma）** | 兒童/青少年；"洋蔥皮"表現 |
| **骨髓瘤（Myeloma）** | 中老年人；多發性；"穿孔"樣骨病變 |

### 轉移性骨腫瘤

- **常見原發：** 乳腺癌、肺癌、前列腺癌、<span style="color:#22d3ee">腎細胞癌</span>、甲狀腺癌

## Summary

1. **內固定主要原則：** 建立穩定結構，使骨折在正確長度、對齊和旋轉下癒合
2. **<span style="color:#f87171">開放性骨折：</span>** 早期靜脈抗生素很重要；清創傷口覆蓋是關鍵
3. **<span style="color:#f87171">腔室症候群：</span>** 早期診斷和緊急筋膜切開術是救命的手術
4. **<span style="color:#f87171">髖關節脫位：</span>** 緊急閉合復位（<span style="color:#60a5fa">6小時內</span>）；否則股骨頭缺血性壞死風險極高
5. **肩關節：** 最常見脫位的大關節；大多數是前脫位
6. **<span style="color:#60a5fa">骨肉瘤：</span>** 最常見原發性惡性骨腫瘤；青少年；好發膝部附近
7. **退化性關節疾病：** <span style="color:#fb923c">非類固醇抗炎藥</span>、物理治療、減重是一線治療
