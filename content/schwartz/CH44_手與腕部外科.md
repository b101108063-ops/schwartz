# CH44 手與腕部外科 (Surgery of the Hand and Wrist)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

手部外科涵蓋創傷、感染、腫瘤及先天性疾病，需要精細的手術技術和對解剖結構的深入理解。本章從實用解剖切入，系統整理骨折分類、腱鞘損傷、神經血管障礙及腔室症候群等急診處理原則，並涵蓋指尖損傷與再植適應症的決策框架。

---

## <span style="color:#60a5fa">手的實用解剖</span>

### 骨骼結構

- **掌骨（Metacarpals）：** <span style="color:#22d3ee">5根</span>
- **指骨（Phalanges）：** <span style="color:#22d3ee">拇指2節，其餘手指各3節</span>
- **腕骨（Carpal bones）：** <span style="color:#22d3ee">8塊</span>排成兩列

| 近端 | 遠端 |
|------|------|
| <span style="color:#22d3ee">舟狀骨、月狀骨、三角骨、豌豆骨</span> | <span style="color:#22d3ee">大多角骨、小多角骨、頭狀骨、鉤狀骨</span> |

### 肌肉與肌腱

| 類型 | 說明 |
|------|------|
| **外在肌** | 來自<span style="color:#22d3ee">前臂</span>（屈肌、伸肌） |
| **內在肌** | <span style="color:#22d3ee">魚際肌、小魚際肌、骨間肌、蚓狀肌</span> |

### 神經支配

| 神經 | 感覺分布 | 運動功能 |
|------|---------|---------|
| **<span style="color:#60a5fa">正中神經</span>** | 拇指、食指、中指、橈側無名指 | 拇指對掌 |
| **<span style="color:#60a5fa">尺神經</span>** | 手掌尺側、無名指尺側、小指 | 骨間肌、蚓狀肌（環小指） |
| **<span style="color:#60a5fa">橈神經</span>** | 手背橈側 | 手指伸肌 |

### 血液供應

- **掌淺弓、掌深弓：** 來自<span style="color:#22d3ee">橈动脉</span>和<span style="color:#22d3ee">尺动脉</span>
- 每指有<span style="color:#34d399">兩條指动脉</span>

## <span style="color:#60a5fa">腕關節</span>

### 舟狀骨骨折（Scaphoid Fracture）

**特點：**

- 腕部<span style="color:#f87171">最常見骨折</span>
- 跌倒伸手撐地
- **<span style="color:#f87171">血管供應特異性：</span>** 近端血供脆弱 → 延遲癒合和<span style="color:#f87171">AVN（缺血性壞死）風險</span>
- **非位移骨折：** 仍有可能<span style="color:#f87171">20%不癒合</span>

**治療：**

| 類型 | 治療方式 |
|------|---------|
| 位移 | <span style="color:#f87171">開放復位內固定（ORIF）</span> |
| 非位移 | 短臂石膏固定 |

### 腕關節韌帶損傷（Mayfield分類）

- 月骨周圍脫位 progression
- **類型4：** 月骨向掌側脫位進入腕隧道 → 可能急性腕隧道徵候群

### 腕關節不穩定

- **舟月脫位（Scapholunate dissociation）：** <span style="color:#22d3ee">舟狀骨</span>和<span style="color:#22d3ee">月骨</span>間韌帶損傷

---

## <span style="color:#60a5fa">骨折與脫位</span>

### 描述骨折的要素

| 要素 | 描述方式 |
|------|---------|
| **位移** | 以骨直徑百分比描述 |
| **旋轉** | 以旋前/旋後角度描述 |
| **成角** | 以角度描述方向 |

### 各部位骨折

| 部位 | 特點 | 治療 |
|------|------|------|
| **遠節指骨 Tuft** | 壓砸傷（門夾）；常非位移 | 保護即可 |
| **掌骨頸（Boxer's fracture）** | 小指；Jahss maneuver復位 | 保守或<span style="color:#f87171">ORIF</span> |
| **拇指掌骨基底（Bennett）** | 不穩定；拇指明顯縮短 | Rolando=需要<span style="color:#f87171">ORIF</span> |
| **指骨（Phalanges）** | 橫向可保守；斜向/螺旋需手術 | 取決於穩定性 |
| **腕骨（Scaphoid）** | 近端骨折<span style="color:#f87171">AVN風險高</span> | <span style="color:#f87171">ORIF</span>（位移）或固定（非位移）|

### Jahss Maneuver（掌骨頸復位）

1. 將小指完全屈曲入手掌
2. Distal hand 控制腕部
3. 拇指放在骨折最突出背側點
4. 牵引、遠端背側推、近端手抵抗背側移動

### PIP關節脫位

- 最常見：<span style="color:#22d3ee">遠節指骨</span>在<span style="color:#22d3ee">近節指骨</span>背側
- **復位：** Pressure on base of distal part until passes beyond head of proximal phalanx
- **復位後固定：** 輕度屈曲位

## <span style="color:#60a5fa">肌腱損傷</span>

### 屈肌腱分區（Zone分區）

| Zone | 範圍 |
|------|------|
| **I** | <span style="color:#e2e8f0">FDS</span>附著處到<span style="color:#e2e8f0">FDP</span>附著處 |
| **II** | A1滑車到<span style="color:#e2e8f0">FDS</span>附著處（「<span style="color:#f87171">No man's land</span>」）|
| **III** | 腕隧道遠端到A1滑車 |
| **IV** | 腕隧道內 |
| **V** | 腕隧道近端 |

- **Zone II：** 過去認為不應一次修復，現已被<span style="color:#60a5fa">primary repair + early controlled mobilization</span>取代

### 屈肌腱修復原則

- 手術室內修復（不需當天）
- 越早修復越容易取回縮回的近端
- 術後早期控制性活動復健

### 伸肌腱修復

- 不穿過滑膜鞘 → 修復體積不是問題
- 可在急診修復（經驗和設備允許下）

**Mallet finger：**

- <span style="color:#22d3ee">DIP關節</span>遠端伸肌損傷
- 伸直副木固定<span style="color:#34d399">6週</span>
- 遠端：Dermatotenodesis suture
- 近端：3-0編織永久縫線

---

## <span style="color:#60a5fa">神經損傷</span>

- 尖銳損傷：感覺缺陷 → 假設神經切斷
- 鈍傷：通常挫傷而非切斷，保守治療
- **神經修復：** 需要顯微手術設備和縫線；不應在急診進行
- 延遲修復 → 可能需要移植

---

## <span style="color:#60a5fa">血管損傷</span>

### 評估

- 毛細血管填充、張力、Doppler信號、pinprick出血
- 手指/手缺血 → <span style="color:#f87171">緊急手術探查</span>

### 治療原則

| 情況 | 處理 |
|------|------|
| 活動性出血 | 直接加壓<span style="color:#34d399">10分鐘</span> |
| 加壓失敗 | 止血帶（收縮壓+100 mmHg）；時間<span style="color:#f87171"><2小時</span> |

- <span style="color:#34d399">97%</span>患者掌弓完整 → 簡單結紮通常不影響手部灌注
- 修復的好處：培訓住院醫師

---

## <span style="color:#60a5fa">麻醉</span>

### 局部麻醉

| 藥物 | 特點 |
|------|------|
| **<span style="color:#fb923c">Lidocaine</span>** | 快速起效 |
| **<span style="color:#fb923c">Bupivacaine</span>** | 長效（<span style="color:#34d399">6-8小時</span>）；小兒劑量：0.25%溶液 1mL/kg |
| **<span style="color:#fb923c">Epinephrine</span>** | 傳統上禁用於手；但濃度≤1:100,000可用於腕部以遠；<span style="color:#f87171">不用於指尖</span> |

### 腕部神經阻斷

| 神經 | 進針位置 |
|------|---------|
| **正中神經** | 掌長肌腱尺側進針，穿過前臂筋膜 |
| **尺神經** | 尺側屈腕肌腱深面進針 |
| **橈神經感覺支** | 橈动脉搏動到遠端尺橈關節 |
| **尺神經背側感覺支** | 尺骨背側 |

### Wide Awake手外科

**優點：**

- 純局部麻醉，無止血帶
- 省成本
- 病人可配合指令（術中主動活動測試肌腱修復）

**常用於：** 腕隧道解除、屈肌腱修復

---

## <span style="color:#60a5fa">指尖損傷</span>

### 治療流程

```
指尖損傷
├── 無組織缺損 → 一期修復
└── 有組織缺損
    ├── <1cm²，無骨頭外露 → 二期癒合或局部護理
    └── ≥1cm² 或有骨頭外露
        ├── 指甲剩餘>50% → 局部皮瓣
        └── 指甲剩餘≤50% → 縮短直接縫合
```

### 局部皮瓣選擇

| 皮瓣 | 適用 |
|------|------|
| **V-Y advancement** | 指腹 |
| **Cross-finger flap** | 鄰指皮瓣 |
| **Thenar flap** | 僅用於拇指 |
| **Moberg flap** | 拇指腹 |

## <span style="color:#60a5fa">截肢與再植</span>

### 再植適應症

- <span style="color:#60a5fa">拇指截肢</span>
- <span style="color:#60a5fa">多指截肢</span>
- <span style="color:#60a5fa">兒童截肢</span>

### 禁忌症（相對）

- 單指（拇指除外）截肢
- 高能量損傷（軟組織嚴重受損）
- 缺血時間過長

### 離斷肢體處理

- 濕紗布包裹 → 密封塑膠袋 → 冰水浴（<span style="color:#f87171">不是乾冰！</span>）
- **不要讓離斷部分直接接觸冰塊** → <span style="color:#f87171">凍傷降低存活率</span>

### 修補截肢（Revision Amputation）

- 骨突處用咬骨鉗/銼刀修平
- 將指神經拉向近端切除 → 減少<span style="color:#f87171">疼痛性神經瘤</span>
- 指尖可在急診進行

## <span style="color:#f87171">腔室症候群（Compartment Syndrome）</span>

### 病因

| 類型 | 原因 |
|------|------|
| **內在** | 水腫、血腫（來自骨折） |
| **外在** | 止血帶/副木/敷料過緊、靜脈滲漏 |

### 診斷（5P）

| 項目 | 說明 |
|------|------|
| **<span style="color:#f87171">Pain（疼痛）</span>** | 超出預期；被動伸展時加劇 |
| **Pressure（壓力）** | 腔室張力高 |
| **Paresthesia** | 感覺異常 |
| **Paralysis** | 麻痺 |
| **<span style="color:#f87171">Pulselessness（無脈搏）</span>** | 晚期發現 |

### 前臂/手腔室

- <span style="color:#22d3ee">前臂掌側腔室</span>
- <span style="color:#22d3ee">背側腔室</span>＋Mobile wad
- 手：魚際、小魚際、7塊骨間肌各為獨立腔室

### 治療

- **確診或高度懷疑：** <span style="color:#f87171">緊急手術減壓</span>
- 測量腔室壓力（<span style="color:#f87171">30-45 mmHg</span>或接近舒張壓）
- 減壓包括釋放腕隧道

---

## <span style="color:#f87171">高壓注射傷</span>

- **特點：** 高壓設備（油漆槍、潤滑油槍）注入
- **危害：** 疏水性化合物造成更大傷害
- **是 digit-threatening emergency！**
- **理想6小時內手術**
- 高達<span style="color:#f87171">50%</span>可能需要截指

---

## <span style="color:#60a5fa">破傷風預防</span>

| 傷口類型 | 破傷風類毒素劑量 |
|---------|--------------|
| 清潔小傷口 | 完整免疫者無需追加 |
| 其他傷口 | 若最後一劑>5年前需追加 |
| 破傷風風險傷口 | 追加<span style="color:#fb923c">破傷風免疫球蛋白（TIG）</span>+類毒素 |

---

## <span style="color:#60a5fa">疼痛管理</span>

### 後鴉片時代考量

- 手術後疼痛通常只需<span style="color:#34d399">2天</span>或更少鴉片
- **多模式疼痛管理：** <span style="color:#fb923c">非類固醇抗炎藥</span>＋鴉片
- 減少過度處方

---

## Summary

- 手部結構複雜，<span style="color:#60a5fa">精確解剖知識</span>是準確診斷和治療的基礎
- <span style="color:#60a5fa">舟狀骨骨折</span>是最常見腕部骨折；近端骨折AVN風險高
- <span style="color:#f87171">屈肌腱Zone II（No man's land）</span>的手術修復觀念已改變，primary repair + early mobilization為主流
- <span style="color:#f87171">腔室症候群</span>需早期識別；5P診斷（以疼痛為首），緊急筋膜切開術是救命手術
- <span style="color:#60a5fa">再植適應症：</span>拇指、多指、兒童截肢；單一指截肢（拇指除外）通常不建議
- <span style="color:#f87171">高壓注射傷</span>是digit-threatening emergency，理想6小時內手術
- <span style="color:#22d3ee">Wide Awake手外科</span>可在純局部麻醉下進行，病人可配合術中指令
