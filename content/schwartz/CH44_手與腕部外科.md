# CH44 手與腕部外科 (Surgery of the Hand and Wrist)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 手的實用解剖

### 骨骼結構

- **掌骨（Metacarpals）：** 5根
- **指骨（Phalanges）：** 拇指2節，其餘手指各3節
- **腕骨（Carpal bones）：** 8塊排成兩列

| 近端 | 遠端 |
|------|------|
| 舟狀、月形、三角、豌豆 | 大多角、小多角、頭狀、鉤狀 |

### 肌肉與肌腱

| 類型 | 說明 |
|------|------|
| **外在肌** | 來自前臂（屈肌、伸肌） |
| **內在肌** | 魚際肌、小魚際肌、骨間肌、蚓狀肌 |

### 神經支配

| 神經 | 感覺 | 運動 |
|------|------|------|
| **正中神經** | 拇指/食指/中指/橈側無名指 | 拇指對掌 |
| **尺神經** | 手掌尺側、無名指尺側、小指 | 骨間肌、蚓狀肌（環小指） |
| **橈神經** | 手背橈側 | 手指伸肌 |

### 血液供應

- **掌淺弓、掌深弓：** 來自橈动脉和尺动脉
- 每指有兩條指动脉

## 腕關節

### 舟狀骨骨折（Scaphoid Fracture）

**特點：**

- 腕部最常見骨折
- 跌倒伸手撐地
- **血管供應特異性：** 近端血供脆弱 → 延遲癒合和AVN風險
- **非位移骨折：** 仍有可能20%不癒合

**治療：**

| 類型 | 治療 |
|------|------|
| 位移 | 開放復位內固定（ORIF） |
| 非位移 | 短臂石膏固定 |

### 腕關節韌帶損傷（Mayfield分類）

- 月骨周圍脫位 progression
- **類型4：** 月骨向掌側脫位進入腕隧道 → 可能急性腕隧道徵候群

### 腕關節不穩定

- **舟月脫位（Scapholunate dissociation）：** 舟狀骨和月骨間韌帶損傷

## 骨折與脫位

### 描述骨折的要素

| 要素 | 描述方式 |
|------|---------|
| **位移** | 以骨直徑百分比描述 |
| **旋轉** | 以旋前/旋後角度描述 |
| **成角** | 以角度描述方向 |

### 各部位骨折

| 部位 | 特點 | 治療 |
|------|------|------|
| **遠節指骨 Tuft** | 壓砸傷（門夾）；常非位移 | 保護即可 |
| **掌骨頸（Boxer's fracture）** | 小指；Jahss maneuver復位 | 保守或ORIF |
| **拇指掌骨基底（Bennett）** | 不穩定；拇指明顯縮短 | Rolando=需要ORIF |
| **指骨（Phalanges）** | 橫向可保守；斜向/螺旋需手術 | 取決於穩定性 |
| **腕骨（Scaphoid）** | 近端骨折AVN風險高 | ORIF（位移）或固定（非位移）|

### Jahss Maneuver（掌骨頸復位）

1. 將小指完全屈曲入手掌
2. distal hand 控制腕部
3. 拇指放在骨折最突出背側點
4. 牵引、遠端背側推、近端手抵抗背側移動

### PIP關節脫位

- 最常見：遠節指骨在近節指骨背側
- **復位：** pressure on base of distal part until passes beyond head of proximal phalanx
- **復位後固定：** 輕度屈曲位

## 肌腱損傷

### 屈肌腱分區（Zone圖44-13）

| Zone | 範圍 |
|------|------|
| **I** | FDS附著處到FDP附著處 |
| **II** | A1滑車到FDS附著處（「No man's land」）|
| **III** | 腕隧道遠端到A1滑車 |
| **IV** | 腕隧道內 |
| **V** | 腕隧道近端 |

- **Zone II：** 過去認為不應一次修復，現已被primary repair + early controlled mobilization取代

### 屈肌腱修復原則

- 手術室內修復（不需當天）
- 越早修復越容易取回縮回的近端
- 術後早期控制性活動復健

### 伸肌腱修復

- 不穿過滑膜鞘 → 修復體積不是問題
- 可在急診修復（經驗和設備允許下）

**Mallet finger：**

- DIP關節遠端伸肌損傷
- 伸直副木固定6週
- 遠端：Dermatotenodesis suture
- 近端：3-0編織永久縫線

---

## 神經損傷

- 尖銳損傷：感覺缺陷 → 假設神經切斷
- 鈍傷：通常挫傷而非切斷，保守治療
- **神經修復：** 需要顯微手術設備和縫線；不應在急診進行
- 延遲修復 → 可能需要移植

---

## 血管損傷

### 評估

- 毛細血管填充、張力、Doppler信號、pinprick出血
- 手指/手缺血 → 緊急手術探查

### 治療原則

| 情況 | 處理 |
|------|------|
| 活動性出血 | 直接加壓10分鐘 |
| 加壓失敗 | 止血帶（收縮壓+100 mmHg）；時間<2小時 |

- 97%患者掌弓完整 → 簡單結紮通常不影響手部灌注
- 修復的好處：培訓住院醫師

## 麻醉

### 局部麻醉

| 藥物 | 特點 |
|------|------|
| **Lidocaine** | 快速起效 |
| **Bupivacaine** | 長效（6-8小時）；小兒劑量：0.25%溶液 1mL/kg |
| **Epinephrine** | 傳統上禁用於手；但濃度≤1:100,000可用於腕部以遠；不用於指尖 |

### 腕部神經阻斷

| 神經 | 進針位置 |
|------|---------|
| **正中神經** | 掌長肌腱尺側進針，穿過前臂筋膜 |
| **尺神經** | 尺側屈腕肌腱深面進針 |
| **橈神經感覺支** | 橈动脉搏動到遠端尺橈關節 |
| **尺神經背側感覺支** | 尺骨背側 |

### Wide Awake手外科

**優點：**

- 純局部麻醉，無止血帶
- 省成本
- 病人可配合指令（術中主動活動測試肌腱修復）

**常用於：** 腕隧道解除、屈肌腱修復

## 指尖損傷

### 治療流程

```
指尖損傷
├── 無組織缺損 → 一期修復
└── 有組織缺損
    ├── <1cm²，無骨頭外露 → 二期癒合或局部護理
    └── ≥1cm² 或有骨頭外露
        ├── 指甲剩餘>50% → 局部皮瓣
        └── 指甲剩餘≤50% → 縮短直接縫合
```

### 局部皮瓣選擇

| 皮瓣 | 適用 |
|------|------|
| **V-Y advancement** | 指腹 |
| **Cross-finger flap** | 鄰指皮瓣 |
| **Thenar flap** | 僅用於拇指 |
| **Moberg flap** | 拇指腹 |

## 截肢與再植

### 再植適應症

- 拇指截肢
- 多指截肢
- 兒童截肢

### 禁忌症（相對）

- 單指（拇指除外）截肢
- 高能量損傷（軟組織嚴重受損）
- 缺血時間過長

### 離斷肢體處理

- 濕紗布包裹 → 密封塑膠袋 → 冰水浴（不是乾冰！）
- **不要讓離斷部分直接接觸冰塊** → 凍傷降低存活率

### 修補截肢（Revision Amputation）

- 骨突處用咬骨鉗/銼刀修平
- 將指神經拉向近端切除 → 減少疼痛性神經瘤
- 指尖可在急診進行

## 腔室症候群

### 病因

| 類型 | 原因 |
|------|------|
| **內在** | 水腫、血腫（來自骨折） |
| **外在** | 止血帶/副木/敷料過緊、靜脈滲漏 |

### 診斷（5P）

| 項目 | 說明 |
|------|------|
| **Pain（疼痛）** | 超出預期；被動伸展時加劇 |
| **Pressure（壓力）** | 腔室張力高 |
| **Paresthesia** | 感覺異常 |
| **Paralysis** | 麻痺 |
| **Pulselessness（無脈搏）** | 晚期發現 |

### 前臂/手腔室

- 前臂掌側腔室
- 背側腔室＋Mobile wad
- 手：魚際、小魚際、7塊骨間肌各為獨立腔室

### 治療

- **確診或高度懷疑：** 緊急手術減壓
- 測量腔室壓力（30-45 mmHg或接近舒張壓）
- 減壓包括釋放腕隧道

---

## 高壓注射傷

- **特點：** 高壓設備（油漆槍、潤滑油槍）注入
- **危害：** 疏水性化合物造成更大傷害
- **是digit-threatening emergency！**
- **理想6小時內手術**
- 高達50%可能需要截指

---

## 破傷風預防

| 傷口類型 | 破傷風類毒素劑量 |
|---------|--------------|
| 清潔小傷口 | 完整免疫者無需追加 |
| 其他傷口 | 若最後一劑>5年前需追加 |
| 破傷風風險傷口 | 追加破傷風免疫球蛋白（TIG）+類毒素 |

---

## 疼痛管理

### 後鴉片時代考量

- 手術後疼痛通常只需2天或更少鴉片
- **多模式疼痛管理：** 非類固醇抗炎藥＋鴉片
- 減少過度處方

## 重點摘要（Key Points）

1. **手是複雜結構**：理解其解剖對於準確診斷和治療至關重要
2. **傷口封閉原則：** 傷口冲洗 → 確認止血 → 分層閉合
3. **複雜手外傷處理：** 需完整評估、計劃和適當分類
4. **腕關節損傷：** 舟狀骨骨折最常見；近端骨折AVN風險高
5. **骨折穩定性：** 橫向通常穩定；斜向縮短；螺旋需要手術
6. **屈肌腱分區：** Zone II（"No man's land"）過去觀念已被primary repair + early mobilization取代
7. **腔室症候群：** 早期識別緊急筋膜切開術是救命的手術
8. **指尖損傷：** 常見；處理流程取決於組織缺損量和是否有骨頭外露
9. **再植適應症：** 拇指、多指、兒童截肢；單一指截肢（拇指除外）通常不建議
10. **局部麻醉：** 腕部神經阻斷可提供多指麻醉、避免炎症區、避免注射volume造成操作困難
