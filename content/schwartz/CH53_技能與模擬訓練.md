# CH53 技能與模擬訓練 (Skills and Simulation)

**來源：** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

模擬訓練已被證實可有效將技能從模擬環境轉移至實際手術室。本章介紹模擬器的科學基礎（虛擬實境、身體模型、任務訓練器）、ACS-APDS技能課程體系（基礎14項+程序15項）、Da Vinci機器人手術模擬及效度類型，展望AI個人化學習和病人特異性模擬演練的未來發展。

---

## <span style="color:#60a5fa">模擬訓練的科學基礎</span>

### 核心假設

- 外科技術技能可在手術室外（OR）**<span style="color:#60a5fa">有效學習及測試</span>**。

### 經典研究

- **<span style="color:#22d3ee">Dr. Angela Davenport</span>** 等人證實模擬訓練可有效將技能轉移至手術室。
- 受過模擬訓練的住院醫師在<span style="color:#22d3ee">腹腔鏡膽囊切除術</span>表現**<span style="color:#60a5fa">顯著較佳</span>**。

### 技能轉移機制

| 機制 | 說明 |
|------|------|
| **<span style="color:#60a5fa">低壓力環境</span>** | 可犯錯無後果→建立<span style="color:#22d3ee">肌肉記憶</span>與自動性 |
| **<span style="color:#34d399">標準化經驗</span>** | 不受臨床病例變異性影響 |
| **<span style="color:#60a5fa">廣泛病例接觸</span>** | 可練習臨床中難得的技能 |

## <span style="color:#60a5fa">模擬器類型</span>

### 虛擬實境（VR）模擬器

- 使用電腦圖形建立 **3D 環境**，模擬手術外觀與觸感。
- 可提供**<span style="color:#60a5fa">觸覺回饋（haptic feedback）</span>**。

| 代表系統 | 說明 |
|----------|------|
| **<span style="color:#60a5fa">MIST VR</span>** | 虛擬實境訓練系統 |
| **<span style="color:#60a5fa">LapSim</span>** | 腹腔鏡模擬系統 |
| **<span style="color:#60a5fa">Da Vinci Skills Simulator</span>** | 達文西機器人模擬系統 |

| 優點 | 缺點 |
|------|------|
| <span style="color:#34d399">標準化可重複</span> | <span style="color:#f87171">造價高</span> |
| <span style="color:#60a5fa">客觀表現回饋</span>（時間、錯誤、動作經濟性）| 部分系統<span style="color:#f87171">觸覺回饋仍不夠真實</span> |
| <span style="color:#34d399">追蹤進步</span> | |

### 身體模型（Physical Models）

- 包括：**<span style="color:#22d3ee">大體組織</span>、<span style="color:#22d3ee">動物組織</span>、<span style="color:#22d3ee">合成模型</span>**。

| 優點 | 缺點 |
|------|------|
| 比 VR <span style="color:#34d399">更真實</span> | <span style="color:#f87171">昂貴</span> |
| | <span style="color:#f87171">重複使用性低</span> |

| 合成模型應用 | 說明 |
|-------------|------|
| **<span style="color:#60a5fa">3D 列印病人特異性模型</span>** | 可用於<span style="color:#60a5fa">術前演練</span> |

### 任務訓練器（Task Trainers）

- 模擬**特定單一手術任務**（如打結、縫合、器械操作）。
- 通常為**<span style="color:#e2e8f0">低擬真度（low-fidelity）</span>**模擬器。
- 適用於**早期訓練者**學習基礎技能。

## <span style="color:#60a5fa">模擬器驗證</span>

### 效度類型

| 效度類型 | 定義 | 建立方式 |
|----------|------|---------|
| **<span style="color:#e2e8f0">內容效度（Content validity）</span>** | 模擬是否代表實際任務 | 專家意見建立 |
| **<span style="color:#e2e8f0">建構效度（Construct validity）</span>** | 模擬能否區分不同技能水準者 | 專家 vs 新手比較 |
| **<span style="color:#e2e8f0">表面效度（Face validity）</span>** | 模擬外觀與觸感是否像實際任務 | 使用者回饋建立 |
| **<span style="color:#60a5fa">轉移效度（Transfer validity）</span>** | 模擬所學技能能否轉移至實際臨床情境 | **<span style="color:#f87171">最重要</span>**，已有眾多研究證實 |

## <span style="color:#60a5fa">Da Vinci 機器人手術模擬</span>

### Da Vinci Skills Simulator（DVSS）

- 整合於 Da Vinci 系統的手術模擬器。
- 機器人手術模擬訓練已成為外科教育**標準組成部分**。

### 基礎課程模組

| 模組 | 說明 |
|------|------|
| **相機控制** | 機器人視覺操作 |
| **關節操作** | 器械關節控制 |
| **能量器械操作** | 能量設備使用 |
| **體驗練習** | 綜合練習 |

## Summary

- **<span style="color:#60a5fa">模擬訓練：</span>** 可有效將技能從模擬環境轉移至實際手術室（Dr. Angela Davenport等證實）
- **<span style="color:#60a5fa">VR模擬器：</span>** MIST VR、LapSim、Da Vinci Skills Simulator；標準化可重複但造價高
- **<span style="color:#60a5fa">任務訓練器：</span>** 低擬真度（low-fidelity）；適用於早期訓練者學習基礎技能
- **<span style="color:#60a5fa">ACS-APDS基礎14項：</span>** 無菌技術、結紮、縫合、皮瓣、植皮、導尿、氣道管理、胸管、中心靜脈導管、外科切片、腹部基本技術、腹腔鏡
- **<span style="color:#60a5fa">效度類型：</span>** 轉移效度（transfer validity）是最重要的效度類型
- **<span style="color:#60a5fa">Da Vinci DVSS：</span>** 機器人手術模擬已成外科教育標準組成部分
- **<span style="color:#60a5fa">未來：</span>** AI個人化學習、病人特異性3D列印模型術前演練
