# CH16 分子生物學、疾病的原子理論與精準外科 (Molecular Biology, The Atomic Theory of Disease, and Precision Surgery)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 概述 (Overview)

- 現代外科越來越依賴**分子研究**（精準外科）。
- **基因體資訊**（如 BRCA、RET proto-oncogene 突變）引導預防性手術。
- 分子工程導致**癌症特異性基因治療**作為手術減積的輔助。

### 關鍵歷史里程碑

| 年份 | 事件 |
|------|------|
| 1869 | Miescher — 分離出 DNA |
| 1900 | 孟德爾定律重新發現 |
| 1944 | DNA 確認為遺傳物質（Avery, MacLeod, McCarty） |
| 1953 | Watson & Crick — DNA 雙螺旋結構 |
| 1970s | 重組 DNA 技術、PCR 發展 |
| 2003 | 人類基因體計畫完成（~20,000-25,000 基因，30 億鹼基對） |

## 中心法則：DNA → RNA → 蛋白質

```
DNA → Transcription → RNA → Translation → Protein
```

### 關鍵分子

| 分子 | 功能 |
|------|------|
| **DNA** | 遺傳資訊儲存 |
| **mRNA** | 攜帶遺傳密碼從 DNA 到核糖體 |
| **tRNA** | 轉譯時傳遞胺基酸 |
| **rRNA** | 核糖體 RNA — 蛋白質合成機器 |
| **miRNA** | 微小 RNA — 轉錄後基因調控 |
| **piRNA** | Piwi-interacting RNA — 表觀遺傳調控 |
| **lincRNA** | Long intergenic noncoding RNA — 染色質修飾 |

## DNA 結構與複製

### DNA 結構

- **右手雙螺旋**（每圈 10.4 核苷酸對）
- **反平行鏈**（5' → 3' 方向）
- **骨幹：** 糖-磷酸（磷酸二酯鍵）
- **鹼基：** Adenine (A), Thymine (T), Cytosine (C), Guanine (G)
- **鹼基配對：** A=T（2 個氫鍵），C≡G（3 個氫鍵）

### DNA 複製

複製步驟：
1. **Helicase** 解開雙螺旋
2. **Primase** 合成 RNA 引子
3. **DNA polymerase III** 以 5'→3' 方向延伸
4. **Leading strand** — 連續合成
5. **Lagging strand** — Okazaki fragments（不連續）
6. **DNA ligase** 連接片段
7. **Proofreading** 確保高精確度

### 複製錯誤 → 突變

- 可改變編碼蛋白質 → 改變細胞行為。
- **遺傳不穩定性** — 大量基因組變化，尤其在癌細胞。

## 基因調控 (Gene Regulation)

### 轉錄（DNA → RNA）

- **Bacteria：** 單一 RNA 聚合酶（mRNA, rRNA, tRNA）。
- **Eukaryotes：** 更複雜的調控。

### 轉錄後修飾

| 過程 | 描述 |
|------|------|
| **5' capping** | 添加甲基鳥苷 cap |
| **Polyadenylation** | 添加 Poly-A tail |
| **Splicing** | 移除 introns，連接 exons |
| **Alternative splicing** | 不同 exon 組合 → 蛋白質多樣性 |
| **mRNA stability** | 影響轉譯效率 |
| **Nuclear export** | 調控轉運至細胞質 |

### 表觀遺傳調控

| 修飾 | 效應 |
|------|------|
| **DNA methylation** | 基因沉默（CpG islands） |
| **Histone acetylation** | 開放染色質 → 基因活化 |
| **Histone methylation** | 可活化或抑制 |
| **Chromatin remodeling** | 核小體重新定位 |

## 人類基因體 (Human Genome)

### 關鍵特徵

- **~20,000-25,000 蛋白質編碼基因**（先前估計為 100,000）
- **~30 億鹼基對**
- **98% 非編碼區域**（introns、調控序列、轉座子）
- **~1.5% 編碼蛋白質**

### 外科重要基因家族

| 基因 | 相關疾病 |
|------|---------|
| **BRCA1/BRCA2** | 遺傳性乳癌/卵巢癌 |
| **RET** | 多發性內分泌腫瘤（MEN2A/2B） |
| **APC** | 家族性腺瘤性息肉病（FAP） |
| **TP53** | Li-Fraumeni syndrome |
| **VHL** | von Hippel-Lindau syndrome |
| **KRAS, BRAF** | 結腸癌、黑色素瘤 |
| **HER2/ERBB2** | 乳癌 |

## 細胞週期與細胞凋亡 (Cell Cycle & Apoptosis)

### 細胞週期階段

| 階段 | 關鍵事件 |
|------|---------|
| **G0** | 靜止狀態 |
| **G1** | 生長、蛋白質合成 |
| **S** | DNA 複製 |
| **G2** | 生長、有絲分裂準備 |
| **M** | 有絲分裂（前期、中期、後期、末期） |

### 細胞週期檢查點

- **G1/S 檢查點** — DNA 損傷檢查
- **G2/M 檢查點** — 複製完整性
- **Metaphase 檢查點** — 染色體排列

### 細胞凋亡（程式性細胞死亡）

**外在路徑：**
```
Death receptors (Fas, TRAIL-R) → Caspase-8 → Caspase-3
```

**內在路徑：**
```
Mitochondrial outer membrane permeabilization (MOMP)
→ Cytochrome c release → Caspase-9 → Caspase-3
```

**關鍵調控因子：**

| 促凋亡 | 抗凋亡 |
|--------|--------|
| **BAX, BAK** | **BCL-2, BCL-XL** |
| **p53** | **MCL-1** |
| **Caspase-3, -8, -9** | **IAPs (survivin)** |

**與癌症的關聯：** 凋亡減少 → 無限制增殖。

## 訊號傳遞路徑 (Signal Transduction Pathways)

### 主要路徑

#### 1. 受體酪氨酸激酶 (RTK) 路徑

```
Growth factor → RTK → RAS → RAF → MEK → ERK → Cell proliferation
```

- **EGFR** — 表皮生長因子受體（針對結腸癌、肺癌）。
- **HER2/ERBB2** — 乳癌中放大（trastuzumab 標的）。

#### 2. PI3K/AKT/mTOR 路徑

```
RTK → PI3K → PIP3 → PDK1 → AKT → mTOR → Protein synthesis, cell growth
```

- **PIK3CA 突變** — 常見於乳癌、結腸癌、子宮內膜癌。
- **PTEN 缺失** — 腫瘤抑制基因（負向調控）。

#### 3. MAPK 路徑

- 細胞增殖、分化、壓力反應。
- **BRAF V600E 突變** — 黑色素瘤、結腸癌（vemurafenib 標的）。

#### 4. Wnt/β-catenin 路徑

- 幹細胞調控、細胞命運。
- **APC 突變** — 結腸癌（家族性腺瘤性息肉病）。

#### 5. TGF-β 路徑

- 細胞生長抑制、免疫調控。
- 雙重角色：腫瘤抑制（早期）→ 促進（晚期）。

#### 6. JAK/STAT 路徑

- 細胞激素訊號。
- **JAK2 V617F** — 骨髓增生病。

## 精準醫學與外科 (Precision Medicine & Surgery)

### 關鍵原則

1. **根據分子特徵進行患者分層**
2. **根據生物標記測試選擇標靶治療**
3. **個人化治療決策**
4. **減少無效治療**

### 外科中的分子檢測

| 檢測 | 目的 | 臨床應用 |
|------|------|---------|
| **Next-generation sequencing (NGS)** | 多基因組合 | 腫瘤分析 |
| **PCR (KRAS, BRAF, etc.)** | 特定突變檢測 | 治療選擇 |
| **Fluorescence in situ hybridization (FISH)** | 基因放大 | HER2 測試 |
| **Immunohistochemistry (IHC)** | 蛋白質表現 | HER2, PD-L1 |
| **Liquid biopsy (ctDNA)** | 非侵入性監測 | 抗性突變 |

### 精準外科應用

- **BRCA1/2 檢測** → 預防性乳房切除/卵巢切除。
- **RET 突變** → MEN2 中預防性甲狀腺切除。
- **MSI-H/dMMR 檢測** → 免疫治療反應（pembrolizumab）。
- **循環腫瘤 DNA (ctDNA)** → 微量殘留疾病偵測。

## CRISPR-Cas9 基因體編輯

### 組成

- **Guide RNA (gRNA)** — 20 nt 序列，與目標互補。
- **Cas9 nuclease** — 產生雙股斷裂。
- **PAM sequence** — 目標旁邊所需（SpCas9 為 NGG）。

### 應用

- **基因剔除** — 框架位移突變。
- **基因修正** — 同源 directed repair (HDR)。
- **基因活化/抑制** — 催化死亡 Cas9 (dCas9)。
- **治療** — 鐮刀型紅血球疾病（ex vivo）、LCA10（in vivo）。

### 限制

- Off-target effects（脫靶效應）。
- Delivery efficiency（遞送效率）。
- HDR efficiency（在非分裂細胞中低）。

## 疾病的原子理論 (The Atomic Theory of Disease)

### 概念

- 疾病起源於**分子/細胞改變**。
- **基因突變** → 蛋白質功能改變 → 細胞功能障礙 → 組織/器官衰竭。
- **精準外科** 旨在分子層面糾正或補償。

### 外科影響

1. 手術前**分子診斷**。
2. 標靶**新輔助/輔助治療**。
3. **分子分期** 輔助 TNM 分期。
4. 根據腫瘤生物學**個人化手術方法**。
