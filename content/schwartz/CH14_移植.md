# <span style="color:#60a5fa">CH14 移植</span> (<span style="color:#60a5fa">Transplantation</span>)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## <span style="color:#60a5fa">移植免疫學</span> (<span style="color:#60a5fa">Transplant Immunobiology</span>)

### 移植抗原 (<span style="color:#60a5fa">Transplant Antigens</span>)

- **<span style="color:#60a5fa">MHC</span> (<span style="color:#e2e8f0">Major Histocompatibility Complex</span>) = <span style="color:#60a5fa">HLA</span> (<span style="color:#e2e8f0">Human Leukocyte Antigen</span>)**
- **Class I <span style="color:#60a5fa">MHC</span>：** 存在於所有<span style="color:#60a5fa">有核細胞表面</span>；呈現 <span style="color:#60a5fa">endogenous peptides</span> → <span style="color:#60a5fa">CD8+</span> <span style="color:#60a5fa">T 細胞</span>。
- **Class II <span style="color:#60a5fa">MHC</span>：** 存在於抗原呈遞細胞（<span style="color:#22d3ee">樹突細胞</span>、<span style="color:#22d3ee">巨噬細胞</span>、<span style="color:#22d3ee">B 細胞</span>）；呈現 <span style="color:#60a5fa">exogenous peptides</span> → <span style="color:#60a5fa">CD4+</span> <span style="color:#60a5fa">T 細胞</span>。
- <span style="color:#60a5fa">HLA</span> matching 影響<span style="color:#f87171">移植排斥風險</span>。

### <span style="color:#60a5fa">Allorecognition</span> 與<span style="color:#60a5fa">淋巴細胞活化</span>

- **<span style="color:#60a5fa">Direct allorecognition</span>：** 受者 <span style="color:#60a5fa">T 細胞</span>直接辨識<span style="color:#60a5fa">捐贈者 APC</span> 上的 <span style="color:#60a5fa">HLA</span> 分子。
- **<span style="color:#60a5fa">Indirect allorecognition</span>：** 受者 <span style="color:#60a5fa">T 細胞</span>辨識經由<span style="color:#60a5fa">受者 APC</span> 處理的捐贈者 <span style="color:#60a5fa">HLA</span> peptides。
- <span style="color:#60a5fa">淋巴細胞活化</span>需要：信號 1（抗原辨識）+ 信號 2（<span style="color:#60a5fa">co-stimulation</span>，<span style="color:#60a5fa">CD28:B7</span>）。

### <span style="color:#f87171">臨床<span style="color:#f87171">排斥反應</span></span> (<span style="color:#f87171">Clinical Rejection</span>)

| 類型 | 時間 | 機制 | 表現 |
|------|------|------|------|
| **<span style="color:#f87171">Hyperacute rejection</span>（<span style="color:#f87171">超<span style="color:#f87171">急性排斥</span></span>）** | 分鐘至數小時 | <span style="color:#f87171">預存抗體</span>（<span style="color:#f87171"><span style="color:#f87171">preformed antibodies</span></span>）對抗 <span style="color:#60a5fa">HLA</span> 或 <span style="color:#60a5fa">ABO</span> | <span style="color:#f87171">移植器官立即壞死</span> |
| **<span style="color:#f87171">Acute rejection</span>（<span style="color:#f87171">急性排斥</span>）** | 數天至數月 | <span style="color:#60a5fa">T 細胞</span>媒介（<span style="color:#f87171">cellular</span>）或<span style="color:#f87171">抗體媒介</span>（<span style="color:#f87171">humoral</span>） | <span style="color:#f87171">移植功能減退</span> |
| **<span style="color:#f87171"><span style="color:#f87171">慢性排斥</span></span>（<span style="color:#f87171">慢性排斥</span>）** | 數月至數年 | <span style="color:#f87171">免疫和非免疫因素</span> | <span style="color:#f87171">移植器官進行性功能喪失</span> |

- **<span style="color:#f87171">急性細胞排斥</span>：** <span style="color:#f87171">腎小管炎</span>（<span style="color:#f87171">tubulitis</span>）、<span style="color:#f87171">間質浸潤</span>。
- **<span style="color:#f87171">急性體液排斥</span>：** <span style="color:#f87171">血管內皮炎</span>、<span style="color:#f87171"><span style="color:#f87171">C4d 染色</span>陽性</span>。
- **<span style="color:#f87171">慢性排斥</span>：** <span style="color:#f87171">移植物血管病變</span>（<span style="color:#f87171">transplant vasculopathy</span>）。

## <span style="color:#fb923c">臨床<span style="color:#f87171">免疫抑制</span></span> (<span style="color:#fb923c">Clinical Immunosuppression</span>)

### <span style="color:#60a5fa">誘導治療</span> (<span style="color:#60a5fa">Induction</span>)

- 移植後立即使用高劑量<span style="color:#fb923c"><span style="color:#f87171">免疫抑制</span>劑</span>。

### 常用<span style="color:#f87171">免疫抑制</span>藥物

| 藥物 | 機制 | 副作用 |
|------|------|--------|
| **<span style="color:#fb923c">Cyclosporine</span>** | 抑制 <span style="color:#60a5fa">calcineurin</span> → 阻斷 <span style="color:#60a5fa">IL-2 轉錄</span> | <span style="color:#f87171">腎毒性</span>、<span style="color:#f87171">高血壓</span>、<span style="color:#f87171">神經毒性</span> |
| **<span style="color:#fb923c">Tacrolimus</span>** | 同上（<span style="color:#60a5fa">效力更強</span>） | <span style="color:#f87171">腎毒性</span>、<span style="color:#f87171">糖尿病</span>、<span style="color:#f87171">神經毒性</span> |
| **<span style="color:#fb923c">Sirolimus</span> (rapamycin)** | 抑制 <span style="color:#60a5fa">mTOR</span> → 阻斷<span style="color:#60a5fa">細胞週期</span> | <span style="color:#f87171">高脂血症</span>、<span style="color:#f87171">傷口癒合延遲</span>、<span style="color:#f87171">肺炎</span> |
| **<span style="color:#fb923c">Mycophenolate mofetil</span> (<span style="color:#fb923c">MMF</span>)** | 抑制 <span style="color:#60a5fa">inosine monophosphate dehydrogenase</span> | <span style="color:#f87171">腸胃不適</span>、<span style="color:#f87171">骨髓抑制</span> |
| **<span style="color:#fb923c">Azathioprine</span>** | 抑制 <span style="color:#60a5fa">purine synthesis</span> | <span style="color:#f87171">骨髓抑制</span>、<span style="color:#f87171">肝毒性</span> |
| **<span style="color:#fb923c">Corticosteroids</span>** | <span style="color:#fb923c">廣泛抗發炎</span> | <span style="color:#f87171">糖尿病</span>、<span style="color:#f87171">高血壓</span>、<span style="color:#f87171">骨質疏鬆</span>、<span style="color:#f87171">感染</span> |
| **<span style="color:#fb923c">Belatacept</span>** | <span style="color:#60a5fa">CTLA4-Ig</span> 融合蛋白；阻斷 <span style="color:#60a5fa">co-stimulation</span> | <span style="color:#f87171"><span style="color:#f87171">移植後淋巴增生病</span></span> (<span style="color:#f87171"><span style="color:#f87171">PTLD</span></span>) |

### 抗體製劑

| 製劑 | 類型 | 用途 |
|------|------|------|
| **<span style="color:#fb923c">Anti-thymocyte globulin</span> (<span style="color:#fb923c">ATG</span>)** | <span style="color:#f87171">去除性抗體</span>（<span style="color:#fb923c">抗 CD52</span>） | <span style="color:#f87171">急性排斥</span>治療、誘導 |
| **<span style="color:#fb923c">Basiliximab</span>** | <span style="color:#fb923c">抗 CD25</span>（<span style="color:#60a5fa">IL-2R</span>）單株抗體 | <span style="color:#60a5fa">選擇性誘導</span> |
| **<span style="color:#fb923c"><span style="color:#fb923c">Rituximab</span></span>** | <span style="color:#fb923c">抗 CD20</span> 單株抗體 | 去除 <span style="color:#22d3ee">B 細胞</span>、<span style="color:#60a5fa">ABO</span> 不相容 |
| **<span style="color:#fb923c">Bortezomib</span>** | <span style="color:#fb923c">蛋白酶體抑制劑</span> | <span style="color:#f87171">抗體媒介</span>排斥 |
| **<span style="color:#fb923c">Eculizumab</span>** | <span style="color:#fb923c">抗 C5</span> 單株抗體 | 預防 <span style="color:#60a5fa">ABO</span> 不相容或<span style="color:#f87171">高敏感患者</span> |

## <span style="color:#f87171">體液性排斥</span> (<span style="color:#f87171">Humoral Rejection</span>)

- **<span style="color:#f87171">Donor-specific antibodies</span> (<span style="color:#f87171">DSA</span>)** 的存在是關鍵。
- **<span style="color:#f87171">C4d 染色</span>：** 陽性表示<span style="color:#f87171">體液性排斥</span>。
- 治療：<span style="color:#fb923c">血漿置換</span>、<span style="color:#fb923c">免疫球蛋白</span>（<span style="color:#fb923c">IVIG</span>）、rituximab、bortezomib、eculizumab。

## <span style="color:#60a5fa">器官捐贈與保存</span> (<span style="color:#60a5fa">Organ Donation</span> & Preservation)

### 捐贈者類型

| 類型 | 說明 |
|------|------|
| **Brain death (<span style="color:#60a5fa">BD</span>) donor** | <span style="color:#60a5fa">腦死捐贈者</span>（<span style="color:#60a5fa">心臟跳動捐贈者</span>） |
| **Donation after cardiac death (<span style="color:#60a5fa"><span style="color:#60a5fa">DCD</span></span>)** | <span style="color:#f87171">心跳停止後捐贈</span>（<span style="color:#f87171">非心跳捐贈者</span>） |
| **<span style="color:#60a5fa">Living donor</span>** | <span style="color:#60a5fa">親屬或非親屬</span><span style="color:#60a5fa">活體捐贈</span> |

### <span style="color:#60a5fa">活體捐贈</span>

- **<span style="color:#22d3ee">腎臟</span>：** <span style="color:#60a5fa">親屬或非親屬</span>。<span style="color:#60a5fa">微創手術</span>（<span style="color:#60a5fa">腹腔鏡捐贈腎切除</span>）增加<span style="color:#60a5fa">活體捐贈</span>意願。
- **<span style="color:#22d3ee">肝臟</span>：** <span style="color:#60a5fa">左葉或右葉肝切除</span>。<span style="color:#f87171">捐贈者年齡</span>和<span style="color:#22d3ee">肝臟</span>品質是關鍵考量。
- **<span style="color:#22d3ee">小腸</span>/<span style="color:#22d3ee">胰臟</span>：** <span style="color:#60a5fa">特定<span style="color:#60a5fa">適應症</span></span>。

### <span style="color:#60a5fa">器官保存</span>

| 溶液 | 適用 | 特點 |
|------|------|------|
| **<span style="color:#fb923c">UW solution</span> (<span style="color:#fb923c">University of Wisconsin</span>)** | 肝、胰、腎 | <span style="color:#60a5fa">細胞內離子組成</span>；含 <span style="color:#fb923c">lactobionate</span> 和 <span style="color:#fb923c">raffinose</span> |
| **<span style="color:#fb923c">HTK solution</span> (<span style="color:#fb923c">Histidine-Tryptophan-Ketoglutarate</span>)** | 肝、腎、心臟 | <span style="color:#60a5fa">組氨酸 buffer</span>；<span style="color:#34d399">低粘度</span> |
| **<span style="color:#fb923c">Euro-Collins solution</span>** | 腎 | <span style="color:#60a5fa">細胞內離子組成</span> |

### <span style="color:#60a5fa">器官分享</span>

- <span style="color:#60a5fa">UNOS</span> (<span style="color:#e2e8f0">United Network for Organ Sharing</span>)：美國<span style="color:#60a5fa">器官分配系統</span>。
- <span style="color:#60a5fa">MELD</span> (<span style="color:#e2e8f0">Model for End-Stage Liver Disease</span>) score：用於<span style="color:#22d3ee">肝臟</span>分配。

## <span style="color:#22d3ee">腎臟移植</span> (<span style="color:#22d3ee">Kidney Transplantation</span>)

### <span style="color:#60a5fa">適應症</span>

- <span style="color:#f87171">末期腎疾病</span>（<span style="color:#f87171">ESRD</span>）：<span style="color:#f87171">慢性腎絲球腎炎</span>、<span style="color:#f87171">糖尿病腎病變</span>、<span style="color:#f87171">高血壓性腎硬化</span>。

### 結果

- **1 年存活率：** <span style="color:#34d399">95%</span>（<span style="color:#22d3ee">活體腎臟</span>）、<span style="color:#34d399">90%</span>（<span style="color:#f87171">大體腎臟</span>）。
- **10 年存活率：** <span style="color:#34d399">60-70%</span>。
- 主要併發症：<span style="color:#f87171">感染</span>、<span style="color:#f87171">心血管疾病</span>、<span style="color:#f87171">惡性腫瘤</span>。

---

## <span style="color:#22d3ee">肝臟移植</span> (<span style="color:#22d3ee">Liver Transplantation</span>)

### <span style="color:#60a5fa">適應症</span>

- <span style="color:#f87171">末期肝疾病</span>：<span style="color:#f87171">肝硬化</span>、<span style="color:#f87171">猛爆性肝衰竭</span>、<span style="color:#f87171">肝細胞癌</span>（<span style="color:#f87171">HCC</span> within <span style="color:#60a5fa">Milan criteria</span>）。

### 捐贈者類型

| 類型 | 優點 | 缺點 |
|------|------|------|
| **<span style="color:#60a5fa">BD</span> (Brain death donor)** | 最佳<span style="color:#22d3ee">肝臟</span>品質 | 捐贈者短缺 |
| **<span style="color:#60a5fa">DCD</span>** | 增加<span style="color:#60a5fa">捐贈者池</span> | <span style="color:#f87171">缺血性膽道病變</span>風險較高 |
| **<span style="color:#60a5fa">Split-liver</span>** | 一個捐贈<span style="color:#22d3ee">肝臟</span>分給兩個受贈者（通常是成人和兒童） |
| **<span style="color:#60a5fa">Living donor</span> liver transplant (<span style="color:#60a5fa">LDLT</span>)** | <span style="color:#60a5fa">右葉肝移植</span> |

### 手術

- <span style="color:#60a5fa">原位移植</span>（<span style="color:#60a5fa">orthotopic</span>）。切除<span style="color:#22d3ee">病肝</span>後植入新肝。
- **<span style="color:#60a5fa">靜脈-靜脈分流</span>（<span style="color:#60a5fa">Venovenous bypass</span>）：** 某些情況下使用。
- 膽道重建：<span style="color:#60a5fa">Roux-en-Y choledochojejunostomy</span> 或 <span style="color:#60a5fa">duct-to-duct anastomosis</span>。

### 併發症

| 併發症 | 發生時間 | 特點 |
|--------|---------|------|
| **<span style="color:#f87171">肝動脈血栓</span> (<span style="color:#f87171">HAT</span>)** | 早期 | <span style="color:#f87171">移植肝壞死</span>；需<span style="color:#f87171">緊急再移植</span> |
| **<span style="color:#f87171">門靜脈血栓</span>** | 早期 | <span style="color:#f87171">移植肝功能障礙</span> |
| **<span style="color:#f87171">膽道併發症</span>** | 早期/晚期 | <span style="color:#f87171">膽漏</span>、<span style="color:#f87171">膽道狹窄</span>（<span style="color:#f87171">ischemic cholangiopathy</span>） |
| **<span style="color:#f87171">排斥反應</span>** | 急/慢性 | 膽汁減少、<span style="color:#f87171">黃疸</span>；確診需<span style="color:#22d3ee">肝臟</span>穿刺 |

### 結果

- **1 年存活率：** <span style="color:#34d399">80-90%</span>。
- 過去 30 年結果持續改善。

## <span style="color:#60a5fa">心臟移植</span> (Heart <span style="color:#60a5fa">Transplantation</span>)

### <span style="color:#60a5fa">適應症</span>

- <span style="color:#f87171">末期心臟衰竭</span>（<span style="color:#f87171">LVEF</span> <20-25%）、<span style="color:#f87171">藥物和節律器治療無效</span>。
- <span style="color:#f87171">缺血性心肌病</span>、<span style="color:#f87171">擴張性心肌病</span>、<span style="color:#f87171">先天性心臟病晚期</span>。

### 禁忌症

- <span style="color:#f87171">肺血管阻力過高</span>（<span style="color:#f87171">PVR</span> >5 <span style="color:#f87171">Wood units</span>）。
- 活動性<span style="color:#f87171">感染</span>、惡性腫瘤。
- 無法配合終生<span style="color:#f87171">免疫抑制</span>。

### 結果

- **1 年存活率：** <span style="color:#34d399">85-90%</span>。
- 主要死因：<span style="color:#f87171">感染</span>、<span style="color:#f87171">排斥反應</span>、<span style="color:#f87171">移植心臟冠狀血管病變</span>（cardiac allograft vasculopathy, <span style="color:#f87171">CAV</span>）。

---

## <span style="color:#22d3ee">肺臟移植</span> (Lung <span style="color:#60a5fa">Transplantation</span>)

### <span style="color:#60a5fa">適應症</span>

- <span style="color:#f87171">末期肺部疾病</span>：<span style="color:#f87171">COPD</span>、<span style="color:#f87171">囊性纖維化</span>、<span style="color:#f87171">特發性肺纖維化</span>、<span style="color:#f87171">α1-antitrypsin 缺乏</span>。
- <span style="color:#60a5fa">單肺移植</span>或<span style="color:#60a5fa">雙肺移植</span>。

### 結果

- **1 年存活率：** <span style="color:#34d399">80-85%</span>。
- 主要併發症：<span style="color:#f87171">支氣管吻合口併發症</span>（<span style="color:#f87171">支氣管裂開</span>、狹窄）、<span style="color:#f87171">感染</span>、排斥。

---

## <span style="color:#22d3ee">小腸</span>及多臟器移植 (<span style="color:#60a5fa">Intestine</span> & Multivisceral <span style="color:#60a5fa">Transplantation</span>)

### <span style="color:#60a5fa">適應症</span>

- <span style="color:#f87171">短腸症候群</span>（<span style="color:#f87171">short bowel syndrome</span>）伴隨<span style="color:#60a5fa">靜脈營養</span>無法進行或不耐受。
- <span style="color:#f87171">先天性腸道疾病</span>、<span style="color:#f87171">腸道動力障礙</span>。

### 結果

- 腸道移植結果不如其他實體器官移植。
- <span style="color:#f87171">移植物和患者存活率</span>較低。

---

## <span style="color:#60a5fa">異種移植</span> (<span style="color:#60a5fa">Xenotransplantation</span>)

- <span style="color:#f87171">動物對人類移植</span>（目前仍是實驗階段）。
- 主要挑戰：<span style="color:#f87171">超<span style="color:#f87171">急性排斥</span></span>（<span style="color:#f87171">hyperacute rejection</span>） due to <span style="color:#f87171"><span style="color:#f87171">preformed antibodies</span></span> against <span style="color:#f87171">α-gal epitopes</span>。
- 基因改造豬的發展（knockout of <span style="color:#60a5fa">α-1,3-galactosyltransferase</span>）。

---

## <span style="color:#f87171">感染</span>與惡性腫瘤併發症

### 機會性<span style="color:#f87171">感染</span>

| 病原 | 預防/治療 |
|------|----------|
| **<span style="color:#c084fc">CMV</span>** | <span style="color:#fb923c">Valganciclovir</span>、<span style="color:#fb923c">Ganciclovir</span>；高風險患者<span style="color:#60a5fa">預防性治療</span> |
