# CH35 腹壁、網膜、腸繫膜和後腹腔
## Abdominal Wall, Omentum, Mesentery, and Retroperitoneum

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 腹壁 (Abdominal Wall)

### 手術解剖學 (Surgical Anatomy)

**腹壁九層結構**：

1. 皮膚（skin）
2. 皮下組織（subcutaneous tissue）
3. 淺層筋膜（superficial fascia / Camper's fascia）
4. 腹外斜肌（external oblique muscle）
5. 腹內斜肌（internal oblique muscle）
6. 腹橫肌（transversus abdominis muscle）
7. 腹橫筋膜（transversalis fascia）
8. 腹膜外脂肪組織（preperitoneal adipose tissue）
9. 腹膜（peritoneum）

**腹直肌鞘（Rectus Sheath）結構差異**：

| 位置 | 前鞘 | 後鞘 |
|------|------|------|
| **弓狀線以上** | 腹外斜肌腱膜 + 腹內斜肌腱膜前層 | 腹內斜肌腱膜後層 + 腹橫肌腱膜 |
| **弓狀線以下** | 腹外斜肌 + 腹內斜肌 + 腹橫肌腱膜（全部三層） | 僅腹橫筋膜（無腱膜覆蓋）→ **此為腹壁弱點** |

**腹壁血液供應**：

| 血管 | 來源 |
|------|------|
| **上腹壁動/靜脈** | 胸內动脉分支，位於腹直肌後方 |
| **下腹壁動/靜脈** | 來自髂外动脉，與上腹壁動/靜脈在臍部形成吻合 |

上下肢血管形成側支循環。

**腹壁神經支配**：

- 感覺神經：T4-L1 皮節
- 運動神經：T6-T12

### 生理學

- **屈曲（Flexion）**：雙側腹直肌 + 外/內斜肌共同收縮
- **旋轉（Rotation）**：對側外斜肌 + 同側內斜肌同時收縮
  - 向右旋轉 = 右內斜肌收縮 + 左外斜肌收縮
- **用力功能**：協助用力（咳嗽、排便、排尿、分娩等）

### 腹部切口的選擇與關閉

#### 切口類型

| 切口類型 | 適應症 |
|---------|--------|
| **正中切口（Midline）** | 最常用，可暴露大多數腹腔器官 |
| **旁正中切口（Paramedian）** | 偏離中線，腹直肌鞘或鞘旁 |
| **肋緣下切口（Subcostal）** | 上腹部、肝膽、脾、胰、腎上腺 |
| **雙側肋緣下（Chevron/Bilateral subcostal）** | 上腹部大手術 |
| **麥氏切口（McBurney/Rocky-Davis）** | 闌尾切除；肌肉分離技術 |
| **橫切口（Transverse）** | 骨盆腔手術；較低 hernia 發生率 |
| **Pfannenstiel 切口** | 婦科/泌尿外科；橫向切開皮膚，腹直肌分離 |

#### 切口關閉原則

- **間距（bite）大小**：**5-8 mm** 的小間距優於 1 cm 標準間距（2 項隨機對照試驗證實可降低切口疝氣發生率）
- 正中切口關閉：距切口邊緣 1 cm 進針，間距 1 cm
- 橫切口關閉需縫合深層（腹內斜肌 + 腹橫肌 + 腹橫筋膜）和淺層（前鞘 + 外斜肌/前鞘）
- **預防性網片植入**：研究顯示可降低切口疝氣，但長期資料和網片相關併發症尚待觀察

#### 腹腔鏡入口技術

- **Hasson 技術（開放式）**：直視下逐層切開各層筋膜，確認進入腹腔
- **Veress 針技術（封閉式）**：盲性穿刺進入，確認進入腹腔後建立氣腹
- 入口位置選擇：依手術目標和操作角度規劃
- **所有 trocar 孔 >5 mm 者皆需縫合筋膜**（防止 Trocar site hernia）

### 先天性異常

#### 腹壁發育（胚胎學）

- 胚胎第 5 週：側板中胚層開始形成腹壁各層
- 胚胎第 7 週：左右側板在中線融合形成腹白線（linea alba）
- 胚胎第 6 週：中腸生長速度快於腹腔，暫時性臍疝形成
- 胚胎第 8-9 週：卵黃管（vitelline duct / omphalomesenteric duct）退化
- 胚胎第 12 週：中腸完成 270° 逆時針旋轉後返回腹腔

#### 臍疝（Omphalocele）vs. 腹裂（Gastroschisis）

| 特徵 | 臍疝（Omphalocele） | 腹裂（Gastroschisis） |
|------|---------------------|----------------------|
| 發生率 | 1:3,000-5,000 | 1:5,000 |
| 位置 | 臍部（缺陷位於臍環） | 臍部旁側（通常右側） |
| 囊膜 | 有羊膜/腹膜覆蓋 | 無（直接暴露） |
| 染色體異常 | 常見（20-30%） | 少見 |
| 腸道旋轉 | 異常 | 正常 |
| 預後 | 取決於是否合併染色體/心臟異常 | 較好（無染色體異常） |

#### 卵黃管殘餘（Vitelline Duct Remnants）

- 胚胎第 8-9 週未退化導致
- 頻率：正常成人 2%（Meckel 憩室最常見）
- **表現光譜**：

| 殘餘類型 | 表現 |
|----------|------|
| 完全未退化 | 卵黃管瘻管（糞便自臍部流出） |
| 部分退化 | 囊腫形成（網膜囊腫/卵黃囊囊腫） |
| 僅存臍端 | 臍息肉（umbilical polyps） |
| 僅存迴腸端 | **Meckel 憩室**（最常見） |
| 纖維帶附著 | 腸阻塞 |

#### 臍尿管殘餘（Urachal Remnants）

- 來自尿囊（allantois）近端
- 退化失敗 → 尿囊管開放 → 膀胱尿液從臍部流出
- **治療**：尿囊切除 + 膀胱修補

### 後天性異常

#### 腹壁疝氣（Abdominal Wall Hernias）

##### 非切口性疝氣

**上腹部疝氣（Epigastric Hernia）**：

- 位於臍與劍突之間
- 通常小、可能多發
- 嵌閉罕見：僅有症狀者需要修補
- **修補**：小切口直接縫合；腹腔鏡可行但非必要

**臍疝氣（Umbilical Hernia）**：

- 先天性（新生兒常見，尤其早產兒）或後天性（腹壓增加：懷孕、肥胖、腹水）
- 女性發生率高於男性
- **5 歲前自然關閉率較高**，可先觀察
- **適應症**：嵌閉、增大、有症狀、5 歲後未關閉
- 大缺陷：網片置於腹膜前（sublay）位置

**肝硬化腹水患者臍疝處理原則**：

| 情況 | 處理 |
|------|------|
| 無症狀 | 保守治療（積極控制腹水） |
| 準備肝移植者 | 移植時一併修補 |
| 嵌閉或皮膚即將破潰 | 緊急修補 |

**Spigelian 疝氣（Spigelian Hernia）**：

- 發生於弓狀線位置的缺陷
- 腹膜穿過弓狀線，但被腹外斜肌腱膜覆蓋
- **嵌閉率達 20%**，建議手術修補
- **修補**：開放或腹腔鏡，縫合腹橫筋膜至腹直肌鞘

**切口疝氣（Incisional Hernia）**：

- 發生率：正中切口可達 20%
- **風險因素**：糖尿病、免疫抑制、肥胖、吸菸、營養不良、結締組織疾病、切口感染、高張力縫合
- 垂直切口比橫向/斜向切口發生率高

**修補方式**：

| 方式 | 說明 |
|------|------|
| **單純縫合** | 復發率高達 54% |
| **網片修補** | 復發率降至 16% |
| **Component Separation（成分分離）** | 游離雙側外斜肌腱膜，可獲得高達 10 cm 的中線移動；結合網片時復發率可降至 4-10% |

**網片放置位置**：

| 位置 | 說明 |
|------|------|
| **Onlay（overlay）** | 置於前鞘上方 |
| **Sublay** | 置於後鞘與腹直肌之間（**目前首選**，復發率低、傷口相關併發症少） |
| **Underlay（IPOM）** | 置於腹腔內 |
| **Bridge（interlay）** | 跨過缺損（高復發率） |

##### 網片材料分類

| 類型 | 材料 | 特點 |
|------|------|------|
| **合成永久網片** | 聚丙烯（polypropylene）、PET、ePTFE | 耐用、便宜 |
| **合成可吸收網片** | Vicryl 等 | 最終失去結構支撐；感染率低；但復發率高 |
| **生物網片（Biologic）** | 豬/牛/人心包膜 | 允許宿主細胞長入；可於感染區域使用；但費用高 |
| **複合網片（Composite）** | 兩面不同材料 | 置於腹腔時接觸臟器面有防黏連塗層 |

##### 腹腔鏡 vs. 開放網片修補（Incisional Hernia）

| 結果 | 腹腔鏡修補 | 開放修補 |
|------|-----------|---------|
| 復發率 | 相當 | 相當 |
| 傷口感染率 | **較低** | 較高 |
| 腸道損傷 | **較高** | 較低 |
| 恢復時間 | 較快 | 較慢 |
| 住院天數 | 較短 | 較長 |

- 腹腔鏡修補：網片需覆蓋缺損邊緣 4-5 cm，以經筋膜縫線和螺旋 tacks 固定
- **Trocar site 疝氣**：越來越常見（微創手術增加）；嵌閉風險高（Richter 疝氣）；最常見於臍部切口；>5 mm 的 trocar 孔需縫合筋膜

#### 腹直肌分離（Rectus Abdominis Diastasis / Diastasis Recti）

- **定義**：腹白線鬆弛導致腹直肌異常分離，正常中線分離 >2 cm 為異常
- **非真正的疝氣**（腹白線完整），不會嵌閉或絞窄
- **風險因素**：肥胖、懷孕、結締組織疾病、多產、高齡產婦、多次剖腹產
- **治療**：保守治療（運動、減重）；手術（plication of rectus sheath 或網片橋接）僅用於功能障礙或美觀需求；復發率高且新引入手術風險

#### 腹直肌鞘血腫（Rectus Sheath Hematoma）

- **機制**：下腹壁動/靜脈分支破裂（弓狀線附近最常見，血管相對固定，易受剪切力損傷）
- **風險因素**：創傷（包含微創 trocar 穿刺）、劇烈咳嗽/運動、慢性肺病（長期咳嗽用力）、抗凝治療

**診斷關鍵**：

- 疼痛隨腹直肌收縮而加劇
- **Fothergill's sign**：觸摸到的腫塊在腹直肌收縮時不變
- 超音波或 CT 確診

**治療原則**：

| 情況 | 治療 |
|------|------|
| 血流動力學穩定 + 小血腫 | 門診觀察、臥床休息、局部加壓 |
| 穩定但較大/雙側血腫 | 住院監測、系列血紅素檢查 |
| 血流動力學不穩定 | 積極復甦 + 血管造影栓塞（首選）；手術僅用於栓塞失敗 |

#### 侵襲性纖維瘤病/硬纖維瘤（Desmoid Tumors / Aggressive Fibromatosis）

- **特性**：纖維母細胞腫瘤，具侵襲性但**無轉移潛能**
- 與家族性腺瘤性息肉病（FAP）相關（Gardner 症候群者達 10-15%）；FAP 接受預防性結腸切除後，desmoid tumor 成為主要死因
- **發生位置**：腹壁/腹腔內
- **風險因素**：手術切口史、懷孕、荷爾蒙暴露、外傷

**治療原則（NCCN 指引）**：

| 情況 | 治療 |
|------|------|
| 無症狀、非危及生命腫瘤 | **初始密切觀察**（16% 在 3 年內需手術，29% 會自動消退） |
| 有症狀、生長快速、侵犯周圍結構 | 手術切除 |
| 完全切除不可能且切除會造成高併發症 | 進行溫和切除 + 輔助治療 |
| 輔助/新輔助放射治療 | 大型（>5 cm）或高惡性度腫瘤 |
| 全身治療 | 荷爾蒙治療、NSAID、化療、Imatinib：無法切除腫瘤 |

#### 其他腹壁腫瘤

| 腫瘤 | 說明 |
|------|------|
| **脂肪瘤（Lipoma）** | 最常見良性腫瘤 |
| **神經纖維瘤（Neurofibroma）** | — |
| **肉瘤（Sarcoma）** | 罕見；需 MRI 評估範圍 |
| **皮膚纖維肉瘤（DFSP）** | 可能需 2 cm 邊緣 |

**治療**：核心針切片確診；完整切除（有時需網片重建腹壁）

## 網膜 (Omentum)

### 手術解剖學

**大網膜（Greater Omentum）**：

| 項目 | 說明 |
|------|------|
| **胚胎來源** | 背側胃系膜（dorsal mesogastrium） |
| **構造** | 雙層臟器纖維脂肪組織 |
| **起源** | 沿胃大彎下降 → 覆蓋小腸 → 折返 → 附著於橫結腸前腹膜 |
| **含** | 胃結腸韌帶（gastrocolic ligament）和胃脾韌帶（gastrosplenic ligament） |
| **血液供應** | 左右胃網膜動/靜脈（gastroepiploic a/v）→ 迴流入肝門靜脈系統 |
| **淋巴引流** | 脾結節或幽門下結節 → 腹腔結節 → 胸導管 |

**小網膜（Lesser Omentum）**：

- 形成小網膜囊前界
- 含肝胃韌帶（hepatogastric ligament）和肝十二指腸韌帶（hepatoduodenal ligament）
- **肝十二指腸韌帶游離緣含門脈三合一（portal triad）**：總膽管、肝动脉、肝門靜脈
- 游離緣形成**Winslow 孔（foramen of Winslow）**→ 可用於 Pringle maneuver

### 生理學

大網膜被譽為**「腹部警察（policeman of the abdomen）」**，是腹膜防禦器官。

| 功能 | 說明 |
|------|------|
| **炎症反應功能** | 網膜接觸異物或炎症時，啟動纖維化反應，可將感染局灶化防止瀰漫性腹膜炎 |
| **內分泌/代謝功能** | 網膜脂肪為內分泌器官，分泌多種 adipokines（脂肪細胞激素）；內臟脂肪增加與胰島素阻抗和高三酸甘油酯血症相關 |

**Graham Patch**（用網膜覆蓋修補穿孔性潰痬）利用網膜的炎症反應特性。

### 後天性疾病

#### 網膜梗塞（Omental Infarction）

- 罕見急性腹痛原因；分為原發性或續發性
- **原發性**：網膜扭轉、突然用力動作、血栓性靜脈炎或網膜靜脈回流受阻
- **續發性**：疝氣、腫瘤、黏連引起扭轉
- 男性、肥胖者較常見
- 臨床表現類似闌尾炎、膽囊炎、憩室炎
- **診斷**：CT 顯示前腹壁脂肪組織呈「streaking whirling pattern」
- **治療**：腹腔鏡切除壞死網膜（保守治療可能併發膿胸或黏連）

#### 網膜囊腫（Omental Cysts）

- 罕見，與腸繫膜囊腫病因相關
- 多為單房（unilocular）；可能為淋巴結構退化或 inclusion 形成
- **表現**：模糊腹痛、噁心、嘔吐；可能為網膜扭轉和梗塞的引發點
- **診斷**：CT 和超聲波顯示界線清楚之囊性佔位
- **治療**：手術切除（囊腫切除/網膜部分切除）；保守治療復發率高

#### 網膜腫瘤（Omental Neoplasms）

- **轉移性腫瘤最常見**（原發性罕見）
  - **卵巢癌**是最常見轉移到網膜的癌症
  - 其他：胃腸道癌症、黑色素瘤、子宮內膜癌、腎細胞癌

- **原發性網膜腫瘤**：脂肪瘤、黏液瘤、desmoid、**胃腸道外基質瘤（GIST）**（罕見，但有 c-kit 和 PDGFRA 突變）

## 腸繫膜 (Mesentery)

### 手術解剖學

- **腸繫膜是連續性結構**：懸吊並固定腸道至腹壁，包含動靜脈、神經、淋巴管
- **胚胎發育新模型（2017 年 Coffey）**：腸繫膜為連續性結構而非碎片化
  - 腸道旋轉：270° 逆時針旋轉
  - 盲腸/升結腸/降結腸 → 緊贴後腹壁（形成 Toldt 白線）
  - 小腸繫膜、橫結腸繫膜、乙狀結腸繫膜保持活動性

**旋轉異常的臨床意義**：

| 異常 | 後果 |
|------|------|
| 腸道與腸繫膜僅靠血管連接懸吊 | 易發生 volvulus |
| 先天性缺陷 | 內疝（paraduodenal/mesocolic areas） |
| 盲腸附著退化 | 移動性盲腸 → 盲腸扭轉 |
| 乙狀結腸繫膜變長 | 乙狀結腸扭轉 |

### 硬化性腸繫膜炎（Sclerosing Mesenteritis）

- 罕見，特發性腸繫膜纖維化
- 為炎症/纖維化光譜的一部分：
  - 侷限性 = **腸繫膜脂肪營養不良（mesenteric lipodystrophy）**
  - 瀰漫性 = **腸繫膜脂膜炎（mesenteric panniculitis）**
- **病因**：可能與先前腹部手術、自體免疫疾病、腫瘤、感染（傷寒、結核、流感、風濕熱）、血管損傷有關
- **好發**：50-70 歲白人，男性稍多

**症狀**：腹痛（最常見）、噁心、嘔吐、體重減輕、食慾不振、排便習慣改變。

**CT 特徵**：

| 特徵 | 說明 |
|------|------|
| 軟組織腫塊 | 密度高於正常腸繫膜組織 |
| **「tumor pseudocapsule」** | 低密度暈環圍繞纖維腫塊 |
| **「fat ring sign」** | 纖維化區域中沿腸繫膜血管保留的脂肪 |

可有鈣化。

**治療**：

| 情況 | 治療 |
|------|------|
| 一般 | 內科治療為主：類固醇、荷爾蒙治療、colchicine、thalidomide、cyclophosphamide |
| 腸道缺血或阻塞 | 腸道和腸繫膜切除 |
| 阻塞症狀為主 | 腸道繞道 |
| 手術角色 | **極小**（主要用於取得組織確診） |

### 腸繫膜囊腫（Mesenteric Cysts）

- 發生率：1:27,000-1:250,000 住院
- **病因**：腸繫膜淋巴管阻斷/創傷/先天性淋巴管畸形
- 多為單房；內襯單層柱狀上皮
- **Tillaux's sign**：腹部腫塊**僅能左右移動**（對比網膜囊腫可自由移動）
- **表現**：多變，50% 為意外發現
- **併發症**：囊腫破裂、腸道扭轉、腸阻塞
- **CT/超聲波**：界線清楚充滿液體的腫塊
- **3-19% 可能為惡性**（實心成分與惡性相關性高）
- **治療**：手術切除（enucleation for 良性；根治性切除 for 惡性）；穿刺引流或剝去囊腫頂部復發率高

### 腸繫膜腫瘤（Mesenteric Tumors）

- 原發性罕見
- **良性**：desmoid、脂肪瘤、囊性淋巴管瘤
- **惡性**：**淋巴瘤最常見**（bulk lymphadenopathy，通常圍繞但不阻塞腸道）
  - 其他：GIST、類癌、脂肪肉瘤、平滑肌肉瘤、惡性纖維組織細胞瘤
- **淋巴瘤不應切除**（需活檢確診後內科治療）
- **治療**：廣泛切除（但可能需切除大量腸道）

## 後腹腔 (Retroperitoneum)

### 手術解剖學

**邊界**：

| 邊界 | 範圍 |
|------|------|
| 前界 | 壁層腹膜 |
| 後界 | 髂腰肌、腰方肌 |
| 上界 | 橫膈 |
| 下界 | 提肛肌 |

**三個間隙**：

| 間隙 | 內容物 |
|------|--------|
| **前腎旁間隙（Anterior pararenal space）** | 腹膜後結構：升/降結腸、十二指腸、胰臟 |
| **腎週間隙（Perirenal space）** | 腎上腺、腎臟、腎血管、輸尿管近端 |
| **後腎旁間隙（Posterior pararenal space）** | 與前腹壁腹膜外脂肪相連 |

腹膜後腫瘤、血腫、膿瘺因前方腹膜較有彈性，常向前擴展至腹腔。

### 腹膜後感染（Retroperitoneal Infections）

**病因分類**：

| 類別 | 說明 |
|------|------|
| **原發性** | 血行性感染（如免疫抑制、糖尿病） |
| **續發性** | 來自鄰近器官（穿孔性闌尾炎、憩室炎、十二指腸潰痬穿孔、胰壞死/胰炎、醫源性胃腸道穿孔） |

**表現**：背部/脇部/腹股溝疼痛、發燒/寒顫。

**嚴重併發症**：

- 壞死性腹膜後筋膜炎：**死亡率極高**
- 敗血症

**診斷**：靜脈注射顯影 CT（顯示是否有 loculations）。

**治療**：

| 情況 | 治療 |
|------|------|
| 單房性膿瘺 | **影像導引引流**為首選 |
| 多房性或無法到達區域 | 手術引流 |
| 延遲診斷和引流不足 | 高致病率和死亡率（可達 25%） |

來源控制 + 引流 + 靜脈抗生素。

### 腹膜後纖維化（Retroperitoneal Fibrosis）

- 罕見；發生率 1.3:100,000/年
- **分為**：特發性（70%）vs. 續發性

**續發性原因**：

| 原因 | 說明 |
|------|------|
| 腹主动脉瘤 | — |
| 胰炎 | — |
| 藥物 | 麥角衍生物、β-blockers、hydralazine 等 |
| 惡性腫瘤 | 淋巴瘤、類癌、肉瘤等 |
| 其他 | 結核、放療、主/髂血管手術、石棉暴露、抽烟 |

特發性與 **IgG4 相關疾病**相關，為多系統纖維化表現之一。

**病生理**：

- 特發性被認為是免疫介導疾病
- 可能與主/髂动脉粥狀硬化相關（过度局部反應）
- 或與自體免疫性纖維細胞因子沉積相關
- HLA-DRB1*03 等位基因相關（與紅斑性狼瘡、第一型糖尿病、重症肌無力相關）

**表現**：

- 非特異性；通常因**輸尿管阻塞**而被診斷
- 症狀：隱匿性背部/脇部疼痛、全身症狀（食慾不振、體重減輕、噁心、嘔吐、發燒、不適）
- 泌尿減少（輸尿管纖維化阻塞）
- 高血壓（腎动脉受壓）
- 其他：下肢水腫、股搏減弱（腔靜脈受壓）、腹股溝疝氣

**實驗室**：ESR 和 CRP 升高；BUN/Cr 升高（有腎功能受阻時）；ANA 可能陽性。

**診斷**：

- **靜脈注射顯影 CT 首選**：
  - 纖維化團塊密度與肌肉相似
  - 常見包繞腹主/髂總动脉並壓迫腔靜脈
- 若無法使用靜脈顯影（腎功能不全）：**MRI**
- **確診需要病理組織**：CT 導引切片或腹腔鏡/開放手術切片
- **鑑別診斷**：淋巴瘤、肉瘤、結核、desmoid

**治療**：

| 病因 | 治療 |
|------|------|
| 續發性 | 治療根本原因；停用致病藥物 |
| 特發性 | **皮質類固醇為主**：高劑量 prednisone 一個月後 → 維持劑量 → 漸減；禁忌類固醇者：**Tamoxifen** |
| 類固醇失敗 | 免疫抑制劑（methotrexate、azathioprine、cyclophosphamide、mycophenolate mofetil） |

**外科治療（保留給腎功能受損患者）**：

| 治療 | 說明 |
|------|------|
| **Ureterolysis** | 游離輸尿管 + 網膜脂肪包裹（防止再次纖維化） |
| **輸尿管支架置入** | — |
| 血管阻塞 | 血管內支架 |

類固醇治療有效者：**5 年存活率達 90%**。復發率：10-30%。

## 重點摘要（Key Points）

1. **弓狀線以上的腹直肌鞘結構與以下不同**：以下所有外側肌肉腱膜層均在前方，後方只有腹橫筋膜（為腹壁弱點）
2. **兩項隨機對照試驗證實**：中線切口以 5-8 mm 小間距縫合比 1 cm 間距更能預防切口疝氣
3. **腹壁切口疝氣原發修補復發率高**：應使用網片修補或成分分離技術
4. **腹腔鏡與開放網片修補切口疝氣**：復發率和傷口感染率相似，但腹腔鏡恢復更快但腸道損傷風險較高
5. **Desmoid tumor（侵襲性纖維瘤）**：無症狀患者可先觀察（有自發消退可能）；快速生長或症狀性腫瘤建議切除
6. **大網膜**提供免疫原性和纖維化反應，能將腹部感染局灶化防止瀰漫性腹膜炎
7. **硬化性腸繫膜炎**的手術角色極小（主要用於確診）；大多數患者應內科治療（類固醇），手術僅用於腸阻塞和缺血
8. **腹膜後纖維化**的手術處理包括：組織病理確診、解除輸尿管阻塞（ureterolysis 或支架）、解除血管阻塞（支架）；**類固醇是特發性病例的主要治療**
