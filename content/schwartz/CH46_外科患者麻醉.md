# CH46 外科患者麻醉 (Anesthesia for Surgical Patients)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 歷史背景

- 麻醉的發現是最重要的醫學進步之一
- 1938年美國麻醉委員會（American Board of Anesthesiology）成立
- 現今：麻醉已成為專科，並擴展至加護病房、疼痛管理、圍手術期醫學

---

## 藥理學基礎

### 藥效學 vs. 藥物動力學

| 術語 | 定義 |
|------|------|
| **藥效學（Pharmacodynamics）** | 藥物對身體的作用 |
| **藥物動力學（Pharmacokinetics）** | 身體對藥物的處理（吸收、分布、代謝、排泄）|

### 半衰期（Context-sensitive Half-time）

- 停藥後血中濃度下降50%所需的時間
- 由給藥持續時間、分布蓄積、和代謝/排泄交互作用決定

### 藥物效應

| 類型 | 說明 |
|------|------|
| **Agonist（激動劑）** | 激活受體 |
| **Partial agonist（部分激動劑）** | 產生低於最大反應 |
| **Antagonist（拮抗劑）** | 阻斷激動劑反應 |
| **Additive（相加效應）** | 兩藥代數總和等於效應 |
| **Synergistic（協同效應）** | 兩藥總效應大於代數總和 |

### 治療指數（Therapeutic Index）

- **TD50/ED50：** 產生毒性與產生療效的劑量比
- **治療指數越高越安全**

## 吸入性麻醉劑

### 最低肺泡濃度（MAC）

- 抑制50%患者對皮膚切開疼痛反應的吸入濃度
- MAC越高 = 麻醉效力越低

| 藥物 | MAC | 優點 | 缺點 |
|------|-----|------|------|
| **Nitrous oxide（N₂O）** | 104% | 無味無臭、快速、止痛 | 空腔擴張、術後噁心、骨髓抑制 |
| **Isoflurane** | 1.2% | 肌肉鬆弛良好、支氣管擴張、便宜 | 攝取/排除慢 |
| **Sevoflurane** | 2% | 快速攝取/排除、不刺激氣道 | 循環中產物A、有腎毒性風險 |
| **Desflurane** | 6.6% | 最快速攝取/排除 | 刺激氣道、需要加熱蒸發器、貴 |

**所有吸入性麻醉劑都是惡性高熱的觸發劑**

---

## 靜脈注射藥物

| 藥物 | 作用機制 | 特點 |
|------|---------|------|
| **Propofol** | GABA受體 | 快速起效、快速恢復、噁心少；**常用於誘導**；引起劑量相關性低血壓 |
| **Thiopental/Methohexital** | GABA受體 | 快速平滑誘導；目前少用 |
| **Midazolam** | GABA受體 | 抗焦慮、遺忘；**最常用苯二氮平類**；術後譫妄風險（老年人）|
| **Etomidate** | GABA受體 | 對心血管影響小；**腎上腺抑制**；注射疼痛 |
| **Ketamine** | NMDA受體 | 止痛+遺忘；**分散麻醉**；升高血壓/心率；支氣管擴張；可用於低血量患者 |
| **Dexmedetomidine** | α2-腎上腺素受體 | 鎮靜+止痛；ICU鎮靜；無呼吸抑制 |

## 類鴉片藥物（Opioids）

### 常用藥物

- **Morphine、Codeine、Hydromorphone、Meperidine、Fentanyl及其類似物**

### 作用於µ受體

**效果：**

- 止痛、欣快感、鎮靜

**副作用：**

- 欣快、鎮靜、便祕、**呼吸抑制**

### 常用合成類鴉片

| 藥物 | 特點 |
|------|------|
| **Fentanyl** | 高脂溶性；蓄積；context-sensitive half-time陡峭增加 |
| **Remifentanil** | 被血漿膽鹼酯酶快速水解；**與年齡/體重/腎/肝功能無關** |
| **Alfentanil/Sufentanil** | 現已少用 |

### 副作用處理

- **Naloxone：** 逆轉呼吸抑制（但口服無效）
- **Methylnaltrexone/Alvimopan：** 周邊型拮抗劑；逆轉便祕但不影響止痛

---

## 非類鴉片止痛藥

| 藥物 | 機制 | 注意 |
|------|------|------|
| **Ketorolac** | NSAID（COX抑制） | 減少術後類鴉片需求；副作用：出血、血小板功能障礙、急性腎損傷 |
| **Acetaminophen** | 中樞 | 無呼吸抑制；可靜脈製劑 |
| **Lidocaine（靜脈輸液）** | 鈉通道阻斷 | 可減少術後疼痛和類鴉片需求；縮短腸道恢復時間 |

## 局部麻醉劑

### 分類

| 類型 | 代謝 | 代表藥物 |
|------|------|---------|
| **Amides** | 肝臟 | Lidocaine、Bupivacaine、Ropivacaine |
| **Esters** | 血漿膽鹼酯酶 | Cocaine、Procaine、Chloroprocaine、Tetracaine |

### 作用時程

| 藥物 | 起效 | 持續時間 |
|------|------|---------|
| **Lidocaine** | 快速 | 短 |
| **Ropivacaine** | 慢 | 長 |
| **Bupivacaine** | 慢 | 長 |

### 局部麻醉系統毒性（LAST）

**CNS症狀：**

- 不安、耳鳴、口齒不清 → 癲癇 → 昏迷

**心血管毒性：**

- 低血壓、心律不整（心臟驟停）
- **Bupivacaine** 最易引起心血管毒性

**危險因子：**

- 累積劑量、注射部位、肝腎功能、心臟功能

**治療：**

- 症狀治療
- **靜脈脂肪乳劑（Lipid emulsion）**

## 神經肌肉阻斷劑

### 比較

| 類型 | 代表藥物 | 作用時間 | 說明 |
|------|---------|---------|------|
| **去極化（Depolarizing）** | **Succinylcholine** | 快速起效（<60秒）/短（5-8分） | 唯一去極化藥物；**惡性高熱觸發劑**；燒傷/癱瘓後高血鉀風險 |
| **非去極化（Non-depolarizing）** | Rocuronium | 中 | 逆轉：Neostigmine + Glycopyrrolate |
| | Vecuronium | 中 | |
| | Cisatracurium | 長 | 自行降解（不需肝/腎）|

### 逆轉

- **Neostigmine + Glycopyrrolate：** 逆轉非去極化阻斷
- **Sugammadex：** 直接結合Rocuronium/Vecuronium

## 術前評估

### ASA分類

| 等級 | 定義 |
|------|------|
| **ASA I** | 正常健康 |
| **ASA II** | 輕度全身疾病 |
| **ASA III** | 重度全身疾病 |
| **ASA IV** | 危及生命的全身疾病 |
| **ASA V** | 瀕死 |

### 禁食指南（ASA）

| 食物 | 禁食時間 |
|------|---------|
| 清流質 | 2小時 |
| 母乳 | 4小時 |
| 嬰兒配方奶/非人類奶 | 6小時 |
| 輕便餐 | 6-8小時 |

### 困難氣道處理演算法（ASA）

1. 評估氣道
2. 嘗試常規插管
3. 失敗 → 嘗試面罩通氣
4. 兩者皆失敗 → **Laryngeal Mask Airway（LMA）**
5. LMA失敗 → 緊急氣管切開

## 監測

| 監測方式 | 應用 |
|---------|------|
| **Standard（ASA標準）** | 心電圖、血壓、血氧飽和度、體溫、呼氣末CO₂ |
| **动脉導管（Arterial line）** | 持續血壓、頻繁血氣分析 |
| **中心靜脈導管（CVP）** | 中心靜脈壓、輸液通路 |
| **肺動脈導管（Swan-Ganz）** | 心輸出量、混合靜脈氧飽和度 |
| **經食道超聲（TEE）** | 術中心臟功能、瓣膜異常 |

## 術後噁心與嘔吐（PONV）

### 風險因素

- 女性、非吸菺者、有PONV/動暈症史、吸入性麻醉劑、術後鴉片

### 預防/治療

| 藥物 | 機制 |
|------|------|
| **Ondansetron（5-HT3拮抗劑）** | 最常用 |
| **Dexamethasone** | 皮質類固醇 |
| **Metoclopramide** | Dopamine拮抗劑 |
| **Scopolamine** | 抗膼鹼 |

---

## 惡性高熱（Malignant Hyperthermia）

### 觸發劑

- **去極化神經肌肉阻斷劑（Succinylcholine）**
- **所有吸入性麻醉劑**

### 表現

- 惡性高熱家族史患者中，暴露於觸發劑�後：骨骼肌持續強直、體溫急遽上升、代謝和呼吸性酸中毒、高血鉀、心律不整

### 治療

- **Dantrolene：** 骨骼肌鬆弛（直接抑制RYR1受體）
- **支持治療：** 降溫、糾正酸中毒、高血鉀處理

## 重點摘要（Key Points）

1. **麻醉發現**是最重要的醫學進步之一，使外科得以成為醫學基礎
2. **監測進步**（动脉導管、中心靜脈、肺動脈導管、TEE）使麻醉更安全
3. **術前評估**應包含功能狀態；ACC/AHA指南可指導術前檢查
4. **ASA禁食指南**可減少吸入風險；個別患者可能需要更嚴格的禁食
5. **ASA困難氣道處理演算法**：插管和面罩通氣皆失敗時，下一步是放置LMA
6. **吸入麻醉劑**都有惡性高熱風險
7. **Propofol**是最常用的誘導藥物；快速起效、快速恢復、術後噁心少
8. **Remifentanil**由血漿膽鹼酯酶快速水解；與腎/肝功能無關
9. **局部麻醉系統毒性（LAST）**可致命；症狀從CNS開始（Bupivacaine心血管毒性最強）
10. **Succinylcholine**仍是快速序貫插管的首選；但有惡性高熱和高血鉀風險
