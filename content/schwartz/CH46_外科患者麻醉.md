# CH46 外科患者麻醉 (Anesthesia for Surgical Patients)

**Source:** Schwartz's Principles of Surgery, 11th Edition

---

## 章節導讀

麻醉是現代外科的基石，本章系統整理麻醉藥理學、吸入性麻醉劑、靜脈注射藥物、類鴉片藥物、神經肌肉阻斷劑及局部麻醉劑的機制與臨床應用，並涵蓋術前評估（ASA分類）、監測標準及惡性高熱的緊急處理原則。

---

## <span style="color:#60a5fa">歷史背景</span>

- 麻醉的發現是<span style="color:#60a5fa">最重要的醫學進步之一</span>
- 1938年美國麻醉委員會（American Board of Anesthesiology）成立
- 現今：麻醉已成為專科，並擴展至加護病房、疼痛管理、圍手術期醫學

---

## <span style="color:#60a5fa">藥理學基礎</span>

### 藥效學 vs. 藥物動力學

| 術語 | 定義 |
|------|------|
| **藥效學（Pharmacodynamics）** | 藥物對身體的作用 |
| **藥物動力學（Pharmacokinetics）** | 身體對藥物的處理（吸收、分布、代謝、排泄）|

### 半衰期（Context-sensitive Half-time）

- 停藥後血中濃度下降<span style="color:#60a5fa">50%</span>所需的時間
- 由給藥持續時間、分布蓄積、和代謝/排泄交互作用決定

### 藥物效應

| 類型 | 說明 |
|------|------|
| **Agonist（激動劑）** | 激活受體 |
| **Partial agonist（部分激動劑）** | 產生低於最大反應 |
| **Antagonist（拮抗劑）** | 阻斷激動劑反應 |
| **Additive（相加效應）** | 兩藥代數總和等於效應 |
| **Synergistic（協同效應）** | 兩藥總效應大於代數總和 |

### 治療指數（Therapeutic Index）

- **TD50/ED50：** 產生毒性與產生療效的劑量比
- **治療指數越高越安全**

## <span style="color:#60a5fa">吸入性麻醉劑</span>

### 最低肺泡濃度（MAC）

- 抑制<span style="color:#60a5fa">50%</span>患者對皮膚切開疼痛反應的吸入濃度
- MAC越高 = 麻醉效力越低

| 藥物 | MAC | 優點 | 缺點 |
|------|-----|------|------|
| **<span style="color:#fb923c">Nitrous oxide（N₂O）</span>** | <span style="color:#60a5fa">104%</span> | 無味無臭、快速、止痛 | 空腔擴張、術後噁心、骨髓抑制 |
| **<span style="color:#fb923c">Isoflurane</span>** | <span style="color:#60a5fa">1.2%</span> | 肌肉鬆弛良好、支氣管擴張、便宜 | 攝取/排除慢 |
| **<span style="color:#fb923c">Sevoflurane</span>** | <span style="color:#60a5fa">2%</span> | 快速攝取/排除、不刺激氣道 | 循環中產物A、有腎毒性風險 |
| **<span style="color:#fb923c">Desflurane</span>** | <span style="color:#60a5fa">6.6%</span> | 最快速攝取/排除 | 刺激氣道、需要加熱蒸發器、貴 |

<span style="color:#f87171">所有吸入性麻醉劑都是惡性高熱的觸發劑</span>

## <span style="color:#60a5fa">靜脈注射藥物</span>

| 藥物 | 作用機制 | 特點 |
|------|---------|------|
| **<span style="color:#fb923c">Propofol</span>** | <span style="color:#e2e8f0">GABA受體</span> | 快速起效、快速恢復、噁心少；**<span style="color:#60a5fa">常用於誘導</span>**；引起劑量相關性低血壓 |
| **<span style="color:#fb923c">Thiopental/Methohexital</span>** | <span style="color:#e2e8f0">GABA受體</span> | 快速平滑誘導；目前少用 |
| **<span style="color:#fb923c">Midazolam</span>** | <span style="color:#e2e8f0">GABA受體</span> | 抗焦慮、遺忘；**<span style="color:#60a5fa">最常用苯二氮平類</span>**；術後譫妄風險（老年人）|
| **<span style="color:#fb923c">Etomidate</span>** | <span style="color:#e2e8f0">GABA受體</span> | 對心血管影響小；**<span style="color:#f87171">腎上腺抑制</span>**；注射疼痛 |
| **<span style="color:#fb923c">Ketamine</span>** | <span style="color:#e2e8f0">NMDA受體</span> | 止痛+遺忘；**<span style="color:#60a5fa">分散麻醉</span>**；升高血壓/心率；支氣管擴張；可用於低血量患者 |
| **<span style="color:#fb923c">Dexmedetomidine</span>** | <span style="color:#e2e8f0">α2-腎上腺素受體</span> | 鎮靜+止痛；ICU鎮靜；**<span style="color:#34d399">無呼吸抑制</span>** |

## <span style="color:#60a5fa">類鴉片藥物（Opioids）</span>

### 常用藥物

- <span style="color:#fb923c">Morphine</span>、<span style="color:#fb923c">Codeine</span>、<span style="color:#fb923c">Hydromorphone</span>、<span style="color:#fb923c">Meperidine</span>、<span style="color:#fb923c">Fentanyl</span>及其類似物

### 作用於µ受體

**效果：**

- 止痛、欣快感、鎮靜

**副作用：**

- 欣快、鎮靜、便祕、**<span style="color:#f87171">呼吸抑制</span>**

### 常用合成類鴉片

| 藥物 | 特點 |
|------|------|
| **<span style="color:#fb923c">Fentanyl</span>** | 高脂溶性；蓄積；context-sensitive half-time陡峭增加 |
| **<span style="color:#fb923c">Remifentanil</span>** | 被血漿膽鹼酯酶快速水解；**<span style="color:#34d399">與年齡/體重/腎/肝功能無關</span>** |
| **<span style="color:#fb923c">Alfentanil/Sufentanil</span>** | 現已少用 |

### 副作用處理

- **<span style="color:#fb923c">Naloxone</span>：** 逆轉呼吸抑制（但口服無效）
- **<span style="color:#fb923c">Methylnaltrexone/Alvimopan</span>：** 周邊型拮抗劑；逆轉便祕但不影響止痛

---

## <span style="color:#60a5fa">非類鴉片止痛藥</span>

| 藥物 | 機制 | 注意 |
|------|------|------|
| **<span style="color:#fb923c">Ketorolac</span>** | NSAID（COX抑制） | 減少術後類鴉片需求；副作用：<span style="color:#f87171">出血、血小板功能障礙、急性腎損傷</span> |
| **<span style="color:#fb923c">Acetaminophen</span>** | 中樞 | 無呼吸抑制；可靜脈製劑 |
| **<span style="color:#fb923c">Lidocaine（靜脈輸液）</span>** | 鈉通道阻斷 | 可減少術後疼痛和類鴉片需求；縮短腸道恢復時間 |

## <span style="color:#60a5fa">局部麻醉劑</span>

### 分類

| 類型 | 代謝 | 代表藥物 |
|------|------|---------|
| **Amides** | 肝臟 | <span style="color:#fb923c">Lidocaine</span>、<span style="color:#fb923c">Bupivacaine</span>、<span style="color:#fb923c">Ropivacaine</span> |
| **Esters** | 血漿膽鹼酯酶 | <span style="color:#fb923c">Cocaine</span>、<span style="color:#fb923c">Procaine</span>、<span style="color:#fb923c">Chloroprocaine</span>、<span style="color:#fb923c">Tetracaine</span> |

### 作用時程

| 藥物 | 起效 | 持續時間 |
|------|------|---------|
| **<span style="color:#fb923c">Lidocaine</span>** | 快速 | 短 |
| **<span style="color:#fb923c">Ropivacaine</span>** | 慢 | 長 |
| **<span style="color:#fb923c">Bupivacaine</span>** | 慢 | 長 |

### 局部麻醉系統毒性（LAST）

**CNS症狀：**

- 不安、耳鳴、口齒不清 → 癲癇 → 昏迷

**心血管毒性：**

- 低血壓、心律不整（心臟驟停）
- **<span style="color:#f87171">Bupivacaine</span>** 最易引起心血管毒性

**危險因子：**

- 累積劑量、注射部位、肝腎功能、心臟功能

**治療：**

- 症狀治療
- **靜脈脂肪乳劑（Lipid emulsion）**

## <span style="color:#60a5fa">神經肌肉阻斷劑</span>

### 比較

| 類型 | 代表藥物 | 作用時間 | 說明 |
|------|---------|---------|------|
| **去極化（Depolarizing）** | **<span style="color:#fb923c">Succinylcholine</span>** | 快速起效（<60秒）/短（5-8分） | 唯一去極化藥物；**<span style="color:#f87171">惡性高熱觸發劑</span>**；燒傷/癱瘓後<span style="color:#f87171">高血鉀風險</span> |
| **非去極化（Non-depolarizing）** | <span style="color:#fb923c">Rocuronium</span> | 中 | 逆轉：Neostigmine + Glycopyrrolate |
| | <span style="color:#fb923c">Vecuronium</span> | 中 | |
| | <span style="color:#fb923c">Cisatracurium</span> | 長 | 自行降解（不需肝/腎）|

### 逆轉

- **<span style="color:#fb923c">Neostigmine</span> + <span style="color:#fb923c">Glycopyrrolate</span>：** 逆轉非去極化阻斷
- **<span style="color:#fb923c">Sugammadex</span>：** 直接結合Rocuronium/Vecuronium

## <span style="color:#60a5fa">術前評估</span>

### ASA分類

| 等級 | 定義 |
|------|------|
| **ASA I** | 正常健康 |
| **ASA II** | 輕度全身疾病 |
| **ASA III** | 重度全身疾病 |
| **ASA IV** | 危及生命的全身疾病 |
| **ASA V** | 瀕死 |

### 禁食指南（ASA）

| 食物 | 禁食時間 |
|------|---------|
| 清流質 | <span style="color:#34d399">2小時</span> |
| 母乳 | <span style="color:#34d399">4小時</span> |
| 嬰兒配方奶/非人類奶 | <span style="color:#34d399">6小時</span> |
| 輕便餐 | 6-8小時 |

### 困難氣道處理演算法（ASA）

1. 評估氣道
2. 嘗試常規插管
3. 失敗 → 嘗試面罩通氣
4. 兩者皆失敗 → **Laryngeal Mask Airway（LMA）**
5. LMA失敗 → 緊急氣管切開

---

## <span style="color:#60a5fa">監測</span>

| 監測方式 | 應用 |
|---------|------|
| **Standard（ASA標準）** | 心電圖、血壓、血氧飽和度、體溫、呼氣末CO₂ |
| **动脉導管（Arterial line）** | 持續血壓、頻繁血氣分析 |
| **中心靜脈導管（CVP）** | 中心靜脈壓、輸液通路 |
| **肺動脈導管（Swan-Ganz）** | 心輸出量、混合靜脈氧飽和度 |
| **經食道超聲（TEE）** | 術中心臟功能、瓣膜異常 |

## <span style="color:#60a5fa">術後噁心與嘔吐（PONV）</span>

### 風險因素

- 女性、非吸菺者、有PONV/動暈症史、吸入性麻醉劑、術後鴉片

### 預防/治療

| 藥物 | 機制 |
|------|------|
| **<span style="color:#fb923c">Ondansetron</span>（5-HT3拮抗劑）** | 最常用 |
| **<span style="color:#fb923c">Dexamethasone</span>** | 皮質類固醇 |
| **<span style="color:#fb923c">Metoclopramide</span>** | Dopamine拮抗劑 |
| **<span style="color:#fb923c">Scopolamine</span>** | 抗膼鹼 |

---

## <span style="color:#f87171">惡性高熱（Malignant Hyperthermia）</span>

### 觸發劑

- **<span style="color:#f87171">Succinylcholine（去極化神經肌肉阻斷劑）</span>**
- **<span style="color:#f87171">所有吸入性麻醉劑</span>**

### 表現

- 惡性高熱家族史患者中，暴露於觸發劑後：骨骼肌持續強直、體溫急遽上升、<span style="color:#f87171">代謝和呼吸性酸中毒、高血鉀</span>、心律不整

### 治療

- **<span style="color:#fb923c">Dantrolene</span>：** 骨骼肌鬆弛（直接抑制RYR1受體）
- **支持治療：** 降溫、糾正酸中毒、高血鉀處理

---

## Summary

- **<span style="color:#60a5fa">吸入麻醉劑MAC：</span>** MAC越高效力越低；所有吸入性麻醉劑都是<span style="color:#f87171">惡性高熱觸發劑</span>
- **<span style="color:#60a5fa">Propofol：</span>** 最常用誘導藥物，快速起效/恢復；但引起劑量相關性低血壓
- **<span style="color:#60a5fa">Remifentanil：</span>** 由血漿膽鹼酯酶水解，<span style="color:#34d399">與腎/肝功能無關</span>
- **<span style="color:#f87171">Succinylcholine：</span>** 唯一去極化藥物；是<span style="color:#f87171">惡性高熱觸發劑</span>且有<span style="color:#f87171">高血鉀風險</span>（燒傷/癱瘓後禁用）
- **<span style="color:#60a5fa">ASA禁食：</span>** 清流質2小時、母乳4小時、輕便餐6-8小時
- **<span style="color:#f87171">LAST（局部麻醉系統毒性）：</span>** CNS症狀先行（Bupivacaine心血管毒性最強）；治療用<span style="color:#fb923c">靜脈脂肪乳劑</span>
- **<span style="color:#f87171">惡性高熱治療：</span>** <span style="color:#fb923c">Dantrolene</span>（直接抑制RYR1）+ 支持治療
